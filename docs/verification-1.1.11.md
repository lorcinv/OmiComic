# OmiComic 1.1.11 手机端工作报告

日期：2026-10-14。本轮只更新 Android；Windows 成品保持 1.1.10。

## 修改结果

| 用户反馈 | 本轮处理 |
| --- | --- |
| 侧栏不能连续划入划出 | 在手指开始横向移动时接管手势，面板位置、遮罩透明度连续跟随；可停在中途、反向拖回。松手后结合位置与速度判断开合，系统取消手势恢复原状态。目录和书架左侧栏、标签右侧栏共用实现。 |
| 打开漫画闪入 | 保留资源库或首页，在后台准备实际阅读器与首张已解码图片；准备好后从右侧短促进入，复用准备阶段的图片节点。取消打开后，迟到的结果不会再弹出阅读器。准备阶段不接管翻页快捷键或音量键。外部文件打开也接入同一流程。 |
| 文件夹、详情与其他界面快闪 | 目录读取完成后一起提交路径、列表和滚动位置。首页、资源库、栏目、详情、书架层级和设置分级通过旧画面与新画面衔接，避免两边同时淡出到空背景。前进约 180 ms、返回约 160 ms、栏目切换约 140 ms。 |
| 快速切换不稳定 | 新导航会终止旧转场；目录、资源和跨漫画加载结果检查请求身份，返回与换栏目立即取消旧请求。修复返回动画尚未结束时重新打开漫画，旧清理过程误清空新阅读器的问题。 |
| 翻页图片加载不及时 | 预读范围内优先保留前后各最多 4 页的实际图片元素，完成解码后才用于替换；慢页加载期间保留当前页。回翻可复用原节点。内存预算与预加载开关沿用现有设置，关闭预加载或将内存缓存设为 0 时不保留这些额外页面。图像增强结果也等解码完成后再替换原图。 |
| 动画不要拖沓 | 侧栏移动期间不套动画、不逐帧重绘目录树，只改变位置与遮罩；松手收尾约 80–180 ms。目录冷查询延后到手势结束，避免拖动中刷新整棵树。尊重系统减少动态效果设置。 |
| 书签数字与日期 | 改为 `10/12 · 2026-10-14`，保持同排，不增加胶囊背景。 |

本轮阅读了本地 EhViewer 参考仓库提交 `634b281c6912b8ab2fb2117240c1fda0c677b6c0`：`MainActivity.kt` 的 DrawerLayout、`GalleryProvider.kt` 的预加载和按解码尺寸计算缓存、`scene_open_enter.xml` 的短转场。Omi 使用自己的界面与 WebView 实现，保留现有主题、布局和图标，没有引入大型界面或动画库。

## 验证

- Android 构建、类型检查和差异格式检查通过。
- **40 项界面回归通过**：覆盖跟手开合、反向与取消、慢解码、图片节点复用、快速换栏目、延迟请求取消、目录与详情返回、设置分级、跨漫画切换、返回过程中重新打开，以及已有双页、缩放、全景和自动阅读交互。最后的准备阶段按键隔离改动后，25 项阅读相关用例复核通过。
- **44 项 DOM／数据交互测试通过**。
- **最终 APK 覆盖安装与原生交互验证通过**：左右各记录 60、120、200、140、80 px 的实际手势位置，包含反向；面板与遮罩随之改变。目录、详情和阅读器均记录到前进／返回转场。
- 原生连续翻页抽样 **267 帧**，可见图片未就绪帧 **0**；验证相邻页翻到前台后仍是原图片节点。该次模拟器采样最大帧间隔 133 ms。
