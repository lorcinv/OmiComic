# OmiComic 1.1.5 工作报告与验证记录

日期：2026-10-14。交付 Windows x64 免安装 ZIP 与原签名 Android APK，Android 版本码 10105。本轮按最新 23 项反馈调整界面和交互，沿用 Omi 的配色、字体、圆角及玻璃面板。

## 逐项完成情况

| 反馈 | 已实现行为 |
| --- | --- |
| 1. PC 页码及两端全景拖动 | PC 浮层显示实际页序号，去掉文件名前导零，双页显示两个数字；使用半透明背景，仅靠近圆点或拖动时出现，离开 1.5 秒隐藏。两端全景拖动实时连续滚动，只有点击轨道触发跳转动画 |

## 封面加载复查

保留前轮请求合并、有界并发、取消无用任务、目录元数据复用及持久化封面位置的优化。本轮进一步修复手机书签封面的可见性观察和缓存使用，并限制连续列表及阅读预览的渲染范围。

以下数值来自最终 1.1.5 APK，清除派生缓存后测量，仅反映本机模拟器和测试文件提供程序：

| 场景 | 结果 |
| --- | --- |
| 24 层目录首封面 | 178ms，4 轮分段查找，图片解码成功；再次请求 14ms |
| 120 个空目录后寻找封面 | 250ms，17 轮，图片解码成功；再次请求 3ms |
| 连续返回同一目录 12 次 | 每次 3–6ms，封面保持可用，没有重新进入扫描状态 |
| 后台封面并发时打开漫画 | 前台首图实际解码 71ms，整本复制字节数 0 |
| 进程重启后 | 深层位置缓存直接命中，查找步数 0；请求与图片解码共 2878ms，包含新 WebView 的启动成本 |

证据为 `test-results/android-mobile-covers.json` 与 `android-mobile-restore.json`。更大归档负载与流式提供程序的历史测量保留在 [1.1.4 验证记录](verification-1.1.4.md)，不将旧测量记成本轮结果。
