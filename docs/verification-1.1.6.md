# OmiComic Android 1.1.6 工作报告

日期：2026-10-14。本轮完成最新 13 项手机反馈，保留 Omi 的主题、字体、圆角和玻璃面板。Android 版本码为 10106，使用原发布证书。Windows 本地交付包继续使用 1.1.5。

## 逐项修改

| 项目 | 结果 |
| --- | --- |
| 1. 非全景翻页闪烁 | 保留上一张已解码图片，等目标图片在实际显示节点完成解码后切换，避免 URL 已到但图片尚未显示时产生空白帧；连续翻页保持有界的页面缓存 |
| 2. 设置宽度溢出 | 移除手机设置继承的桌面最小宽度；按本阅读设置纵向排列，长标题省略，滑块与数值自适应。验证 320px、390px 竖屏及 740px 横屏 |
| 3. 目录索引 | 保存目录树的轻量索引，关闭／重开侧栏和进程重启均复用；合并同路径请求，最多两项目录读取并发，批量写入索引。刷新和本地文件操作使旧索引失效 |
| 4. 叶子目录 | 没有子目录的节点不显示展开符号；纯图片目录继续作为漫画，不增加无效层级 |
| 5. 外部浮动分页 | 收窄至约 138px，中央数字可点击输入页码；与 60px 底栏的间隔由 12px 降至 8.4px，减少 30% |
| 6. 阅读拖动预览 | 仅拖动进度条时唤出，取消关闭叉号；点击外部直接关闭并消费该次手势，不翻页、不先隐藏工具栏。上下留白均为 6px，背景不透明度 35%；关闭后不会随工具栏重新出现 |
| 7. 详情预览分页 | 标题垂直居中，分页按钮无边框；滚过标题栏后在底部中央出现同款浮动分页，标题回到视口时隐藏。两处采用 SVG 尖括号，浮动背景不透明度 80%；数字输入支持软键盘 |
| 8. 手机标签管理 | 显示选项加入「标签管理」，从右侧打开抽屉；沿用现有全局标签顺序、选择、全选及删除逻辑，长按可排序，返回键先退出选择再关闭抽屉 |
| 9. 标签／简介独立编辑 | 添加标签只提交标签，编辑简介只提交简介。长按现有标签或添加标签后进入可移除状态，标签旁显示叉号；「完成」退出编辑。同步修复数据接口的局部保存，保留未提交的另一字段及收藏元数据 |
| 10. 标签侧栏无搜索 | 标签抽屉只保留管理操作与标签列表，搜索仍使用顶部统一搜索入口 |
| 11. 模糊／精准搜索 | 设置→资源库→搜索匹配方式：逗号条件在模糊模式下为「任一满足」，精准模式下为「全部满足」。中英文逗号均支持，名称／标签／备注可混合；保留引号、字段限定和排除词 |
| 12. 文件夹式书架 | 网格和列表共用新的 SVG 文件夹外壳，包住封面，前袋遮挡封面底部约四分之一；保留标题和资源数 |
| 13. 书架排序反馈 | 去掉虚线外框，使用整张卡片的浅蓝蒙版，与现有手机选择状态一致 |

详情浮动分页已移至独立的顶层容器，避免毛玻璃父容器影响定位；打开输入时不会因原容器滚动而丢失输入框。实包截图检查同时修复了「添加标签」被旧按钮宽度裁切的问题，并修正播放按钮说明中的过时位置描述。

## 安装与复验

成品：`release/OmiComic-1.1.6-android.apk`。直接覆盖安装，保留记录，不要先卸载。旧版 APK 和修改前备份 `.cache/mobile-fixes-116-20261014-140718` 已保留；本轮没有提交、推送或发布到 GitHub。

构建与检查入口：`npm test`、`npm run test:dom`、`npx playwright test`、`npm run dist:android`、`node scripts/verify-android.cjs`。
