# OmiComic 1.1.7 工作报告

日期：2026-10-14。Windows 和 Android 同步更新，本轮对应最新 16 项反馈。保留 Omi 的配色、字体、圆角与面板样式；未上传 GitHub。

## 修改结果

| 项目 | 修改 |
| --- | --- |
| 1. 全景左右顺序 | 横向全景按左右阅读方向实际排列图片，换向保持当前页；拖动、惯性和横向滚轮随方向变化，纵向滚轮、进度跳转仍按页码前进。图片本身不镜像。 |
| 2. 弹层外部模糊 | 手机侧栏、底部菜单和确认弹窗的外部遮罩取消模糊，保留遮罩与面板自身的玻璃质感。 |
| 3. 页码胶囊 | 手机卡片页数使用主题色胶囊，与文件大小分开。 |
| 4. 书签日期 | 书签卡片左下显示“第 X 页”及建立日期，日期格式为年-月-日。 |
| 5. 独立编辑 | 两端标签和简介各自保存。手机长按标签进入编辑，不显示完成按钮，点非标签区退出；简介保留编辑／保存，也支持长按及点外部保存退出。PC 支持双击对应区域编辑、点外部退出。 |
| 6. 预览标题边距 | 手机缩略预览 dock 标题增加左侧内边距。 |
| 7. 预览文件名 | 两端页码左对齐，文件名右对齐；文件名最多占卡片宽度三分之二，过长省略。 |
| 8. 三层书架封面 | 前三本封面错位叠放，后两层依次向右下偏移并逐渐灰化；自定义封面只替换第一层。缺少封面的层以半透明玻璃占位，兼容网格和列表。 |
| 9. 目录箭头间距 | 缩小展开箭头占位和文字左边距，图标尺寸保持一致。 |
| 10. 资源库菜单 | 根目录右侧增加三点菜单，可删除资源库索引，确认框说明原文件不删除；操作菜单不显示完成，点空白关闭当前层。书架分类菜单同样去掉完成。 |
| 11. 设置入口顺序 | 应用设置移到标签管理下方。 |
| 12. 左侧底部按钮底板 | 左侧抽屉底部操作区使用不透明主题底板，浅色为白色／近白色，夜色跟随深色主题。 |
| 13. 标签管理手势 | 在资源列表左滑打开右侧标签管理；右滑关闭右侧抽屉，保留原左侧栏手势。 |
| 14. 书架图标 | 加入书架、设置、占位与导航统一使用原底栏书架 SVG 形状及线宽。 |
| 15. 首页底栏 | 入口改名“进入资源库”，宽度约占可用按钮宽度的 47%，刷新和设置平分余下部分。 |
| 16. 主题检查 | 雾蓝、北境、暖沙、夜色的左右抽屉、菜单、底部按钮和确认弹窗使用当前主题表面色与文字色。 |

另外修复了侧栏之上打开确认／重命名窗口时窗口被侧栏遮挡的问题：手机对话框放到顶层显示，关闭子窗口后保留原侧栏。
