## 五项改动

| 项目 | 完成内容 |
| --- | --- |
| 启动动画 | 首屏准备期间显示主题背景与 Omi 图标，首页首帧绘制完成后渐隐进入，正常帧率下约 260 毫秒；按实际绘制帧推进，首帧卡顿不会吞掉过渡。启动层结束后再接收首页点击；尊重系统减少动态效果设置。加载异常时会释放启动层以显示错误。 |
| 设置文字变暗 | 根因是资源库设置位于较低的页面层级，被全局灰色遮罩盖住。现在两个入口都在同一顶层显示。保留之前的连续遮罩及面板转场。 |
| 长按直接多选 | 资源库、最近阅读、收藏、书签、书架内资源和书架卡片，长按即选中并出现蓝色蒙版；随后轻点其他卡片增减选择。底部选择按钮已删除，右侧竖向全选保留。返回退出多选。 |
| 排序默认全选 | 收藏、书签、书架及书架内资源进入排序时全部选中并显示蓝色蒙版；拖动调整顺序，排序中轻点不会取消蒙版或误开漫画。完成排序后保留多选，可返回退出。 |
| 工具栏自动隐藏 | 「设置 → 默认阅读 → 阅读工具栏 3 秒自动隐藏」，默认开启，关闭后重启保留。空闲三秒同时隐藏上下栏，点阅读中央可再次显示。按住手势、编辑、打开设置或预览面板时暂停隐藏；自动阅读不会因工具栏隐藏而停止。新开关有中／英／日文案。 |

书架多选的重命名与重置封面只在单选时可用；批量删除仍经过原有确认，并列出选中的书架，不删除漫画原文件。首页原有长按继续阅读菜单保留。
