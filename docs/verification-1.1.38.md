# OmiComic 1.1.38 安卓修复记录

2026-10-18 · 本地交付 · [完整校验数据](releases/verification-1.1.38.json)

## 修复内容

首次从首页进入资源库时，旧包虽然设置了 280 ms 动画，首次合成画面仍会挤占播放时间：对照记录中的动画进度从 150 ms 跳到结束，ready 到 finished 实际经过约 1631 ms。现在安卓首页转场先完成页面绘制和临时图层准备，再启动原生圆形展开，保留原来的 280 ms 时长、缓动和展开起点。返回首页走同一原生转场；栏目与详情仍沿用已有过渡。

临时绘制图层只在内容不超过 400 万像素时启用，动画结束、取消或切后台后恢复原图层。更大尺寸沿用普通原生转场。“减少动态效果”仍直接切换。准备图层的依据见 [Android View.buildLayer 文档](https://developer.android.com/reference/android/view/View#buildLayer())。

手机首页 Omi 图标中心的两条高亮描边已移除，保留外圈、眼睛、白色嵌片和交互。已查看雾蓝、夜色主题的实际 APK 截图；桌面图案未改。

## 验证结果

- 类型检查、安卓生产构建通过；94 项 DOM 测试、41 项相关界面测试通过。
- 实际 APK 的首次进入、返回首页、再次进入均出现连续过渡帧，未采集到空白帧。两种主题都确认使用一次原生转场，动画设置均为 280 ms，结束后临时图层和截图均释放。
- 准备时取消、播放时暂停均释放资源，迟到的帧回调不会重新播放动画。
- 原生阅读器的单／双页、RTL、全景、自动阅读、大图缩放、EXIF、画面调整、分层返回和快速复开通过，退出后图片与分块内存归零。
- 首页和阅读器各经过 15 秒后台、15 秒锁屏及内存压力恢复，页面保留、恢复后操作和覆盖层释放通过。
