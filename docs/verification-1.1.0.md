## 大图与连续阅读

本机浏览器样本：5000×5000（2500 万像素）图片，在原始尺寸模式同时开启锐化和降噪，生成最多 400 万像素处理预览。记录从打开调整面板到预览就绪为 1090 ms，采样期间仍绘制 160 帧，最长帧间隔约 111 ms。这是该样本的观测值，包含界面操作、原图解码及预览生成；不代表纯算法耗时，也不代表完全无掉帧。

30 页场景验证请求与处理数量有界，可见处理图少于 5 张；9000 像素单页条漫可自动滚到实际末端；慢速后续页加载前不会连续跳过。核心测试另覆盖 11000 张图片目录、10000 页 ZIP、100000 页预取边界。未进行数小时运行的系统总内存或内存泄漏测量，不将这些检查描述为长期性能保证。

处理预览有像素 / 长边上限，原始尺寸大图可能更软；原图解码和 PDF 缓存仍占内存。EPUB 不支持像素锐化 / 降噪；动画图片像素处理为静帧。当前 Android 原生页面接口不提供修改时间，共享界面的两个时间排序项禁用并说明原因；本轮未发布新版 APK。

## 可复现入口与证据

- `npm run verify`：类型、生产构建、核心与 DOM。追加同名章节回归后再次运行 `npm test`，80 项结果如上。
- `npx playwright test`：73 项完整界面回归。
- `npm run dist:portable`，`node --test tests/portable.electron.cjs`：验证最终 ZIP 解压出的实际程序；内部包含多格式、布局与新阅读工具测试。
- 本地证据：`test-results/reader-performance.json`、`reader-tools-small.png`、`reader-tools-smoke.json`、`reader-layout-smoke.json`、`packaged-smoke.json`、`portable-smoke.json`。
- GitHub 的 Verify reader and library 工作流执行干净依赖安装、构建、核心 / DOM 和完整浏览器回归；Windows 实际 EXE 验证为本地执行。
