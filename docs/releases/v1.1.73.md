# OmiComic 1.1.73

2026-11-03。Windows / Android 本地修复版，Android versionCode 10173。

- 手机阅读缩略预览条恢复系统原生横向滚动与惯性，支持快速甩动、连续滑动和反向滑动。
- 移除手指松开时的强制居中定位，预览条自然停在滑动位置，页码和选中页跟随实际位置。
- 进度条主动跳转、点击缩略图和调整预览尺寸仍能定位到指定页；保留有界缩略图加载与 PDF 预览。

本版针对手机阅读预览手势修复，沿用 1.1.72 的其他功能。旧包保留，没有提交、推送或公开发布。验证记录见 [手机预览条快速滑动修复](../status/2026-11-03-filmstrip-1.1.73.md)。
