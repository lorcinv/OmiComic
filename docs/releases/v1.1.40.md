# OmiComic 1.1.40 — 原创 Omi 主页与内置操作说明

本版更新原创 Omi 主页和内置操作说明，并为 Windows、Android 发行包附上 OmiComic 的 **GPL-3.0-only** 全文及对应源码入口。

## 更新内容

- PC 主页使用作者新绘制的大 Omi 和三只小 Omi，按原稿校准位置、遮挡和轮廓，并适配四种主题与底部渐隐。
- 最大化或调整窗口时，主页插画、品牌和阅读卡片按同一比例适配。
- 更换主页看板娘时，默认大小 Omi 一同隐藏；恢复默认时一同恢复。
- “设置 → 关于 OmiComic”新增操作说明：六类折叠目录、问题跳转、关键词搜索，以及 Windows／Android 操作切换，支持中英日文。
- 旧版改制图不再包含在新版程序中，来源记录保留于 `ASSET_CREDITS.md`。

## 许可文件

- 免安装 ZIP 解压后可在程序旁找到 `LICENSE` 和 `SOURCE_CODE.txt`；第三方许可仍随程序提供。
- Windows 安装程序显示 GPLv3 许可页，安装后也可在程序目录查看同样的文件。
- Android APK 内的 `assets/LICENSE` 和 `assets/SOURCE_CODE.txt` 提供同样的信息，使用原发布证书签名，可覆盖安装。
- 本页的 Source code (zip) / Source code (tar.gz) 对应 `v1.1.40` 标签。
