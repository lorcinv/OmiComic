# OmiComic 1.1.39 — PC 小更新

本次是 PC 阅读界面的小更新。同一发行页提供 **PC · Windows x64 1.1.39** 和 **Android 1.1.38**，方便按平台下载；Android 沿用已发布的 APK。

## PC 更新

- 阅读方向按钮只点亮当前方向的箭头，另一个箭头浅灰显示。
- 修复从右到左阅读时整个按钮变蓝的问题，四套主题保持一致。

本页的 Source code ZIP 和 tar.gz 对应 `v1.1.39` 标签，包含这次修复。验证范围见 [Windows 1.1.39 校验记录](https://github.com/lorcinv/OmiComic/blob/main/docs/verification-1.1.39-windows.md)。
