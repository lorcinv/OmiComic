# OmiComic 1.1.56

2026-10-31。本轮更新集中改善大图读取。

- 单张图片达到 5 MiB、超过 1600 万像素或长边超过 8192 像素时，自动采用快速显示路线；压缩包按其中的单页图片大小判断。
- Android 大图跳过额外逐行重采样，保留系统采样解码与放大时的局部分块，降低额外处理时间。
- Windows 大图直接使用原图显示，减少额外的图片复制、重采样及显示等待；普通图片保留原有高质量滤波。
- 补充大文件、超长图、透明图片、压缩包单页大小和普通漫画画质检查。

Windows 安装包和 Android APK 使用独立的 `1.1.56` 版本号和文件名。当前为本地构建，保存在 `release/OmiComic-1.1.56-本地版/`，尚未上传 GitHub。

本轮已完成 Windows 打包程序运行检查及 Android 模拟器检查。用户实际问题漫画和手机真机验证仍待补充；大图快速路线依赖系统显示，密集网点的缩小效果可能与普通图滤波路线不同。
