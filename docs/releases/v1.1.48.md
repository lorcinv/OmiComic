# OmiComic 1.1.48 · Windows / Android

本次为两端统一更新，新增 PC 拖入目录，并整理操作说明和常见问题。

- **PC 拖入目录**：从文件管理器把单个文件夹拖入 OmiComic，即可加入资源库。首页、资源库、阅读器和设置界面都能接收，添加时保留当前界面与阅读位置。
- **拖入提示**：拖入时显示提示，添加后告知结果；已添加的目录不会重复加入。每次接收一个文件夹，单个漫画文件继续通过“打开文件”阅读。
- **双端说明更新**：说明卡片何时代表文件夹、整本漫画或单张图片；补充书架、收藏、书签的区别与具体操作，讲清图片收藏、封面与页面缩略图、WebP 格式等常见疑问。
- **用语整理**：同步更新应用内离线说明，以及中文、英文、日文使用文档。Android 保持系统目录授权方式。

两端版本统一为 1.1.48。继续包含 1.1.47 的封面缓存、加载队列和增量搜索优化，以及此前的主界面开关、随机阅读和手机收藏位置调整。

Windows 提供安装包和完整免安装 ZIP；Android 使用原签名，可覆盖升级。源码和 SHA-256 校验文件随附件提供。

此前更新：[1.1.47 封面与搜索优化](https://github.com/lorcinv/OmiComic/releases/tag/v1.1.47) · [1.1.40–1.1.45 累计说明](https://github.com/lorcinv/OmiComic/releases/tag/v1.1.45)。
