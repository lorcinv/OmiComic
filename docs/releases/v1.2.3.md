# OmiComic 1.2.3

Windows 和 macOS 桌面版同步更新，修复跨页拆分后左右方向键有时需要按两次才能翻页的问题。普通窗口和全屏下，按一次方向键即可翻到相邻的半页或整页，两种阅读方向均支持。
