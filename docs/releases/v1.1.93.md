# OmiComic 1.1.93

Windows 与 Android 统一为 1.1.93，本版汇总阅读切换与安卓界面修复。

- 从首页最近阅读或历史记录进入漫画后，按源目录的排序定位当前漫画，再切换上一本或下一本。
- 上下本切换跳过没有直接可读图片的空目录和整理目录，保留真正的图片漫画文件夹；不递归进入整理目录。
- 修复安卓普通单页、双页滑动到首尾后，跨本箭头需要点击两次的问题。
- 全景连续阅读补齐开头的上一本与结尾的下一本入口。普通单页、双页统一左右箭头；全景按横向、纵向及阅读方向显示。
- 安卓资源库菜单统一三行按钮间距，保留底部安全留白并增加底线；书架分类和资源库侧栏底部按钮文字居中。
- 精简画面调整弹窗的小字说明和关闭按钮，调整平板上的底部位置。
- 恢复安卓系统“打开方式”识别，并加入构建检查，防止后续打包遗漏。
