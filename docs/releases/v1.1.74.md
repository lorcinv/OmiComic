# OmiComic 1.1.74

2026-11-03。Windows / Android 本地修复版，Android versionCode 10174。

- 修复进入漫画前整个界面缩小、闪动的问题，保留真实内页就绪后的 200 ms 进入动画。
- 文件夹打开和返回改用淡入淡出，取消整屏缩放造成的颤动。
- 重新进入普通目录或书架文件夹从顶部开始；切换栏目和退出阅读器时仍保留当前浏览位置。
- 底部阅读进度条不再出现触摸高亮或焦点外框，拖动定位继续有效。
- 修正连续列表切换时先显示旧可见行的问题，避免长列表进入短文件夹时短暂空白或位置跳动。
- 两端加入书架浮窗的书架计数改为纯数字，与书架分类一致；“已加入”和“部分已加入”提示保留。

最新交付目录：`release/OmiComic-1.1.74-书架计数调整版/`。手机版本保持 1.1.74，PC 同步至 1.1.74；原 Android 交付保留。

详见 [手机稳定性修复](../status/2026-11-03-mobile-stability-1.1.74.md) 和 [书架计数调整](../status/2026-11-03-picker-count-1.1.74.md)。
