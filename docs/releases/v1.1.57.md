# OmiComic 1.1.57

2026-10-31。本轮重点修复 PC 阅读与详情预览。

- **混合命名页序校准**：同一目录中，`P001…P086` 与“书名090…”一类明确的单组页码会按页码衔接，封面、字母附页和子目录保持稳定顺序。原文件名、图片和压缩包不作改写，书签与阅读位置继续对应具体图片。
- **放大显示原始像素**：大图，以及放大到原始像素密度的普通图片，按当前可视区域从原图重画，不再等待整张大图显示层重新铺满。普通适屏图片的高质量滤波保留在后台，先显示已解码原图。
- **减少大文件卡顿风险**：限制同时完整解码的图片数量、预读窗口与原始数据缓存；可视区域画布有独立上限，前台读页优先。
- **详情缩略图连续滚动**：PC 可跨过第 48、96 页一直向后浏览，无需手动换组；只挂载附近的缩略图。手机保留分页操作。

本地包位于 `release/OmiComic-1.1.57-本地版/`。Windows 与 Android 均标注 1.1.57，1.1.56 的现有文件保留原位。本轮尚未上传 GitHub。
