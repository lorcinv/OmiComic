Windows 1.0.4 调整缩放规则、书籍切换与工具提示。

- 缩放选项简化为“适应窗口”，去掉“默认”字样。只有适应窗口同时限制宽高，左右不留保护边距；适应宽度、高度各按对应方向缩放，原始尺寸保持原图大小。
- 上下本按钮改为半透明磨砂圆角底，中央使用小三角，仍在尝试越过首尾翻页后出现。
- ↑ 切换上一本，↓ 切换下一本，横向和纵向阅读均生效，恢复各自进度；输入页码、操作下拉菜单时不触发切书，按住方向键不连续跳书。
- 窗口控件与顶部工具栏的解释提示统一显示在按钮行下方，修正窗口控件穿透提示框的问题。
