## 本版更新

Windows 1.1.0 增加阅读器页面排序、自动阅读与画面调整，沿用 Omi 的磨砂界面和阅读交互。

- 页面排序在阅读器设置内，按每本记忆：文件名自然升序 / 降序、修改时间升序 / 降序。图片文件夹与压缩包适用；PDF、EPUB 保留原顺序。重排保留当前图片，书签、续读、缩略图与双页配对同步更新。
- 顶部左侧按钮组最右侧提供播放 / 暂停。普通阅读按设定间隔推进页面组，全景平滑滚动。加载时等待；手动操作、打开菜单、失焦或后台暂停；到末尾停止。
- 画面调整面板提供亮度、对比度、伽马、暖色、灰度、反色、锐化和降噪。默认原图，支持总开关对比和恢复默认，按书保存，不修改原文件。
- 锐化与降噪仅处理可见页面，预览上限 400 万像素 / 长边 8192 像素。超大图原始尺寸下的处理预览可能更软，关闭总开关即可看原图。EPUB 支持基础调整与滤镜，明确禁用锐化、降噪；动画图像素处理显示静帧。
- 修复真实 RAR5 文件读取兼容问题，保留此前缩放、双页末页、全景、切书快捷键和工具提示修复。
