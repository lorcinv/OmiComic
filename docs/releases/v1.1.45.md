# OmiComic 1.1.45 · Windows / Android

本版汇总 1.1.40 至 1.1.45 的更新，包含此前本地迭代的 1.1.41、1.1.42、1.1.42.1、1.1.42.2、1.1.43 和 1.1.44。Windows 与 Android 同步更新至 1.1.45。

## 1.1.40：原创主页、操作说明与许可文件

- 默认主页使用作者新绘制的大、小 Omi，适配四种主题和窗口尺寸；更换自选图片时隐藏默认组合，恢复默认时一同恢复。
- 关于页加入六类折叠操作说明，支持离线搜索、分类跳转、中英日文及 Windows／Android 操作切换。
- Windows、Android 发行包附带 GPL-3.0-only 全文及对应源码入口；Windows 安装程序加入许可页。移除授权未核实的旧主页图，保留来源记录。

## 1.1.41–1.1.42：资源搜索、随机浏览与性能修复

- 资源库搜索覆盖当前根目录的全部子目录。两端统一搜索语法，支持多条件匹配、排除关键词、名称／标签／备注限定、完整标签及带引号的短语。
- 资源库、收藏和书签支持随机阅读，先应用搜索与标签筛选，再按每页数量显示随机批次。图片漫画目录按一本处理；重随机更换顺序，阅读返回保留当前批次，关闭随机恢复普通排序与浏览位置。
- 资源清单改为渐进发现和持久保存，搜索与随机共用已发现信息。已有结果先显示，取消或切换查询保留有效清单，各资源库任务分别处理；移除两端“正在补全清单”的横幅。
- 优化大资源库搜索：复用查询和字段匹配信息，大批匹配与排序分段执行；输入法组词期间不堆积搜索任务，空搜索恢复快速处理。
- 重随机复用已有候选，不再先遍历全部候选路径；新发现的漫画在下次重随机时参与，删除或失效资源按实际显示需要处理。
- 后台发现为目录导航、可见封面和阅读让出资源；Android 扫描随应用暂停、恢复，慢目录查询可以取消，减少扫描期间文件操作等待。
- Android 扫描与普通浏览共用目录快照和持久定位信息，减少深层漫画打开时重复查找父目录；缓存仍遵守目录授权与访问检查。
- PC 保留每页 50／100／150／200／500 档，实际卡片和封面加载按视口控制；修复手机旋转后的列表尾部空隙及末页页码。
- 优化嵌套压缩包封面加载，只读取必要候选，减少为一张封面准备全部内层包的工作；保留嵌套阅读兼容、阅读优先级及缓存限额。
- 文件改名、删除等操作局部更新清单，完整刷新核对全部目录；减少重复读取、重复封面请求，并修复未知元数据对时间排序和封面复用的影响。
- 进入搜索命中的文件夹后可以正常浏览，逐级返回恢复搜索词、标签、排序、随机批次和位置。修复手机收起键盘就取消搜索的问题，统一“重随机”文案并同步多语言说明。

## 1.1.42.1：PC 菜单材质与悬浮按钮

- 修复视图菜单底板透明，使用与排序菜单一致的半透明毛玻璃材质。
- 右下角悬浮按钮和文字底板采用底部控件同款主题底色，并加入轻微描边，增强与资源卡片重叠时的边界，适配四种主题。

## 1.1.42.2：PC 框选与取消选择

- 修复拖动框选并滚动列表时，移出视口的已选资源被取消选中；收回选框仍可正常缩小范围。
- 点击列表两侧留白或卡片间隙可清空选择；操作滚动条保留原有选择。

## 1.1.43：修正搜索匹配范围

- 搜索只匹配文件或文件夹自身名称、标签和备注，不再匹配所在路径，避免父目录含关键词时命中无关资源。
- 资源库、收藏、最近阅读、临时存放和书架同步生效；书签继续支持书签标题及页面名称。
- 更新搜索提示及中英日操作说明。

## 1.1.44：搜索结果稳定与随机返回

- 已显示的搜索结果固定顺序，后续命中追加到末尾；修复新增结果挤动当前页面、连续翻页衔接不顺和滚动位置变化。
- 搜索期间取消周期性自动重查，减少停留一段时间后的闪烁；重新搜索或手动刷新仍可更新清单。
- 随机阅读时，PC Esc 和手机返回先退出随机模式，后续操作再处理输入法、搜索、弹层和目录返回。

## 1.1.45：逐批搜索、手机收藏与主界面开关

- 漫画命中不再等待全库文件夹发现完成。结果按发现批次立即显示，每批先文件夹、后漫画；后续批次追加，不挤动已有结果。
- 未变化资源复用匹配结果，只排序新增命中项，保留当前页码、可见卡片和滚动位置。
- 手机网格、列表的收藏按钮移到右上角，减少误触；PC 位置保持原样。
- 两端新增“设置 → 外观与主题 → 显示主界面”，默认开启。关闭后启动直达资源库，不加载主页封面；重新开启即可恢复主页。
- 删除开关下方的解释文字，PC 勾选框统一放在文字左侧；内置操作说明和中英日使用说明同步补充相关功能。

## 下载与升级

- Windows x64 提供 Setup 安装包和完整免安装 ZIP；免安装版须完整解压后运行。
- Android 8.0+ 提供原签名 APK，可覆盖升级。
- 本页附件提供对应源码 ZIP 和 SHA-256 校验文件；更新前后继续使用原有设置与阅读数据。
