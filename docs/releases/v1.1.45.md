# OmiComic 1.1.45

Windows 与 Android 同步更新。Windows 提供安装包和完整 ZIP，Android 使用原签名，可覆盖升级；对应源码与 SHA-256 校验文件一并提供。

- 搜索只匹配资源名称、标签和备注，不再匹配所在路径。目录和漫画按发现批次显示，每批先目录、后漫画；后续结果追加，已显示内容及翻页位置保持稳定。
- 复用未变化资源的搜索结果，只排序新增命中项；搜索期间不再周期重扫，减少等待和闪烁。
- 随机阅读时，PC Esc 与手机返回先退出随机模式，再处理其他返回操作。
- 手机网格、列表的收藏按钮移到右上角；PC 位置保持原样。
- 两端“设置 → 外观与主题 → 显示主界面”默认开启。关闭后启动直达资源库，不加载主页封面；需要主页时重新开启即可。设置页只保留开关，PC 勾选框与其他选项一样放在左侧。
- 包含此前本地小版本的 PC 修复：视图菜单毛玻璃、跟随主题的悬浮按钮底色与细描边、滚动框选保留视口外选择，以及点击列表留白清空选择。

软件内“关于 OmiComic → 操作说明”和中英日使用说明已同步更新。

本次文字及勾选框位置调整执行构建检查，沿用前一轮已完成的搜索、主界面开关及安卓原生阅读验收，不重复运行完整测试。
