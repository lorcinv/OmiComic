# OmiComic 1.2.7

普通图片文件夹可按文件名前缀生成章节目录。把图片放在同一层，用以下任一种格式命名：

| 格式 | 示例 |
| --- | --- |
| 中文 | 第01话-001.jpg、第一话-001.jpg、第01章-001.jpg |
| 日文 | 第01話-001.jpg、第01章-001.jpg |
| 英文 | Chapter 01-001.jpg、Episode 01-001.jpg |

识别到至少两个章节，且各章的图片在阅读顺序里连在一起时，「章节」显示章名和起始页。目录沿用现有页面顺序。需要按话数顺序阅读时，建议在文件名里使用阿拉伯数字。

[下载试读样本](https://github.com/lorcinv/OmiComic/releases/download/v1.2.7/OmiComic-1.2.7-folder-chapter-demo.zip)。解压后添加到资源库，打开「01 中文」，点击阅读器的「章节」，可跳到第 1、3、5 页。

macOS 版未经 Apple Developer ID 签名和公证。 [Mac 安装与首次打开说明](../APPLE.md#mac-install)
