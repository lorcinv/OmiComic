Windows 1.0.3 修复阅读缩放、全景和双页布局。

- 普通阅读使用“适应窗口（默认）／适应宽度／适应高度／原始尺寸”下拉菜单。适应窗口完整显示图片；适应高度同时限制宽度；短横图居中。
- 横向全景自动适应高度，纵向全景自动适应宽度，下拉菜单仅影响普通阅读，退出全景后恢复原选择。
- 双页放不下当前窗口时自动拆开；超长全景可以拖到两端。切换模式不再保留导致裁切的旧滚动位置。
- Esc 退出后清除多余按钮描边，刷新按钮与同排控件统一样式和对齐。
- 修复切换缩放后立即输入页码时，跳页被延迟焦点打断的问题。
