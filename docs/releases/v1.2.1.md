# OmiComic 1.2.1

Windows、macOS 与 Android 同步更新。

**2026-11-15 桌面样式修正：** 补齐阅读设置侧栏的半透明毛玻璃，Windows 和两种 Mac 桌面包已替换，版本号仍为 **1.2.1**。已安装此前 1.2.1 桌面版的用户请重新下载并覆盖安装；Android APK 保持原文件。此次只调整侧栏背景，详见[修正记录](https://github.com/lorcinv/OmiComic/blob/main/docs/status/2026-11-15-1.2.1-sidebar-glass.md)。

- 新增跨页拆分：普通单页阅读时，横页按阅读方向分为左右两半；保留原始页数，以 `12L/100`、`12R/100` 显示，书签与续读记住具体半页。默认关闭，按本书保存，不改动原文件。
- 桌面阅读设置收拢到沉浸右侧的横向三点。侧栏直接展开适应方式、拆页和画面调整，覆盖到窗口顶部，使用毛玻璃背景；点击外部关闭时不会误翻页。
- 统一适应方式、拆页和 Android 沉浸按钮的选中颜色；优化 Android 阅读按钮松手后的反馈，修复预览条切换阅读方向后顺序未更新的问题。
- 修复部分带 XML 命名空间前缀的 EPUB 内容被过滤、导致空白页的兼容问题。
- 修复 `00016-GIF.gif`、`00021- GIF.gif` 等名称被排在 JPG 编号页之后的问题，混合图片按页码连续排列。
