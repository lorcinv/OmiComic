# OmiComic 1.1.72

2026-11-02。Windows / Android 本地修复版，Android versionCode 10172。

- PC 详情页缩略预览的左右箭头改为居中的图标，保留原有翻页、页码和连续滚动。
- 恢复两端 PDF 详情页的页面缩略图，可以直接从所选页开始阅读。
- 修复手机阅读预览条无法拖动的问题；手指松开后立即对齐，不再延迟回中。
- MOBI 补齐 KF8 与双格式解析，传统 MOBI 继续支持。带 DRM、HUFF/CDIC 压缩和超出既有容量限制的文件仍不支持。
- 详情预览优先加载当前可见的图片，减少后台封面和已滑走页面造成的排队。
- PDF 提前准备并复用解析线程，减少进入阅读和详情预览时的重复初始化。
- 切换资源库、书架、收藏、最近阅读等栏目时保留目录与滚动位置；再次点击当前栏目才回到顶层。
- Android PDF 封面改用系统直接生成并保存缓存；两端 PDF.js 封面也增加持久缓存，修改文件或清理封面缓存后重新生成。

旧版本安装包保留。本版仅作本地交付，未提交、推送或公开发布。验证记录见 [PDF、MOBI 与栏目位置修复](../status/2026-11-02-pdf-mobi-navigation-1.1.72.md)。
