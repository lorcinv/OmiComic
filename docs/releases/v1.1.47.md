# OmiComic 1.1.47 · Windows / Android

本次统一更新 Windows 与 Android，重点优化封面加载和大资源库搜索。

- **PC 封面加载**：先处理可见卡片，再预加载附近内容。滚动或追加搜索结果时保留仍需要的封面任务，减少重新排队和重复读取。
- **PC 重启后复用封面**：图片、压缩包和 EPUB 封面加入有容量上限的磁盘缓存。源文件变化、缓存损坏时重新生成；手动刷新可清理旧封面。
- **双端增量搜索**：新增批次只处理新增与变更记录，减少重复遍历旧结果。搜索条件变化、资源修改或删除时继续正确更新，已显示结果及翻页位置保持稳定。
- **PC 搜索调度**：封面加载期间仍能读取已有目录摘要，减少已建立清单的搜索等待；新的磁盘扫描继续为导航、封面和阅读让出资源。
- **减少重复等待**：封面队列已按视口控制加载，已生成的卡片图片直接显示；未变化资源的页数统计复用，手动刷新仍会重新核对。
- **统一版本**：两端均为 1.1.47，包含 1.1.46 将手机收藏爱心进一步靠近右上角的调整。搜索仅匹配名称、标签和备注，主界面开关、随机阅读及此前修复继续保留。

Windows 提供安装包和完整免安装 ZIP；Android 使用原签名，可覆盖升级。源码和 SHA-256 校验文件随附件提供。

此前 1.1.40–1.1.45 的累计更新见 [完整发行说明](https://github.com/lorcinv/OmiComic/releases/tag/v1.1.45)。
