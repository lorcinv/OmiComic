# OmiComic 1.1.61

2026-11-01。本地修复版，Windows x64 与 Android 版本统一为 1.1.61，Android versionCode 10161。

- 修复快速翻页和全景跳页时旧任务占住前台名额，导致卡住、超时及重开迟迟不显示的问题。
- 读取、解码超时后回收任务，可直接重试此页；取消能传到压缩包后台，共享读取和缓存仍保留。
- PC 原图解码后直接切页，适屏抗混叠不再阻挡切页；放大立即使用原图可见区域，取消画质淡入。
- 手机按实际预算保留普通页源分辨率，正文改用系统解码；大图细节到齐后直接交接，取消缩放安静期和画质渐变。旧滤波位图不会作为新正文缓存复用。
- 保留大图内存上限、区域解码、主动选择的画面调整和 MOBI 兼容。

包位于 `release/OmiComic-1.1.61-本地版/`，旧 1.1.60 保留。Android 验证为模拟器，没有用户真机或截图漫画原件的运行证据。具体原因、验证与性能边界见 [修复记录](../status/2026-11-01-reader-cancellation-and-clarity.md)。未提交、推送或上传 GitHub。
