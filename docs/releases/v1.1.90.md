# OmiComic 1.1.90

2026-11-08。Windows 与 Android 版本统一为 **1.1.90**；Android 版本码 10190，沿用原签名，可覆盖升级。

## 本次更新（累计 1.1.88–1.1.90）

- **双端放大拖动惯性**：普通阅读与横、纵向全景支持松手滑行，按下立即停止，支持反向拖动和边界停止。
- **安卓拖动跟随修复**：图片位置立即跟随最新输入，高清区域后台补齐，修复等高清解码后画面突然跳过去的问题。
- **安卓 PDF 与大图优化**：复用仍有用的高清区域和解码任务，减少反复取消和重复绘制；阻止旧任务回调覆盖新位置。
- 保留全景快滑回滚、切换颤动修复，以及手机、平板横竖屏安全区域适配。
