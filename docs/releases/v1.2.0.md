# OmiComic 1.2.0

Windows、macOS 与 Android 统一更新至 1.2.0。

- 修复 GIF、动画 WebP 和 APNG 在阅读中变成静态图片的问题，覆盖文件夹、压缩包和 EPUB 内嵌动图，手机同步修复。支持 `.png` 和 `.apng` 扩展名的 APNG。
- 关于页的三个入口统一间距，重新绘制项目主页、操作说明和检查更新的 SVG 图标，并修正垂直居中。
- PC“漫画阅读设置”新增“默认进入沉浸模式”，默认关闭。开启后，每次打开漫画直接进入沉浸模式，阅读中仍可手动切换。

动图保留原始动画，亮度、对比度等基础滤镜继续生效；锐化和降噪仅处理静态图片。
