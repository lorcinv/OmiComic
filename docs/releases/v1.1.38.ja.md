# OmiComic 1.1.38

今回は **Android 1.1.38** と **PC · Windows x64 1.1.37** を配布します。1.1.38 はモバイル版のホーム画面遷移とロゴの修正です。Windows には検証済みの 1.1.37 パッケージを提供します。

## Android 1.1.38

- ホームから初めてライブラリを開くとアニメーションが一瞬で終わる問題を修正。画面の準備が完了してから円形の展開を開始し、従来の時間とイージングを維持します。
- ロゴ中央の白い細い縁取りを削除。外周、目、操作時の動作は維持します。
- 初回表示、戻る操作、再表示、アニメーション中断、バックグラウンドからの復帰、リーダーを確認し、一時描画レイヤーの解放も検証しました。

## 両プラットフォームの 1.1.37 更新

- 「最近読んだ本」を矢印のない時計アイコンに変更。
- PDF エンジンを必要なときだけ読み込み、EPUB では PDF モジュールを読み込まないように変更。
- Windows で保存に失敗した後に未保存の状態がメモリーに残る問題と、PDF／EPUB を開く操作のキャンセル後にネイティブセッションが残る問題を修正。
- Android の書庫インデックスにパスの長さとファイル名の総バイト数の制限を追加。

ビルド、回帰テスト、パッケージ検証は完了しています。Android の動作確認には Android 15 エミュレーターを使用し、実機では検証していません。詳細は [1.1.37 検証記録](https://github.com/lorcinv/OmiComic/blob/main/docs/verification-1.1.37.md) と [1.1.38 検証記録](https://github.com/lorcinv/OmiComic/blob/main/docs/verification-1.1.38.md) を参照してください。
