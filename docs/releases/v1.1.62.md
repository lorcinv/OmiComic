# OmiComic 1.1.62

2026-11-01。本地优化版，Windows x64 与 Android 均为 1.1.62，Android versionCode 10162。

- 全景预加载逐页补充空出的任务名额，准备好的页面及时呈现；PC 按实际屏幕和页面宽度挂载两端内容。
- PC 缩回适屏直接复用已有画布；大图可见区域随几何同步更新，减少闪烁。
- 手机大图缩放复用已准备的原图区域，正文与细节共用预算；空出内存后主动补回下一页。
