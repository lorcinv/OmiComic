# OmiComic 1.1.55 · Windows / Android

本次发行汇总 1.1.50–1.1.55 的阅读修复与新增操作。1.1.51–1.1.54 是此前的本地验证版本，本次一起收入正式发行；下面按版本说明改动，最终行为以 1.1.55 为准。

## 1.1.55：翻页响应、缩放画质衔接和点击范围

- **PC 横向点击翻页**：左右两侧的触发区从各 25% 扩大到各 40%，覆盖图片两侧，中央保留 20%。普通单页、双页和横向全景都适用，翻页方向遵循从左到右／从右到左设置；手机与 PC 纵向点击区保持原样。本次按原版本修改，版本号仍为 1.1.55。
- **PC 单双页响应**：相邻页此前只预读了原图，点击后还要等待显示滤波。现在在既有预读页数和内存预算内提前准备相邻组的显示画布，目标组优先处理，切换时复用已准备的画面。
- **双端缩放稳定性**：连续缩放先沿用已有完整画面，停稳 320 毫秒后准备最终画质，减少短暂停顿触发的反复重刷；新旧画质用 180 毫秒渐变交接。只调整准备和显示时机，沿用现有抗摩尔纹采样。
- **安卓分块交接**：新分块未全部准备好时保留上一完整画质，不先退回底图再突然切回。新旧分块按实际占用共享原有预算，容量不足时保留当前完整层，避免为过渡增加缓存上限。
- **操作说明**：补充 PC 点击范围、放大后的手机跨页拖动、缩放还原、EPUB／MOBI 按章节阅读等说明，同步内置离线说明和中文、英文、日文文档。

## 1.1.54：翻页闪烁、全景比例和放大后拖动

- **PC 单双页防闪烁**：修复已经卸载的画布仍保留就绪标记、目标页提前显示的问题；目标画面真正准备好后才交接，等待期间保留原页。
- **PC 全景跳转比例**：修复点击进度条后，跳转动画的临时缩放被误记为静止尺寸，导致动画结束后图片比例不恢复的问题。
- **全景拖动稳定性**：使用稳定布局尺寸和像素对齐；拖动与缩放还原期间保留已有采样画面，减少整体颤动。
- **PC 放大显示**：隐藏自由放大后阅读区右侧多余的滚动条。
- **手机放大后跨页**：普通单页／双页先移动放大的图片，到达边缘继续拖动即可进入下一页／组；双页快速松手时等待完整邻组准备好再交接。
- **安卓还原与预读**：还原期间保留已完成的高清分块，结束后渐隐回适屏画面；全景优先交付视口附近已完成的邻页。沿用原并发及内存限制，保留正在进行的全景解码。还原渐变时长在 1.1.55 统一为 180 毫秒。

## 1.1.53：平滑还原和手机跟手拖动

- **双端缩放还原**：改为 300 毫秒逐帧减速动画，可由新手势打断；动画中保留当前画面，结束后更新采样。
- **手机单双页拖动**：图片和下一组跟随手指连续移动，邻页准备好后统一交接。松手后根据近期速度与剩余距离完成翻页或回弹，可反向拖回或打断回弹；首尾页使用有限阻尼。
- **PC 缩放按钮**：只显示缩放文字和百分比。常态底色与相邻按钮一致，展开菜单时使用当前主题的强调颜色；修复滑条与下方比例文字重叠，保留 8px 间距。

## 1.1.52：缩放操作、手机滑页和传统 MOBI

- **全景缩放**：修复缩放还原后再次拖动被提前中断的问题。缩放使用实际页面几何，缩小到 50% 后仍可连续浏览；自由缩放范围为 50%～600%。100% 是当前适应方式的默认大小，不是原图像素比例。
- **PC 缩放菜单**：在“画面调整”右侧加入“缩放”菜单，滑条中心为 100%，下方可重置；画面中央双击也可复位。纵向阅读可点击上下边缘翻页。
- **手机操作**：保留双指缩放，不增加独立比例控件；中央双击复位。普通单／双页支持拖动预览下一组，松手翻页或返回。
- **手机全景点击翻页**：默认关闭，可在默认阅读或阅读设置中、音量键和方向反转选项下方开启。开启后按上下／左右边缘翻页，中央仍用于工具栏和双击复位。
- **EPUB 纯图片章节**：取消额外正文边距、最小正文高度和独立页码；文字章节保留阅读留白，不裁切源图。
- **传统 MOBI**：两端接入独立线程解析和章节阅读。限传统无 DRM、未压缩／PalmDOC 格式，文件最多 64 MiB、正文最多 8 MiB；暂不支持 KF8／双格式、HUFF/CDIC、内嵌字体等变体，遇到不支持的文件会提示转换 EPUB。MOBI 暂用格式占位封面；PDF／EPUB 目录界面不在本次范围内。

## 1.1.51：阅读稳定性和封面缓存

- **PC 显示对齐**：按最终屏幕像素对齐采样图的尺寸和位置，修复分数显示比例下再次缩放的问题；保留自由缩放时的完整画面。
- **普通阅读交接**：准备完成后统一显示，翻页等待期间保留原来的完整画面，减少原图、滤波图和空白之间的切换。
- **安卓显示路径**：保留解码阶段抗混叠和硬件缩放，移除显示后的第二轮整页滤波。适屏阅读复用固定底图，主动放大后再准备高分辨率分块；首次阅读等待清晰图就绪。
- **安卓全景跟随**：等待邻页时，已有画面继续跟随最新位置，避免整帧停在旧位置而产生回拉。
- **PC 调度与缓存**：后台采样给可见画面留出绘制机会，运动期间合并缓存统计。文件夹封面增加内存与磁盘缓存，并校验选中封面的下层文件变化。
- **PC 点击翻页**：加入左右区域点击翻页和阅读方向支持，拖动、自由缩放与点击分开处理；横向点击范围随后在 1.1.55 扩大。

## 1.1.50：网点抗混叠、全景准备和文件过滤

- **双端网点处理**：缩小前先过滤密集网点，减少摩尔纹。PC 按最终显示比例分块采样；安卓在 PNG 流式解码时先抗混叠再抽样，避免提前缩小遗留混叠。
- **PC 全景准备**：提前准备多屏页面，长距离拖动时后台继续处理新页；把尺寸测量和缓存统计移出指针移动过程，保留惯性与快速甩动。
- **采样可靠性**：修复重复尺寸通知取消待执行任务、后台线程退出后显示图丢失等问题；安卓不再复用旧算法生成的图片缓存。
- **安卓解码速度**：复用相同扫描行、合并对称滤波计算，降低密集网点大图的首次解码耗时，保留流式内存限制和已有缓存。
- **文件过滤**：目录、搜索及旧目录缓存只接收支持阅读的普通文件；MP4、MP3、TXT 等不再成为资源卡片。真实文件夹仍可浏览，原文件不会被删除。
- **PC 呈现与按钮**：改用常规 Windows 窗口呈现路径，减少全景移动撕裂；横向／纵向及单页／双页按钮切换时只改变图标或数字，不再加深常态底色，保留悬停和焦点反馈。
- **预算约束**：采样结果计入阅读内存缓存上限，安卓继续等整组页面就绪后统一显示。

## 下载与验证

Windows x64 提供 Setup EXE 和完整免安装 ZIP；Android APK 保留原签名，可覆盖安装。更新前请退出旧程序；安卓覆盖升级时不要先卸载。Windows 安装包未数字签名。对应源码可从本发行标签的 GitHub 源码归档获取。

此前 1.1.55 已通过核心、DOM、浏览器与实际 Windows 包的阅读回归；安卓验证来自 Android 15 模拟器，未作实体手机验收。本次点击范围改动另行检查单页、双页、横向全景、反向阅读及拖动排除，并核对手机、纵向点击范围和内置说明。
