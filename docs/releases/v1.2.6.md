# OmiComic 1.2.6

Windows、macOS、Android 同步更新，新增阅读器章节目录功能，并优化侧栏交互和数据备份体验。

## 更新内容

- **新增阅读器章节目录**：阅读工具栏新增「章节」入口，支持自动识别漫画压缩包的分章子文件夹、PDF 书签目录以及 EPUB 内置目录，点击即可快速跳转；未包含目录的作品会自动显示逐页列表。压缩包分章整理方法见 [使用说明](../USER_GUIDE.zh-CN.md)。
- **桌面端侧栏交互优化**：点击窗口内侧栏以外的空白区域（包含顶部区域），即可关闭章节侧栏或阅读设置侧栏。
- **Android 界面细节调整**：章节侧栏改为从系统状态栏下方展开，收紧顶栏章节和书签图标的间距，修正资源库空状态提示文字对齐。
- **Android 卸载可保留数据**：在支持的系统上卸载时可勾选「保留应用数据」；也可以在卸载前导出 JSON 备份，重装后再导入。
- **修复备份导入兼容问题**：导入备份时自动兼容空标签、空备注等选填字段。
