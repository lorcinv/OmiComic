# OmiComic 1.2.2

Windows、macOS 与 Android 同步更新，修复大体积动图兼容问题。

- Android：修复大 GIF、动态 WebP、APNG 无法打开或被误报损坏的问题，以及压缩包遗漏大图页面的问题。
- Android：修复大动图生成封面时可能阻塞后续切书的问题。
- Windows/macOS：修复 EPUB 中大体积动图被跳过、无法显示的问题。
- 动图采用分段读取，单张读取上限为 256 MiB，超限时明确提示大小限制。
