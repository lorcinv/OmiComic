# OmiComic 1.2.4

Windows 和 macOS 桌面版修复了部分高分辨率扫描 PDF 封面和页面空白的问题。旧的封面缓存会自动重新生成。「设置 → 关于」现在显示程序的实际版本。

## 下载

- [Windows x64 安装版](https://github.com/lorcinv/OmiComic/releases/download/v1.2.4/OmiComic-Setup-1.2.4-x64.exe)
- [Windows x64 免安装版](https://github.com/lorcinv/OmiComic/releases/download/v1.2.4/OmiComic-Portable-1.2.4-x64.zip)，完整解压后运行 `OmiComic.exe`。
- macOS Apple Silicon（M 系列） · [DMG](https://github.com/lorcinv/OmiComic/releases/download/v1.2.4/OmiComic-1.2.4-mac-arm64.dmg) · [ZIP](https://github.com/lorcinv/OmiComic/releases/download/v1.2.4/OmiComic-1.2.4-mac-arm64.zip)
- macOS Intel · [DMG](https://github.com/lorcinv/OmiComic/releases/download/v1.2.4/OmiComic-1.2.4-mac-x64.dmg) · [ZIP](https://github.com/lorcinv/OmiComic/releases/download/v1.2.4/OmiComic-1.2.4-mac-x64.zip)
- [对应源码 ZIP](https://github.com/lorcinv/OmiComic/releases/download/v1.2.4/OmiComic-1.2.4-source.zip) · [SHA-256 校验文件](https://github.com/lorcinv/OmiComic/releases/download/v1.2.4/SHA256SUMS.txt)

Windows 安装包未做代码签名，首次运行时可能会显示“未知发布者”。

macOS 安装包未经 Apple Developer ID 签名和公证。首次打开请参阅 [Mac 安装说明](https://github.com/lorcinv/OmiComic/blob/v1.2.4/docs/APPLE.md#mac-install)。
