# OmiComic 1.1.97

Windows、macOS 与 Android 统一为 1.1.97，另提供 iOS 模拟器测试版。

- 新增 macOS Apple Silicon（arm64）与 Intel（x64）版本，支持原生窗口、Command 快捷键及 Dock 重新打开窗口。
- 桌面卡片保留七档尺寸，以默认窗口为基准适度适配；放大窗口主要增加列数，最小档保持紧凑。
- 关于页底部新增“检查更新”，放在操作说明之后。结果显示在按钮内，发现新版后可打开官方发布页；启动后也会静默检查，不自动下载安装。
- 内置操作说明增加 macOS 分类，补充安装、快捷键、窗口操作与更新说明；同步更新中、英、日三种 GitHub 主页和操作指南。
- iOS 模拟器版支持本地格式、文件授权、iPhone/iPad 阅读与触摸操作。

## 下载与安装

| 设备 | 文件 |
| --- | --- |
| Windows x64 | `OmiComic-Setup-1.1.97-x64.exe` 或 `OmiComic-Portable-1.1.97-x64.zip` |
| Android 8.0+ | `OmiComic-1.1.97-android.apk`，沿用原签名，可覆盖安装 |
| Mac · Apple Silicon | `OmiComic-1.1.97-mac-arm64.dmg` 或 `.zip` |
| Mac · Intel | `OmiComic-1.1.97-mac-x64.dmg` 或 `.zip` |
| iOS 模拟器 · arm64 | `OmiComic-1.1.97-ios-simulator.zip` |
| 源码与校验 | `OmiComic-1.1.97-source.zip`、`SHA256SUMS.txt` |

Mac 打开 DMG 后将应用拖入“应用程序”。当前包没有 Apple Developer ID 签名与公证，首次打开请参阅 [Mac 安装说明](../APPLE.md)。iOS ZIP 仅供 Apple Silicon Mac 上的 Xcode 模拟器运行，不能安装到实体 iPhone/iPad。

English: macOS builds are available for Apple Silicon and Intel, without Developer ID signing or notarization. The update action is below the user guide and includes its status. The iOS ZIP is simulator-only. See the [English guide](../USER_GUIDE.en.md).

日本語：Apple Silicon・Intel 向け macOS 版を追加しました。Developer ID の署名・公証は行っていません。更新確認は操作ガイドの下にあり、結果もボタン内に表示します。iOS ZIP はシミュレーター専用です。[操作ガイド](../USER_GUIDE.ja.md)。
