# OmiComic 1.1.97

支持 Windows、macOS 与 Android。

- 新增 Mac 版，支持 Apple Silicon 与 Intel，适配原生窗口按钮、Command 快捷键和 Dock 重开窗口。
- 桌面卡片保留七档大小，窗口放大时增加列数，避免最小档卡片也过大。
- 关于页增加“检查更新”，放在操作说明后，检查结果显示在按钮内。
- 操作说明补充 Mac 安装和操作方法，支持中文、English 与日本語。
