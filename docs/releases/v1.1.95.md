# OmiComic 1.1.95

Windows 与 Android 统一更新为 1.1.95。

- “显示设置页面”更名为“调整栏目布局”。
- 双端“默认阅读”新增“启动页”，可选择主页、资源库、书架、收藏、书签或最近阅读；PC 还可选择临时存放。
- 各栏目、文件夹、书架分类及书架内部记住浏览位置，网格与列表分别保存；退出重开后恢复。设置、详情预览和标签列表也保留滚动位置。
- 手机版“默认缩放模式”与 PC 统一，支持适应窗口、适应高度、适应宽度和原始尺寸。新漫画采用默认设置，续读沿用该漫画保存的缩放方式。
- 移除设置内“双击放大画面”底部的说明小字。
