# OmiComic 1.1.96

Windows 与 Android 统一更新为 1.1.96。

- 浏览位置只在本次使用期间保留，完全退出后重启，各栏目、文件夹、设置和详情回到顶部。
- 再次点击当前导航栏的资源库、书架、收藏、书签或最近阅读，回到该栏目最顶层并滚到顶部；PC 临时存放遵循相同规则。
- 普通返回、切换到其他栏目后再回来，仍保留本次使用期间的位置；手机网格和列表分别记忆。
- 启动页选择与漫画阅读进度继续保存，重启进入所选启动栏目的顶层顶部。
