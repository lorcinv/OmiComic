# OmiComic 1.1.38

This release includes **Android 1.1.38** and **PC · Windows x64 1.1.38**. The PC package was updated on 2026-10-24 to fix the reading-direction indicator. The Android package remains the version published on 2026-10-18.

## PC · Windows x64 1.1.38

- Highlight only the arrow for the current reading direction and show the other arrow in pale grey.
- Fix the entire button turning blue for right-to-left reading; keep its normal background in both directions.
- Check all four themes, double-page reading and direction switching.

The PC fix is commit [c195ace](https://github.com/lorcinv/OmiComic/commit/c195acedeb2666fb7c43ce55d9514e0e3f9c5aa0). See the [Windows 1.1.38 verification](https://github.com/lorcinv/OmiComic/blob/main/docs/verification-1.1.38-windows.md) for scope.

## Android 1.1.38

- Fix the animation flashing past on the first visit from Home to the library. The circular reveal starts after the page is ready, with the existing duration and easing.
- Remove the thin bright outline around the logo's centre, preserving the outer ring, eyes and interaction.
- Verify first entry, return, repeat entry, interruption, background recovery and the reader, including temporary layer cleanup.

## Version 1.1.37 changes for both platforms

- Use a plain clock for Recent Reading, without an arrow.
- Load the PDF engine on demand; EPUB no longer loads PDF modules.
- Fix draft state remaining in memory after a failed Windows save, and release late native PDF/EPUB sessions after opening is cancelled.
- Limit archive path lengths and total indexed filename bytes on Android.

Builds, regression tests and package checks passed. Android runtime checks used an Android 15 emulator; physical devices were not tested. See the [1.1.37 verification](https://github.com/lorcinv/OmiComic/blob/main/docs/verification-1.1.37.md) and [1.1.38 verification](https://github.com/lorcinv/OmiComic/blob/main/docs/verification-1.1.38.md) for scope and evidence.
