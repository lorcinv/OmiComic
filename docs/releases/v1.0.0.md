Windows 与 Android 统一版本 **1.0.0**。

- **Windows**：下载 `OmiComic-Setup-1.0.0-x64.exe`，支持 Windows x64。安装器提供桌面与开始菜单快捷方式，保留原有默认文件关联。
- **Android**：下载 `OmiComic-1.0.0-android.apk`，支持 Android 8.0 及以上，建议使用较新的系统 WebView。已沿用此前发布密钥签名，可以直接覆盖升级并保留授权和阅读记录，不要先卸载。

两端支持本地图片、ZIP/CBZ、RAR/CBR、7z/CB7、PDF 和 EPUB。手机端保留 Omi 的界面与主题，适配触控、两列书库和底部导航，并提供自适应及主题图标。RAR4、RAR5 和固实 7z 可直接阅读，无需手动解压。

资源管理新增本地重命名、仅移除索引和恢复索引。重命名同步迁移进度、书签、收藏及书架引用。Windows 本地删除移入回收站；Android 本地删除需在弹窗中单独选择，属于永久删除。

Windows EXE 未做 Authenticode 签名，系统可能显示“未知发布者”或 SmartScreen 提示。Android 不支持密码和分卷压缩包；单个归档/文档上限 1 GB。

实际安装包的测试范围和结果见 [1.0.0 验证记录](https://github.com/lorcinv/OmiComic/blob/v1.0.0/docs/VERIFICATION.md)。手机运行验证使用 Android 15 模拟器，未连接实体手机。

`SHA256SUMS.txt` 用于校验附件完整性。`7z2604-src.tar.xz` 是 Windows 随附的未修改 7-Zip 26.04 对应源码，普通使用无需下载。第三方许可和原生依赖来源均包含在应用资源中。
