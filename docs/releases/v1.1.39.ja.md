# OmiComic 1.1.39 — PC の小規模更新

PC の読書画面に関する小規模な更新です。ダウンロードしやすいよう、このリリースページに **PC · Windows x64 1.1.39** と **Android 1.1.38** をまとめています。Android は公開済みの APK を使用します。

## PC の変更

- 現在の読む方向を示す矢印だけを強調し、もう一方を薄いグレーで表示。
- 右から左へ読むときにボタン全体が青くなる問題を修正。四つのテーマで表示を統一しました。

このページの Source code ZIP と tar.gz は `v1.1.39` タグに対応し、今回の修正を含みます。確認範囲は [Windows 1.1.39 検証記録](https://github.com/lorcinv/OmiComic/blob/main/docs/verification-1.1.39-windows.md) を参照してください。
