# OmiComic 1.1.63

2026-11-01。本地优化版，Windows x64 与 Android 均为 1.1.63，Android versionCode 10163。

- PC 适屏按像素预算选择处理路线，取消文件超过 5 MiB 就跳过抗混叠的规则，改善文字边缘和网点横纹。
- PC 大图拖动复用已覆盖屏幕的原图区域，减少反复绘制；放大清晰度与内存上限保留。
- 手机优先处理当前阅读位置，合并同页解码等待并清理旧队列；限制后台图片同时读入，减少争抢。
- 手机加载和跳页交接保留上一张清晰画面，继续使用原图区域放大。
- 手机正文同时校验普通与全景的物理显示尺寸；非低内存设备适当放宽原生缓存，减少彩图反复解码，仍受用户缓存设置和硬上限约束。

两端参数分别生效。文件体积受压缩格式和画面内容影响，不能直接代表图片处理开销；本版没有统一放开手机内存限制。MOBI 与其他文件格式适配保持原实现。

安装包、APK、源码及校验记录位于 `release/OmiComic-1.1.63-本地版/`，1.1.62 保留。具体技术逻辑和验证见 [修复记录](../status/2026-11-01-reader-platform-isolation.md)。Android 验证使用专用模拟器，尚无用户真机证据。未上传 GitHub。
