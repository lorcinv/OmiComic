# OmiComic 1.1.36

A local comic reader for Windows and Android, supporting images, archives, PDF and EPUB. Organize your comics with shelves, tags, favorites and bookmarks, then continue from your last page.

## PC · Windows

Refined themes and controls, plus cropped home artwork with a preview. Double-click descriptions to edit and save them automatically, or double-click a thumbnail to start reading there. Immersive mode shows a clear completed-progress rail.

![Windows](https://github.com/lorcinv/OmiComic/raw/main/docs/images/v1.1.36/windows-library.png)

## Android

Independent layouts for the library, shelves and reading history. Touch gestures, volume-key page turns, pinch zoom, large-image reading and resuming when you return to the app.

<img src="https://raw.githubusercontent.com/lorcinv/OmiComic/main/docs/images/v1.1.36/android-library.png" height="480" alt="Android">

Both platforms include About OmiComic with the app version and GitHub project link.

[Explore all screens](https://github.com/lorcinv/OmiComic/blob/main/README.en.md)

Windows: extract the full ZIP and run OmiComic.exe. Android: install the APK to update.
