Windows 11 x64 首个安装包版本。

下载并运行 **OmiComic-Setup-0.2.0-x64.exe**（约 96 MiB）。可选择安装目录，支持桌面/开始菜单快捷方式、系统“已安装的应用”和“打开方式”；保留已有默认文件关联，卸载不会删除漫画或阅读数据。

- 启动按需加载资源库与阅读器，首屏脚本减少约 61%；程序文件相较初始打包结果缩小约 32%。
- 新增灰蓝品牌图标；缩放提示简化为“缩放，支持ctrl+滚轮操作。”。
- 七档拖动缩放铺满当前窗口，Ctrl＋滚轮可切档；优化详情折叠、仿玻璃控件及提示浮层。
- PDF、EPUB 与图片共用阅读窗口，改进全景加载、快速翻页和进度跳转；新增临时存放与四套主题。
- 整理使用说明、更新记录及项目状态，删除 00–07 旧开发规则。

实际安装后的图片、ZIP、7z、PDF、EPUB 打开、翻页、进度保存，以及安装/卸载均已验证。完整结果及 Windows 符号链接测试的权限限制见 [验证记录](https://github.com/lorcinv/OmiComic/blob/v0.2.0/docs/VERIFICATION.md)。

安装包目前未做数字签名，Windows 首次下载或运行可能显示发布者/SmartScreen 提示。

附件 `SHA256SUMS.txt` 用于校验下载完整性；`7z2604-src.tar.xz` 是随软件分发的未修改 7-Zip 26.04 对应源码，普通使用无需下载。第三方许可证保留在应用资源中。
