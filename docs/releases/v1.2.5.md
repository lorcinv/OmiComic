# OmiComic 1.2.5

Android 版修复了从文件管理器打开文件时出现重复窗口的问题。选择「仅此一次」也会进入 OmiComic 自己的窗口。应用已打开时会复用该窗口，最近阅读和续读进度会随之更新。
