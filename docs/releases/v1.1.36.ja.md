# OmiComic 1.1.36

Windows と Android 向けのローカル漫画リーダーです。画像、書庫、PDF、EPUB に対応。本棚、タグ、お気に入り、しおりで整理し、前回の続きから読めます。

## PC · Windows

テーマとコントロールの配色を調整し、ホーム画像のトリミングプレビューに対応。紹介文はダブルクリックで編集・自動保存でき、サムネイルをダブルクリックするとそのページから読めます。没入モードでは読了位置がわかりやすい進捗バーを表示します。

![Windows](https://github.com/lorcinv/OmiComic/raw/main/docs/images/v1.1.36/windows-library.png)

## Android

ライブラリ、本棚、履歴の表示レイアウトを個別に保存。タッチ操作、音量キーでのページ送り、ピンチズーム、大きな画像の表示、アプリに戻ったときの読書再開に対応しています。

<img src="https://raw.githubusercontent.com/lorcinv/OmiComic/main/docs/images/v1.1.36/android-library.png" height="480" alt="Android">

両プラットフォームの「OmiComic について」でバージョンと GitHub リンクを確認できます。

[すべての画面を見る](https://github.com/lorcinv/OmiComic/blob/main/README.ja.md)

Windows は ZIP をすべて展開して OmiComic.exe を起動。Android は APK をインストールして更新できます。
