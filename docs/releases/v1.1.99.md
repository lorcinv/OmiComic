# OmiComic 1.1.99

Android EPUB 阅读修复版。Windows 保持 1.1.98，macOS 保持 1.1.97。

- 修复旧版 Android WebView 中连续阅读页面偏向右下角、恢复阅读进度后页面移出屏幕的问题，覆盖横向、纵向及从右向左阅读。
- EPUB 图片读取失败或图片格式不支持时，显示明确提示，支持重试或跳过该页；避免将图片加载失败后的空内容缓存为正常页面。
- 手机错误提示允许换行，完整显示失败原因。

保留现有阅读模式、25% 最小缩放、手势和阅读进度。纯矢量 SVG 页面仍未新增渲染支持，遇到不支持的页面会显示提示。
