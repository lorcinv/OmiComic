# OmiComic 1.1.91

本次更新 Android，Windows 保持 1.1.90。

- 修复放大、缩小时画面上下颤动的问题，保持顶部区域可用。
- 双击围绕点击位置放大至 2 倍，再次双击还原，适合单手查看细节。
- 开启双击放大时，单击确认等待为 0.18～0.20 秒。
- 阅读设置和默认阅读设置新增“双击放大画面”开关，默认开启；关闭后松手直接翻页，仍可双指缩放，重启后保留选择。
- 普通单页、双页放大后可使用顶部状态栏和摄像头所在区域，工具按钮保留安全边距，还原后恢复原布局。
- 修复拖动后立即双击还原时误翻页的问题。
- 修复从缩略详情进入阅读后，底部翻页胶囊残留、无法点击或消除的问题。

保留双指缩放、拖动惯性与全景阅读的现有操作。
