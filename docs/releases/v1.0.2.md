Windows 1.0.2 完成本轮资源库与阅读优化：

- 视图菜单点击空白或按 Esc 关闭；刷新与失效检测移至顶部“选择”右侧。
- 首尾跨本按钮改为三角形，越界翻页后才出现，并跟随阅读方向换边。
- 双页默认 1+2；从第 6 页切换为 6+7、8+9，宽跨页独立显示，续读保留配对起点。
- 末组包含尾页就显示最终页码，内外阅读进度同步为 100%。
- 合集文件夹使用首个可读子资源封面，显示“文件夹 · 含 X 项目”。支持 PDF 第一页、EPUB 封面提取；没有封面时显示专属格式图标。
