## 本版更新

Windows 1.0.2 完成本轮资源库与阅读优化：

- 视图菜单点击空白或按 Esc 关闭；刷新与失效检测移至顶部“选择”右侧。
- 首尾跨本按钮改为三角形，越界翻页后才出现，并跟随阅读方向换边。
- 双页默认 1+2；从第 6 页切换为 6+7、8+9，宽跨页独立显示，续读保留配对起点。
- 末组包含尾页就显示最终页码，内外阅读进度同步为 100%。
- 合集文件夹使用首个可读子资源封面，显示“文件夹 · 含 X 项目”。支持 PDF 第一页、EPUB 封面提取；没有封面时显示专属格式图标。

安装文件：OmiComic-Setup-1.0.2-x64.exe。Windows 保持未签名；SHA-256 见附件。

本轮为 PC 更新，手机继续使用 [已签名 Android 1.0.1 APK](https://github.com/lorcinv/OmiComic/releases/download/v1.0.1/OmiComic-1.0.1-android.apk)。

已通过核心、DOM、界面回归，以及实际打包程序的多格式读取、封面、双页和进度持久化检查。测试范围见仓库 docs/VERIFICATION.md。



补充 Windows 免安装版：[OmiComic-Portable-1.0.2-x64.zip](https://github.com/lorcinv/OmiComic/releases/download/v1.0.2/OmiComic-Portable-1.0.2-x64.zip)。完整解压后运行 OmiComic.exe。程序内容与安装版相同；本机记录继续保存在 %APPDATA%\OmiComic\omicomic-data.json。ZIP 不含用户漫画或阅读记录，校验值见同名 .zip.sha256 附件。
