# OmiComic 1.1.89

2026-11-07。Android 更新至 1.1.89，版本码 10189，沿用原签名，可覆盖安装。Windows 保持 1.1.88。

- 优化安卓图片放大后的拖动：提前准备即将进入屏幕的高清区域，减少大图压缩包的停顿。
- 优化 PDF 放大拖动，减少多余绘制并短暂复用同页内容，保留屏幕所需清晰度。
- 换向时继续复用可见高清区域；缩回适应窗口后结束旧区域预读。保留现有惯性、按下止动和翻页逻辑。
- 兼顾手机与平板，补齐平板高清区域的尺寸上限检查。

手机竖屏、平板横屏模拟器的对照与回归检查通过，尚未做实体设备复测。压力测试中的较大 PDF 仍可能短暂停顿，数据和验证范围见 [工作报告](../status/2026-11-07-1.1.89-work-report.md)。
