## 本版更新

Windows 1.1.2 优化资源库目录浏览及阅读器缩放按钮。

- 阅读器缩放下拉按钮由 146px 收紧为 96px，沿用现有圆角和磨砂样式。
- 资源库内按 Esc 返回上一级；菜单、输入、选择模式优先处理 Esc。
- 纯图片文件夹只显示“文件夹”；含子文件夹或多个独立漫画文件才显示“含 X 项目”。数量统计子文件夹与漫画文件，不统计图片页面或无关文件。
- 目录连续滚动，页码作为定位分段。按完整行向上取整，例如 7 列、每页 60 时实际 63 项；跳页到该段首行，滚到底显示末页，调整列数和窗口大小保留当前项目。只渲染当前位置附近卡片，避免整页替换或一次加载全部卡片。
