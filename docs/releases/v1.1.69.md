# OmiComic 1.1.69

2026-11-02。Windows / Android 本地修复版，Android versionCode 10169。

- PC 拖入文件夹后的提示移至底部。
- PC 各界面右键菜单按常用程度与用途分组，移除、清空和删除操作置于末组；菜单随窗口边界调整位置。
- 手机收藏可加入书架；手机书架与内部列表直接滚动，隐藏右侧滚动条。
- 两端新建书架只填写名称；修复手机连续重命名时备注丢失、再次保存无反应的问题，兼容旧书架缺失备注。处理中文输入法确认键，保存失败时在弹窗内显示原因。
- 整文件夹加入书架时展开其中的漫画与文档，内容平铺并去重；图片目录作为一本漫画直接打开，旧合集目录在打开时平铺。
- 安卓 PDF/MOBI 使用二进制范围读取，减少界面线程上的文本转换。文档先完成首屏，再后台预读。
- 手机 PDF 恢复拖动预览；PDF 翻页保留完整画面直至新页准备完成，解析结果与缩略预览按数量限制保留。
- PC PDF 跳过重复显示采样，减少全景和翻页时的额外工作。

验证、对照条件与交付清单见 [修复记录](../status/2026-11-02-optimization-1.1.69.md)。原 1.1.68 本地包保留。
