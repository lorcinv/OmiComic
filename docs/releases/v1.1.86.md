# OmiComic 1.1.86

本版全景回滚、切换颤动和 PDF 快滑问题已由 [1.1.87](v1.1.87.md) 跟进修复，安装新版即可覆盖升级。

2026-11-07 本地 Android 版本，版本码 10186，沿用原签名。Windows 继续使用 1.1.85。

- 优化 EPUB 书目和章节读取，减少反复遍历压缩包，保留兼容回退、读取限制及完整性校验。
- 全景慢拖保持精确，快拖渐进加速，快甩滑行更远；支持按下止动和立即反向，避免将 WebView 松手坐标校正误判为反向甩动。
- 全景漫画利用顶部、侧边挖孔区域；工具栏、进度栏和阅读设置避开遮挡，手机和平板按实际横竖屏窗口适配。
- PDF、MOBI、普通图片和压缩漫画沿用现有加载路径。完整入场时间包含过渡动画，本版不宣称所有格式均已提速。
