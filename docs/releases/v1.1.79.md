# OmiComic 1.1.79：Android 平板兼容修复

Android：1.1.79 / versionCode 10179。Windows 保持 1.1.78。

1. 平板首页竖屏将封面与文字作为一组居中；横屏使用两列封面与详情布局，填满内容区域。
2. 安卓首页和资源库底部导航统一为选中点亮图标与文字、未选中使用次文字颜色，取消选中底色和浮起阴影。
3. 旧 WebView 使用按原主题计算的颜色回退，修复进度按钮光圈、标签描边、详情封面和选中缩略图的深色效果。支持现代颜色函数的手机继续使用原表达式。
4. 安卓所有页面及弹层隐藏滚动条。阅读设置删除标题、完成按钮及重复提示；保留现有菜单短横条与下拉关闭。
5. 补齐 Promise、AbortSignal 和 structuredClone 兼容接口。旧 WebView 的 PDF 使用独立兼容运行时，新 WebView 保留现有运行时，封面预热与正文使用同一个分支。
6. Android MOBI 文件大小与驻留解析预算分离，大文件按需读取；图像型大章节按图分页。小 MOBI 保留原路径，原有文本、单图和章节资源限制继续生效。
7. 增加原生 MOBI 封面；EPUB/MOBI 的详情与阅读预览使用实际插图或章节开头文字，删除已经能够显示预览时的旧占位说明。

本地包位于 `release/OmiComic-1.1.79-平板兼容修复版/`。旧内核浏览器与 Android 模拟器已验证，华为 MatePad 11、OPPO Pad Mini 尚待实机复测。没有提交、推送或公开发布。

详细验证见 [修复与验证记录](../status/2026-11-04-tablet-1.1.79.md)。
