# OmiComic 1.1.76

本地功能版，Windows 与 Android 均为 1.1.76，Android versionCode 为 10176。

- 标签联想：候选位于输入框下方，宽度与输入框一致；两端隐藏滚动条，边界渐隐。PC 使用滚轮或拖动，手机横向滑动。
- 标签管理：拖动排序有落点提示，选择模式轻微摆动；选中直接点亮，无勾选框，删除按钮单独使用红色。
- 快速标签：PC 在详情页重命名左侧打开；手机在详情向左划出右侧栏。上部为已有标签，下部为可用标签，中间使用加入、移出，只分配已有标签。
- 数据管理：设置中导出、导入和恢复导入前备份。文件名为 `OmiComic-Data-win-YYYYMMDD-HHmmss.json` 或 `OmiComic-Data-android-YYYYMMDD-HHmmss.json`。备份不含漫画原文件、缓存与自定义首页图案。
- 目录匹配：先尝试原路径，再通过本机已授权资源库中的相对子目录和文件名识别唯一对应目录。仅检查少量已有路径，不扫描整库、不计算漫画内容指纹；多处候选或没有候选时保留记录，允许手动补配。目录匹配不等于文件版本校验。
- 临时目录：PC 临时存放和两端最近阅读支持打开所在目录，不要求先将其加入资源库。Android 仍遵守系统目录授权。PC 最近阅读中不属于书库的记录可右键加入所在目录。

本版继续沿用现有阅读画质、缓存预算、翻页和进入动画。
