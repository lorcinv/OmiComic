# OmiComic 1.1.85

Windows 与 Android 均为 1.1.85；本次安卓包包含同版 EPUB 启动热修复，版本码保持 10185。

相较上个公开版 1.1.78，累计更新如下：

- **文档阅读**：安卓 PDF 使用原生位图和区域渲染；图片 EPUB/MOBI、长图复用原生绘制与缓存。文字书按页显示，优先准备当前章节，减少重复解析与分页干扰。
- **翻页与跳转**：修复大 MOBI 快速跳页失败、PC EPUB 切页闪烁；放大后可点击翻页并恢复原尺寸，完善阅读预览、邻页准备和续读。
- **平板适配**：首页竖屏居中、横屏封面加详情；修正目录箭头、导航选中样式、过深光效及旧 WebView 兼容。阅读画布保持固定，改善时间栏显隐与入场衔接。
- **资源库与反馈**：缺失的外置目录不再阻塞其他可用目录；修复首页刷新，完善卡片主题蒙版与按钮反馈。
- **跟随系统主题**：双端均可开启，默认关闭。系统浅色时使用所选日间配色，深色时使用夜色，保留日间选择。
- **EPUB 同版补充**：安卓先准备最终阅读窗口，入场后再启动其他章节的后台分页；PDF、MOBI 的解析和绘制代码保持上一包实现。

## 下载与升级

- Windows x64：Setup 安装程序、Portable ZIP；便携版须完整解压后运行。
- Android 8.0+：APK 沿用原签名，可直接覆盖安装，无需卸载。
- 附对应源码和 SHA-256 校验清单；不包含用户书籍、签名私钥或依赖目录。

## 验证范围

最终 EPUB 热修复通过类型检查、APK 构建与签名校验，139 项核心检查通过（1 项跳过）、257 项 DOM 检查及 24 项浏览器阅读回归通过。此前双端功能验证见工作报告。本次热修复因模拟器启动失败，未完成最终 APK 的运行验证及华为、OPPO 实机复测，不将浏览器结果作为实机速度承诺。
