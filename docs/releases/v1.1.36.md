# OmiComic 1.1.36 · Windows & Android

![OmiComic 1.1.36](https://raw.githubusercontent.com/lorcinv/OmiComic/v1.1.36/docs/images/v1.1.36/overview.png)

## 简体中文

Omi 是 Windows 和 Android 本地漫画阅读器，支持图片、压缩包、PDF 和 EPUB，以及书架、标签、收藏、书签和续读。

- PC 设置新增“关于 OmiComic”，写入 Omi 介绍；手机和 PC 的关于页统一版本及 GitHub 项目链接。
- Windows 汇总此前的主题调整、首页自定义图案裁剪、详情简介双击编辑并自动保存、缩略图双击阅读、沉浸进度条及大图缓存和预读优化。
- Android 汇总独立栏目布局、三语设置、原生图片显示、大图处理、目录索引和后台恢复修复，沿用原签名覆盖升级。
- 本页全部配图使用 Omi 符号占位图，不包含漫画封面、实际页面或个人资源。

Windows 下载 ZIP，完整解压后运行 `OmiComic.exe`。Android 下载 APK，覆盖安装保留记录。校验值见 `SHA256SUMS-1.1.36.txt`。

## English

Omi is a local comic reader for Windows and Android, supporting images, archives, PDF and EPUB, with bookshelves, tags, favorites, bookmarks and resume reading.

- Added About OmiComic to PC settings. Both platforms now share the Omi introduction, version and GitHub project link.
- Windows includes the recent theme refinements, cropped custom home artwork, double-click description editing with automatic saving, double-click thumbnail reading, immersive progress rail and large-image caching and preloading improvements.
- Android includes independent view layouts, three interface languages, native image rendering, large-image handling, directory indexing and background-resume fixes. The original signing certificate is retained for in-place upgrades.
- Every promotional image uses Omi symbol placeholders; no comic covers, real pages or personal libraries are shown.

Windows: extract the entire ZIP and run `OmiComic.exe`. Android: install the APK over the existing app to retain records. Checksums are in `SHA256SUMS-1.1.36.txt`.

## 日本語

Omi は Windows と Android 向けのローカル漫画リーダーです。画像、書庫、PDF、EPUB に対応し、本棚・タグ・お気に入り・しおり・続きから読む機能を備えています。

- PC の設定に「OmiComic について」を追加。両プラットフォームの紹介文、バージョン、GitHub リンクを統一しました。
- Windows にはテーマ調整、ホーム画像のトリミング、紹介文のダブルクリック編集と自動保存、サムネイルのダブルクリック読書、没入モードの進捗バー、大画像のキャッシュと先読み改善を含みます。
- Android には画面ごとのレイアウト、3 言語の UI、ネイティブ画像表示、大画像処理、フォルダー索引、バックグラウンド復帰の修正を含みます。従来の署名で上書き更新できます。
- 紹介画像はすべて Omi のプレースホルダーです。漫画の表紙、実際のページ、個人のライブラリーは含みません。

Windows は ZIP をすべて展開して `OmiComic.exe` を起動。Android は APK で上書きインストールすると記録を引き継げます。チェックサムは `SHA256SUMS-1.1.36.txt` にあります。
