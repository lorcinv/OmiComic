# OmiComic 1.1.36

面向 Windows 和 Android 的本地漫画阅读器，支持图片、压缩包、PDF 和 EPUB。用书架、标签、收藏和书签整理漫画，从上次的位置继续阅读。

## PC · Windows

首页图案支持裁剪与实时预览。双击简介即可编辑并自动保存，通过缩略图从需要的页面开始阅读；沉浸模式保留清晰的阅读进度。

![Windows](https://github.com/lorcinv/OmiComic/raw/main/docs/images/v1.1.36/windows-library.png)

## Android

资源库、书架和最近阅读分别保存显示布局。支持触摸与音量键翻页、双指缩放、大图阅读，切回应用时继续上次的阅读。

<img src="https://raw.githubusercontent.com/lorcinv/OmiComic/main/docs/images/v1.1.36/android-library.png" height="480" alt="Android">

两端设置均提供“关于 OmiComic”，可查看版本与 GitHub 项目主页。

[查看完整界面介绍](https://github.com/lorcinv/OmiComic/blob/main/README.md)

Windows 完整解压 ZIP 后运行 OmiComic.exe；Android 安装 APK 即可更新。
