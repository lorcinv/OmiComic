# OmiComic 1.1.39 — Small PC update

This is a small update to the PC reading interface. This release page provides **PC · Windows x64 1.1.39** and **Android 1.1.38** together for convenient downloads. Android uses the previously published APK.

## PC changes

- Highlight only the arrow for the current reading direction, with the other arrow in pale grey.
- Fix the entire button turning blue for right-to-left reading, consistently across all four themes.

The Source code ZIP and tar.gz on this page use the `v1.1.39` tag and include this fix. See the [Windows 1.1.39 verification](https://github.com/lorcinv/OmiComic/blob/main/docs/verification-1.1.39-windows.md) for scope.
