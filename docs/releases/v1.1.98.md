# OmiComic 1.1.98

Windows、macOS 与 Android 更新至 1.1.98。Mac 的 Apple Silicon 与 Intel 安装包于 2026-11-14 补发。

- 阅读最小缩放从 50% 降至 25%，支持桌面滚轮、缩放滑块和手机双指缩放，覆盖普通阅读与横、纵全景。
- 改善旧版 Android WebView 的启动、动画和界面兼容；无法启动时提供重试入口和 WebView 版本信息。
- 更新中文、英文和日文操作说明。
