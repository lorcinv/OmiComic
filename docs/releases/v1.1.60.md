# OmiComic 1.1.60

2026-11-01。本版将阅读链路修复正式编入独立的 1.1.60 本地构建。

- PC 原图解码后即可进入阅读，显示采样在后台完成；快速翻页保留已可用画面。
- 锐化／降噪预览不再重复重采样；放大取原图可视区域，局部效果随后补齐。
- 封面与页面预览在独立后台进程解码，减少主进程停顿。保留缩略图尺寸、缓存校验和格式兼容回退。
- Android 清晰正文直接解码；预览不再阻止原图区域补图，调整缓存区分预览和正文。
- 传统无 DRM MOBI 支持 256 MiB 文件，正文仍为 8 MiB；文件按 1 MiB 分段传入解析线程。KF8、双格式及其他未支持变体的限制保留。

Windows 与 Android 统一标记 **1.1.60**，Android versionCode 为 **10160**。交付目录为 `release/OmiComic-1.1.60-本地版/`；旧包保留，未上传 GitHub。Windows 安装包沿用本地未签名方式，Android 沿用原证书。

本版未更改上一轮已经验证的阅读实现。完整分析和验证边界见 [阅读链路报告](../status/2026-10-31-reader-route-repair.md)。Android 实际阅读证据限于模拟器，PC 极大图片仍有整图解码成本。
