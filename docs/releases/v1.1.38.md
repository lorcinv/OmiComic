# OmiComic 1.1.38

本次提供 **Android 1.1.38** 和 **PC · Windows x64 1.1.38**。2026-10-24 更新 PC 附件，修复阅读方向按钮的高亮显示；Android 附件沿用 2026-10-18 发布的版本。

## PC · Windows x64 1.1.38

- 阅读方向按钮只高亮当前方向的箭头，另一个箭头浅灰显示。
- 修复从右到左阅读时整个按钮变蓝的问题，切换方向后保持普通按钮底色。
- 检查雾蓝、北境、暖沙、夜色四套主题，以及双页阅读和方向切换。

PC 修复对应提交 [c195ace](https://github.com/lorcinv/OmiComic/commit/c195acedeb2666fb7c43ce55d9514e0e3f9c5aa0)，验证范围见 [Windows 1.1.38 校验记录](https://github.com/lorcinv/OmiComic/blob/main/docs/verification-1.1.38-windows.md)。

## Android 1.1.38

- 修复首次从首页进入资源库时动画一闪而过：页面准备完成后再播放圆形展开，保留原有时长和缓动。
- 去掉 Omi 图标中心的白色细描边，保留外圈、眼睛和交互。
- 检查首次进入、返回、再次进入、动画中断、后台恢复及阅读器，临时图层均能正常释放。

## 两端的 1.1.37 更新

- “最近阅读”改为普通时钟图标，去掉箭头。
- PDF 引擎按需加载，EPUB 无需加载 PDF 模块。
- 修复 PC 保存失败后的内存状态残留，以及取消打开 PDF／EPUB 后迟到的原生会话未释放问题。
- 安卓归档索引增加路径长度和文件名总量限制。

两端构建、回归测试及安装包校验已完成。安卓运行验证使用 Android 15 模拟器，未做实体手机测试。详细范围见 [1.1.37 双端校验](https://github.com/lorcinv/OmiComic/blob/main/docs/verification-1.1.37.md) 和 [1.1.38 安卓校验](https://github.com/lorcinv/OmiComic/blob/main/docs/verification-1.1.38.md)。
