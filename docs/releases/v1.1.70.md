# OmiComic 1.1.70

2026-11-02。Windows / Android 本地修复版，Android versionCode 10170。

- PC 拖入文件夹后的结果提示改到内容区顶部。
- 资源库中显示“xx 项”的合集文件夹不再提供资源信息、加入书架或加入收藏；资源库右键菜单取消打开路径，补上选择文件。
- 进入选择模式后，右键统一显示全选、取消全选和退出选择。书架根层及内部资源均提供选择入口；根层支持批量选择和删除确认。
- PC 书架菜单取消编辑备注，临时存放菜单取消打开路径。
- 修复 WebP 缩略预览：系统解码不支持的格式在独立缩略图进程中使用浏览器解码。JPG/JPEG、PNG、WebP、BMP、GIF 的散图和压缩包内预览均检查。
- 手机预览条保留已解码的小图，在原生预览层更新或被回收后仍可显示；拖动停止后同步虚拟列表位置，避免快速跳页后只剩背景。
- PDF 当前正文完成时立即发布缩略预览，绕过旧预览队列；首次打开提前加载 PDF 组件，读取文件头与组件加载重叠进行。

验证范围见 [修复记录](../status/2026-11-02-menus-previews-1.1.70.md)。Android 使用专用模拟器验证，未做实体手机测试。
