## 本版更新

Windows 1.1.1 调整阅读设置入口和资源详情布局。

- 页面排序、翻页间隔、滚动速度移到左下角「设置 → 阅读器」。阅读器顶部移除设置齿轮，保留画面调整与播放 / 暂停。
- 配置依然按每本漫画保存，可在总设置中选择书籍。优先选中详情页漫画，否则使用最近阅读的漫画；重排保留图片、书签与续读位置。
- 详情页重命名、删除放在底部左侧，与返回按钮水平对齐，使用相同圆角磨砂样式。
- 添加标签跟在所有标签最后，空间不足自然换行，颜色和尺寸统一。
