# OmiComic 1.1.58

> 2026-10-31 更正：用户确认本版普通图滤波变糊，画质平衡验收结论撤回。请使用 [1.1.59](v1.1.59.md)；本文保留历史说明。

2026-10-31。本版采用“先显示、轻滤波、当前可见细节优先”的策略。

- **大图详情预览**：修复 PC 大图缩略图出现感叹号；目录图片和压缩包图片统一使用后台系统缩略图，重复请求合并并缓存小图。
- **打开路径**：PC 资源库、最近阅读、收藏、书架内资源和书签右键菜单均可进入资源所在目录，与手机入口一致。
- **阅读交互**：最近阅读先打开后更新顺序；单／双页放大后静止点击继续翻页，移动后仍是平移。
- **速度与画质**：普通图片使用较短的滤波核保留抗摩尔纹能力；大图跳过全图自定义重采样。PC 拖动保留已有画面，新页继续预读；手机放大细节和可见预览独立调度。
- **兼容上一版**：保留混合文件名页码校准、连续详情缩略滚动、页面身份和书签映射及原始图片。

本地交付目录：`release/OmiComic-1.1.58-本地版/`。Windows 安装包、Android APK、源码快照和交接包统一标注 1.1.58；旧版本保持原位。本轮没有提交、推送或上传 GitHub。
