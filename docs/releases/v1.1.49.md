# OmiComic 1.1.49 · Windows / Android

本次继续优化两端打开漫画时的加载流程，并修复 PC 阅读加载闪现与首次随机数量不足的问题。

- **双端减少重复读取**：打开漫画时，清单、阅读设置和进度一起准备，减少额外等待；PC 不再为阅读初始化重复读取整份资源库资料。
- **PC 阅读衔接**：提前准备阅读界面，当前单页或双页图片就绪后再进入阅读，改善首次打开及返回后重新进入时短暂出现加载框的情况。
- **PC 全景拖动**：修正实时位移与重绘的衔接，按屏幕物理像素对齐，稳定页面合成；修复窗口最大化时横向、纵向慢拖中的闪烁和颤动。
- **首次随机补齐**：大量文件夹首次扫描时，保留已显示的随机卡片，继续补足本批数量，无需再次点击“重随机”；补满后继续扫描也不会打乱这一批。
- **PC 拖入提示**：拖入和添加结果提示在右侧内容区居中，随全局字号同步缩放，去掉提示末尾句号。

两端统一为 1.1.49。继续保留封面缓存、增量搜索、Android 原生解码，以及已有的预加载和内存限制。PC 拖入目录、主界面开关和离线操作说明继续提供。

Windows 提供安装包和完整免安装 ZIP；Android 使用原签名，可覆盖升级。源码和 SHA-256 校验文件随附件提供。
