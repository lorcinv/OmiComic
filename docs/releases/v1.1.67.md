# OmiComic 1.1.67

2026-11-01。本地版本；Windows x64 / Android 均为 1.1.67，Android versionCode 10167。

- 优化已开启全景连环画的漫画开书：只运行全景可见页读取，先确定当前页尺寸再补齐真正可见的邻页，减少无关双页和重复初始化等待。
- PC 先进入阅读界面，首屏图片适配、解码完成后整组显示，避免加载卡片闪现和双页先后出现。较慢读取仍有延迟提示，错误与重试保留。
- 修复手机拖动全景进度条时原生画面停在旧位置的问题：目标页及时获得读取优先级，手指按住期间已准备好的清晰图片按目标位置显示。
- 设置名称改为“默认开启全景连环画模式”。确认新建数据默认全景关闭、单页、从左到右；保留已保存的全局和单本选择。
- 检查代码模块和开书链路，合并全景重复读取及初始化时重复的系统全屏请求。保留手机进入动画、原图画质、缓存预算和文件格式支持。

验证结果、模拟器前后数据及后续优化空间见 [本版修复与结构检查](../status/2026-11-01-reader-1.1.67.md)。模拟器数据不等同于真机开书时间。
