# OmiComic 1.1.71

2026-11-02。Windows / Android 本地修复版，Android versionCode 10171。

- 手机阅读预览条松手即对齐当前页，取消停止后再次回中的动画；慢速页面回报和双页配对不再把预览拉回旧位置。
- 对照 1.1.49 恢复缩略预览原位置的翻页样式：PC 左右箭头和页码，手机左右箭头、页码跳转及原有浮动控件。两端都能连续滚动，页码跟随位置更新，翻页只定位，不切断预览列表。
- 手机“加入书架”改为底部弹层，依次显示搜索、单列分类、书架和两个新建按钮；分类区域加大，分类与书架均直接上下滑动，不显示右侧拖拽条。
- 从“加入书架”新建分类或书架时，两端都留在原页面，保留待加入的资源；新建操作统一称为“新建书架分类”。
- PC 两个新建按钮与分类、书架面板使用一致的背景、边框和圆角。
- 拖入结果、成功和错误提示统一对齐内容区顶部并保持同宽，多条提示略微错位叠放；后一条在前一条关闭或消失后才开始计时。手机使用同一规则。

旧版本安装包保留。本版仅作本地交付，未提交、推送或公开发布。验证记录见 [预览与书架交互修复](../status/2026-11-02-picker-previews-1.1.71.md)。
