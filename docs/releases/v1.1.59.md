# OmiComic 1.1.59

2026-10-31。本版修复 1.1.58 的画质退步，并梳理正文解码、滤波、缓存、预读和放大补图的衔接。

- **清晰度**：删除软化细字的高斯方案；普通图使用统一的 Lanczos 滤波。PC GPU 与软件处理采用相同权重，Android 原生 PNG 与逐行 PNG 共用同一处理实现。
- **翻页**：PC 相邻页组整组预读；画面真正准备完成再交接，避免回翻重复处理和滤波闪烁。
- **大图**：保留原图与有界可视区域路线；Android 放大优先补当前细节，不再因无效滤波级别变化重复解码。
- **缓存**：Android 排除旧模糊派生缓存，保留阅读记录、书签和源文件；高清区域从原有预算中优先分配内存。
- **原有修复**：保留大图详情预览、打开路径、先打开后刷新最近阅读、放大点击翻页、混合页码排序和详情连续滚动。

Windows 安装包和 Android APK 均为 **1.1.59**，Android versionCode 为 **10159**，放在独立目录 `release/OmiComic-1.1.59-本地版/`。旧包保留，没有提交、推送或上传 GitHub。Windows 本地安装包没有数字签名；Android 沿用原签名。

详细根因、实际测量、测试环境和接手方式见 [协同交接报告](../status/2026-10-31-reader-1.1.59-handoff.md)。Android 真机和长期内存压力仍需复核；本机测试不代表所有文件都能瞬开。
