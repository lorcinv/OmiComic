# OmiComic 1.1.10 工作报告

日期：2026-10-14。本轮完成手机侧栏、页面切换、数字排版、自动阅读与雾蓝底色的 8 项调整。

## 修改结果

| 反馈 | 修改结果 |
| --- | --- |
| 1. 侧栏卡顿、划回后闪烁 | 关闭动画结束后保持滑出位置，直到面板移除，修复中间一帧回到原位的问题。缓存目录树在首帧呈现；冷查询延后至滑入结束，索引写入合并处理。滑动只更新面板位置，遮罩独立淡入淡出，不做背景模糊。 |
| 2. 点击漫画先弹出文件名 | 手机不再创建全局悬浮提示，也不再显示「正在打开文件名」浮层；点击资源直接进入阅读。 |
| 3. 层级切换闪现加载文字 | 目录读取期间保留当前列表，新目录准备好后切换；移除手机首页、目录、阅读设置和阅读页面的瞬时加载文字。 |
| 4. 数字与日期排版 | 普通卡片显示 `10/12 · 83% 0.4MB`，圆点两侧留空格。首页最近阅读去掉「页」，其余布局保留；书签页码与创建日期同排。 |
| 5. 右到左阅读的两端数字 | 右侧显示当前页，左侧显示总页数；切回左到右时同步恢复。双页继续使用当前页范围。 |
| 6. 播放按钮未居中 | 固定按钮点击区域，使 SVG 图标中心与进度轨道中心对齐，播放按钮保留在最右侧。 |
| 7. 手机自动播放行为 | 点击三角形后显示双竖线，工具栏保持可见。点漫画、手动翻页和拖进度不会关闭自动阅读；操作手势与打开设置期间临时停留，结束后继续。再次点击按钮停止并恢复三角形。另修复「打开设置后进入后台，回来重新播放却不动」的状态残留问题。 |
| 8. 雾蓝阅读底色 | 主背景改为柔白 `#f8f8f7`，阅读背景改为少蓝的微暖中性白 `#efefed`。北境保留冰雪蓝灰，暖沙保留沙褐色系；继续使用纯色底板。共享主题同步到 PC。 |

自动阅读在离开阅读界面、进入后台、页面出错或到达结尾时仍会停止；重新进入不会自行启动。PC 保留手动操作后暂停的原有规则。

上一版的漫画页面磁盘缓存、独立读图队列、预加载设置与 50% 无模糊拖拽预览继续保留。本轮没有修改漫画解压或页面缓存算法。
