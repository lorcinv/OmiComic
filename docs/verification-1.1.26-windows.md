# OmiComic Windows 1.1.26 工作报告

日期：2026-10-17。本轮按提供的五张截图修正 PC 界面，已生成并验证 Windows x64 免安装包。

## 修复结果

| 对应需求 | 完成内容 |
| --- | --- |
| 1：主界面“选择”按钮颜色 | 修正旧样式覆盖问题。“选择”、标签、排序、视图和刷新现在使用相同的普通按钮颜色。 |
| 2、6、10、11：主题同步 | PC“雾蓝”更名为“雾灰”，采用冷白背景、浅灰蓝普通按钮，继续阅读、新建书架等关键操作保留蓝色。资源库、详情、阅读器、设置及主题预览同步。 |
| 3：书架分类光效 | 选中分类改为浅色上下渐变，移除深蓝实线、内阴影和强光晕。 |
| 4、6：书架图标与左缘 | 默认书架图标线条变细；卡片左缘改为同色系浅灰。 |
| 5：中键拖拽提示 | 提示位于目标卡片外侧，左右同时显示，浅色、上下宽、中间窄。书架和资源卡片共用该样式；鼠标所在左右半区仍决定插入前后。 |
| 7：详情标签和简介 | 改为与背景同色系、略深的灰色区域，标签使用灰色底和灰蓝文字。 |
| 8：详情文字 | 顶部只显示“文件夹”等资源类型，删除重复总页数。“共 xx 页”移到“缩略预览”同一行，删除点击操作说明；电子书继续按章计数。 |
| 9：阅读器颜色与分隔 | 移除雾蓝专属的米黄色覆盖。阅读区使用主题灰色，上下工具栏使用同色系浅色，并以细线分隔。文件名属于顶部栏，和按钮栏之间的细线从中间向两侧变淡，两端仍可见。 |
| 12：默认阅读说明 | 删除默认阅读页的长段说明，保留开关和下拉设置。 |
| 13：阅读器设置 | 删除“当前漫画”下拉选择、“每本漫画的阅读设置”组标题，以及截图中的三段解释文字。将“切换按钮背景透明度”更名为“上/下一篇按钮透明度”。 |

页面排序、翻页间隔和滚动速度仍可使用。在详情页打开设置时作用于该漫画，从资源库打开时作用于最近阅读的漫画，原有按本保存的设置继续沿用。已实际调整“上/下一篇按钮透明度”到 60%，确认保存到换书按钮对应设置。

同时修复了主按钮悬停时被普通按钮颜色覆盖的问题，关键操作在悬停时仍保持主题强调色。

## 雾灰配色

| 用途 | 色值 |
| --- | --- |
| 冷白背景、阅读器上下栏 | `#f6f7f9` |
| 面板 | `#fcfdfe` |
| 普通按钮 | `#f0f3f7` |
| 普通按钮悬停 | `#e5eaf1` |
| 关键操作 | `#4c73ad` |
| 阅读区域 | `#eef0f3` |

北境、暖沙和夜色也通过同一套颜色角色同步各个界面。保留 `mist` 等已有主题标识，旧版选择雾蓝的用户打开新版即使用雾灰。漫画图片和封面本身不受主题颜色影响。
