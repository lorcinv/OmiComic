# 主题配色（Windows 1.1.26 / Android 1.1.23）

2026-10-17：PC 将“雾蓝”调整为“雾灰”，保留 `mist` 标识，已有主题设置自动沿用。冷白背景为 `#f6f7f9`，浅灰蓝普通按钮为 `#f0f3f7`，关键按钮为 `#4c73ad`，阅读区域为 `#eef0f3`。详情标签、简介和设置分组使用同色系灰色。阅读器上下栏使用主题背景，与阅读区以细线分隔；顶部按钮与文件名之间的细线中间清晰、两端较淡。分类和卡片拖拽仅局部使用浅色渐变。四套主题共享这些颜色角色，设置里的主题预览也使用实际色值。Android 沿用原配色。本轮验证见 [1.1.26 工作报告](../verification-1.1.26-windows.md)。

2026-10-16：PC 资源卡片与手机共用四套主题和信息排布。标题、页数、详情三点、悬停及焦点状态使用语义颜色；收藏为无底框白色爱心，收藏后使用主题收藏色，以保持封面上的辨识度。卡片移除标签与路径，进度条贴底。阅读进度浮层、文档保存错误边框与外部打开错误阴影也改用主题变量。各主题的资源库、详情、弹窗、设置分类和阅读工具验证见 [Windows 1.1.24 工作报告](../verification-1.1.24-windows.md)。

2026-10-14：主题底色、详情页、阅读区和控件采用纯色，不使用背景渐变。PC 与 Android 使用同一套语义颜色，分别定义背景、表面、文字、强调、控件、边缘、阴影和状态色。移除了旧样式中 450 处只对深色生效的 `light-dark()` 分支，标签、按钮、输入框、弹窗与设置分组不再保留固定的绿色、黄色。

| 主题 | 视觉方向 | 背景 / 面板 | 强调色 |
| --- | --- | --- | --- |
| 雾蓝 | 柔白纯色底，柔和蓝色按钮和边缘；阅读底色 #efefed，减少蓝调 | #f8f8f7 / #ffffff | #4b669b |
| 北境 | 冰雪蓝灰纯色底，蓝灰按钮，无绿色倾向 | #e2e8f2 / #f4f6fa | #4f658b |
| 暖沙 | 纸张米白、沙褐边缘，不混入绿色 | #f3efe9 / #fdfbf8 | #806247 |
| 夜色 | 保留原有深蓝黑底，冰蓝按钮与标签 | #2e3440 / #363e4c | #88c0d0 |

配色参考 [Nord 官方色板](https://www.nordtheme.com/docs/colors-and-palettes/) 的冰雪与深海层次，以及 [Atlassian 的颜色角色](https://atlassian.design/foundations/color) 对中性色、强调色、透明色的区分。北境在 Nord 基础上调整明度和色相以适合 Omi，并不是照搬 Nord 原色。危险操作保留红色、成功状态保留独立的成功色；普通标签不使用成功绿。所有色值均保存在应用内，运行时不访问参考网站。

审查范围包括：首页、资源库、书架分类与书架、收藏、书签、临时存放（PC）、最近阅读、详情与缩略预览、标签筛选与管理、独立标签/简介编辑、名称与删除确认、书架新建/重命名/转存、设置各分类、下拉选项、右键菜单、左右侧栏、底部操作栏、阅读工具/进度/错误提示。漫画图片及封面本身不应用主题滤镜。

手机侧栏采用 180ms 的位移动画，触摸拖动只更新合成层位置，不随手指移动反复更新目录组件；关闭后保持末端位置直至移除，避免返回时回闪。缓存目录树在首帧呈现，冷查询延后至滑入完成，索引合并写入。面板使用主题纯色，外部遮罩独立淡入淡出，不做背景模糊。系统减少动态效果开启时直接呈现。阅读拖拽预览保留 50% 面板颜色及 50% 背景可见度，漫画能透出。阅读内容隔离在底层，上下操作栏始终在跳转动画上方。

Android 状态栏、系统导航栏及系统安全边距也同步主题；深色向系统请求浅色图标，启动时先恢复上次的系统区域颜色，避免固定浅色边缘。当前 Android 15 模拟器的启动器仍会覆盖三键导航的图标颜色，此项视觉限制记录在工作报告中。

设置标识 `mist/nord/sand/night` 保持不变，旧数据直接沿用；两端显示名称统一为雾蓝、北境、暖沙、夜色。详细运行验证见 [1.1.10 工作报告](../verification-1.1.10.md)。
