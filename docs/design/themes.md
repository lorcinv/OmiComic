# 主题配色

2026-10-10：保留经典雾灰、北境雾蓝和暖砂，移除鼠尾草与柔紫，新增非纯黑的暮夜灰。色值作为本地样式保存，运行时不访问配色网站、不新增依赖。

| 主题 | 配色来源 | 主要颜色 |
| --- | --- | --- |
| 经典雾灰 | OmiComic 原有配色 | 背景 #f1f3f6，文字 #20242a，强调 #476184 |
| 北境雾蓝 | [Nord 官方色板](https://www.nordtheme.com/docs/colors-and-palettes/) 的 Snow Storm、Polar Night 与 Frost | 背景 #eceff4，文字 #2e3440，强调 #4c566a，点缀 #81a1c1 |
| 暖砂 | Radix Sand + Gold | 背景 #f2f0e7，文字 #21201c，强调 #71624b |
| 暮夜灰 | Nord Polar Night + Frost，面板明度按 OmiComic 调整 | 背景 #2e3440，面板 #363e4c，文字 #e5e9f0，强调 #88c0d0，阅读背景 #292f3a |

Radix 依据其[官方配色组合说明](https://www.radix-ui.com/colors/docs/palette-composition/composing-a-palette)，使用带色相的灰阶搭配强调色；具体色值来自[官方色板源文件](https://github.com/radix-ui/colors/blob/main/src/light.ts)。Nord 的面板与细边框做了适合浅色毛玻璃的明度调整，其余表面通过透明混合生成。

主题令牌集中在 `src/styles/theme.css`；四张设置色卡以两列呈现，并与实际界面读取相同令牌。背景、面板、文字、强调、控件、毛玻璃与阅读背景同时切换。已有中性色通过 `light-dark()` 保留浅色外观并接入暗色令牌，原生控件同步切换颜色模式。首页装饰插画通过局部 CSS 滤镜协调色相与明度，漫画封面和阅读图片不加主题滤镜；暗色 EPUB 使用浅色文字与深蓝灰纸面。

`settings.colorTheme` 沿用现有设置保存接口，立即预览并写入本地应用数据；旧数据、已移除的 sage/mauve 或未知值回退到经典雾灰，其他设置保持原值。重开应用后恢复保存的配色。

封面标签、收藏、详情共用仿玻璃材质：使用主题玻璃基色作不透明底色，关闭背景模糊，以轻微明暗渐变、细边框及上沿高光模拟玻璃外观。控件不再透出封面颜色，悬停/按下保留同一材质，通过图标、文字颜色反馈。标签各自独立且底边对齐收藏按钮，现有倒角保留，无投影或内阴影。首页和其他面板继续沿用各自的玻璃样式。

回归使用暖橙/冷蓝与纯白/纯黑封面区域，对标签、收藏、详情按钮的实际截图像素取样；四套主题下，控件内部取样的最大 RGB 通道差均不超过 6，允许不同尺寸上的轻微渐变差异。同时验证共享材质、底部对齐，以及悬停和按下时背景不变，并生成样例卡片局部预览。

首页最近阅读统一在封面下方显示独立进度条，不与封面图片、缩放动画或边框重叠。图片、PDF 和 EPUB 共用相同位置及比例；有进度时保留至少 2px 的标记，小于 1% 的阅读显示“<1%”。图片绝对定位在固定封面内，避免原图尺寸撑大卡片；详情封面同步限制宽度，保留标题与操作空间。
