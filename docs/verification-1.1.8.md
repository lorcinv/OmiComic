# OmiComic 1.1.8 工作报告

日期：2026-10-14。本轮完成最新四项反馈，Windows 与 Android 同步更新；保留 Omi 的字体、圆角、图标及布局语言。

## 修改结果

| 项目 | 本轮结果 |
| --- | --- |
| 手机卡片数字 | 移除页数胶囊，改为普通文字，例如 `10/12页 83%，0.4MB`。书签日期继续单独显示；未知文件大小不显示虚假的 `0MB`，目录集合仍显示项目数量。 |
| 左右侧栏卡顿 | 侧栏进入、退出和跟手拖动改用位移动画；手指移动时直接更新面板位置，不反复刷新整棵目录。移除侧栏面板的大面积背景模糊，保留当前主题底色。保留竖向滚动、拖动回弹及系统减少动态效果设置。 |
| 两端主题 | 统一按钮、标签、输入框、边框、弹窗、下拉选项、操作栏、菜单和设置分组的颜色来源，清理旧的绿色描边、绿色标签和黄色弹窗背景。雾蓝、北境重新拉开差异，夜色保留原深蓝黑底。 |
| 手机拖拽预览 | 取消背景模糊，预览栏只叠加 35% 面板底色，后方漫画可直接透出。保持拖动呼出、点击外部关闭，不增加关闭按钮。 |
| 全景跳转层级 | 阅读内容及跳转动画放在独立底层，上下阅读工具栏始终在动画上方；进度预览位于内容上方、工具栏下方。 |

同时修复了动画关闭流程引出的返回键问题：标签管理处于选择状态时，第一次返回取消选择，第二次返回关闭侧栏，不会卡在无法关闭的状态。

## 主题调整

| 主题 | 调整后的视觉 | 背景 | 强调色 |
| --- | --- | --- | --- |
| 雾蓝 | 明亮蓝白、柔和蓝色按钮 | `#f2f5fb` | `#4b669b` |
| 北境 | 冰川灰青、较深的海青按钮 | `#dce8eb` | `#326675` |
| 暖沙 | 纸张米白、沙褐边缘 | `#f3efe9` | `#806247` |
| 夜色 | 保留深蓝黑底，按钮与普通标签使用冰蓝 | `#2e3440` | `#88c0d0` |

参考了 [Nord 官方色板](https://www.nordtheme.com/docs/colors-and-palettes/) 的冰雪层次，以及 [Atlassian 的颜色角色](https://atlassian.design/foundations/color) 对中性色、强调色和透明色的区分，再按 Omi 的界面调整。危险操作保留红色，成功状态保留状态色；普通标签不再借用成功绿。主题不会给漫画图片加颜色滤镜。

检查范围包括首页、资源库、书架与分类、收藏、书签、最近阅读、PC 临时存放、详情、缩略预览、标签管理与编辑、简介编辑、新建/重命名/删除窗口、下拉与右键菜单、设置分类、左右侧栏、底部菜单、阅读设置和画面调整。共迁移 450 处旧 `light-dark()` 样式，并清理首页残留的固定提示颜色；主题名称两端统一为雾蓝、北境、暖沙、夜色，旧设置继续兼容。

- 四套主题、PC 与手机共 168 个屏幕检查点，旧颜色和宽度溢出检查均为 0；检查了标签、输入焦点、创建书架窗口、详情及阅读设置截图。
- 浏览器全景跳转采样 36 帧，工具栏被动画覆盖 0 次；透明预览确认无背景模糊，底色透明参数为 0.35。
- 最终 Android APK 已覆盖安装并进行原生触摸、返回键、主题切换、目录复开、透明预览和全景跳转验证。目录侧栏复开新增目录读取为 0；选择状态与关闭侧栏分层返回通过；全景跳转采样 13 帧，工具栏被覆盖 0 次。
- Android 非全景连续翻页采样 183 帧，空白帧 0。输入法、设置宽度、标签与简介独立保存、外部点击关闭和目录缓存回归通过。
- Windows 最终 ZIP 已解压并运行其中的 EXE，图片、CBZ、CB7、PDF、EPUB、本地资源列表、全景方向、阅读布局、自动阅读、画面处理和大图封面检查通过。
- APK 使用原发布证书，包含 arm64-v8a、armeabi-v7a、x86_64、x86 四种原生库，16 KB 对齐和随包许可证检查通过。APK、Windows ZIP 均检查过不包含签名密钥、测试资产或用户数据；前端构建一致性、类型检查及差异格式检查通过。

验证环境为 Windows x64 和 Android 15 x86_64 模拟器，没有连接实体手机；未测实体手机帧率。侧栏优化的结论来自动画实现、跟手交互及目录读取验证。

Android 系统状态栏与安全边距已跟随主题。当前模拟器的三键导航仍存在系统侧限制：应用请求的浅色图标标志正确，状态栏图标正常，但启动器将底部三键图标覆盖成深灰。该现象在独立启动及测试运行中都可见，不能记为视觉通过。应用使用 [Android 官方的透明系统栏与图标明暗控制方式](https://developer.android.com/develop/ui/views/layout/edge-to-edge-manually)，未为模拟器改动用户系统设置；实体手机上的系统三键图标颜色仍待验证。
