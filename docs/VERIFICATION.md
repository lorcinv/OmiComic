# Windows 1.1.2 验证记录

日期：2026-10-11。交付 Windows x64 ZIP 免安装版，Android 保持 1.0.1。[1.1.1 验证记录](verification-1.1.1.md)和[阅读工具原始验证](verification-1.1.0.md)保留此前证据。

## 本轮改动

- 阅读器缩放下拉按钮从 146px 收紧为 96px，保留原有高度、圆角和磨砂样式。
- 资源库子目录按 Esc 返回直接父目录；菜单、输入、对话框和选择模式优先处理，不穿透返回。
- 只有含子文件夹或多个独立漫画文件的目录才显示“含 X 项目”；只统计子文件夹和压缩包、PDF、EPUB，不统计图片页面或无关文件。
- 资源库目录改为连续虚拟列表，页码作为完整行的定位分段。每页行数向上取整，例如 60 项 / 7 列使用 9 行、63 项。跳页定位段首，滚到底部显示末页；调整列数、窗口和每页数量保留当前项目所在行。
- 页面数量输入与滚动页码同步；资源库的选择范围覆盖筛选后的列表，已选项目不会因滚出渲染范围而丢失。
