# Verification and release checklist

This branch changes the renderer, file services and Electron runtime. It is a development candidate, not an assertion that every bug has been eliminated.

## Automated coverage

- `npm run build`: strict renderer/main/preload TypeScript, Vite renderer/assets and Electron compilation.
- `npm test`: real filesystem, ZIP/RAR/7z, EPUB worker/PDF range, image pre-decode guard, inertial physics, IPC progress validator and JSON data compatibility tests.
- `npm run test:dom`: actual React state/DOM navigation, home/recent, nested folders, tags/description, pagination and cancellation, with mocked IPC. No visual-layout or FPS claim.
- `npm run test:ui`: Chromium geometry/screenshots and actual PDF.js browser worker with mocked IPC transport. CI installs Chromium; optional `CHROMIUM_PATH` uses an installed browser locally.
- `scripts/run-pdf-stress.mjs`: real native PDF.js raster stress, separate from browser UI.

Detailed workloads and measurements: [directory/image guards](../tests/DIRECTORY_STRESS.md), [archives and licenses](../tests/ARCHIVE_STRESS.md), [documents](document-stress-results.md), [data compatibility](library-data-regression-tests.md), [runtime migration](runtime-security.md).

All fixtures are synthetic; no personal comics or user-data files are checked into the repository. Large fixtures are temporary and removed by tests. RSS readings include test setup/runtime and native allocator behavior; process RSS is not guaranteed to immediately return to baseline.

## Cloud execution limits

Local Chromium launch was attempted normally and once with approved process access, but the environment rejected required socket operations. The existing cloud browser could not reach the test server. These are environment failures before test assertions, not passing browser tests. No access restriction was bypassed. Native PDF.js/canvas tests and React DOM tests are independent coverage, not substitutes for Electron visuals, IPC or Windows native decoding.

## Windows manual release gate

- Open nested image-less parent directories, then image children; back/forward and quick root changes must keep correct paths and not show spurious errors.
- Exercise all card sizes in directory/recent/favorites/bookmarks/bookshelf. Check title clipping, cover aspect, progress and keyboard focus.
- Add/remove Unicode tags, edit long descriptions, click blank space, cancel with Escape, and reopen. Preserve old user data, favorites/bookmarks and first-read timestamps.
- Reorder bookshelf categories and items; copy/move/remove references; confirm source files are unchanged. Clean only intended invalid references.
- Single/double-page, left/right flow, horizontal/vertical panorama, long/short drags, hold/release, quick reversals, fullscreen/immersive and reduced motion.
- Open large PDF and illustrated/text EPUB; jump quickly, resize, zoom, close during first parse/render, reopen at saved position. Check actual peak memory and UI responsiveness.
- ZIP/CBZ, RAR4/RAR5/solid-RAR and 7z/CB7 with Unicode names; corrupt/password/multipart/oversized files fail clearly. Automated RAR fixtures cover stored RAR4, not every codec variant.
- Packaged ASAR must unpack the official 7-Zip executable and companion libraries with notices; test on a clean Windows machine. No installer was generated by this branch.

Keep the pull request in draft until native-platform review is satisfactory. Do not merge or deploy automatically.
