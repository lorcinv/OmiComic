## 主界面图案

选择 PNG、JPG、WebP 或 BMP 后，首页右侧插画换成自选图片。自选图案按原色等比显示，不套用默认插画的滤镜和渐隐遮罩。

应用在用户数据目录保存独立副本，移动原图后仍可显示。“恢复默认”只移除应用保存的图案副本，原文件不变。取消选择、选到损坏图片或保存失败时保留已有图案。

支持 20 MB 以内、4000 万像素以内的图片；保存时最长边缩至不超过 2400 像素。图片副本独立存放于用户数据目录的 `home-artwork.json`，不会混入漫画资源或阅读记录。
