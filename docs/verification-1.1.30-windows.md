# OmiComic Windows 1.1.30 工作报告

日期：2026-10-17。本轮完成首页按钮颜色同步、书架与拖拽光效调整，以及详情页窗口拖动修复。

## 完成内容

| 项目 | 修改结果 |
| --- | --- |
| 首页“我的资源库”按钮 | 底色、文字色和悬停色直接沿用资源库顶部普通控件的颜色。雾灰主题为浅灰蓝底，不再使用深色强调按钮；四套主题同步。 |
| 书架分类聚焦 | 改为上下两条浅白横杠，各向中间带少量柔光。聚焦固定在分类轨道第一位，切换时不跟随分类文字移动。 |
| 中键拖拽提示 | 改为整张目标卡片背后的明亮柔光，移除左右轮廓光带。适用于书架、书架内资源、收藏和书签；结束或取消拖拽后移除。 |
| 详情页拖动窗口 | 恢复顶部空白区域的窗口拖动能力，避开标题和窗口控制按钮，保留标题复制及按钮点击。 |

详情页问题的原因是：进入详情后，带窗口拖动能力的资源库工具栏被隐藏，而替代它的顶部空白没有定义拖动区域。本次补上独立拖动区域，不覆盖详情内容。

保留此前的首页图案裁剪与羽化预览、实时画面调整、字号设置和 PC 大图加载优化。本轮未改动 Android 成品。
