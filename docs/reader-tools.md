# 阅读器设置与画面调整（Windows 1.1.2）

本轮只增加打开漫画后的阅读功能。资源库、书架的条目排序保持原有设置。页面排序、翻页间隔与滚动速度统一放在左下角「设置 → 阅读器」。工具栏左侧按钮组末尾保留「画面调整」与播放 / 暂停，不再增加设置齿轮。

## 页面排序

打开左下角「设置」→「阅读器」→「页面排序」。

「当前漫画」优先选择已打开的详情页漫画，否则选择最近阅读的漫画；可从下拉列表切换其他已读漫画。设置仅作用于选中书籍。图片文件夹、ZIP/CBZ、RAR/CBR、7z/CB7 支持文件名自然升序（默认）、自然降序、修改时间升序、修改时间降序。文件名按 1、2、3、10 排列。

排序仅记住当前漫画，与左右阅读方向独立。PDF、EPUB 保持原有页面 / 章节顺序，设置面板不会显示无效的排序控件。

文件夹使用文件修改时间；压缩包使用条目记录的修改时间。缺失时间始终排在最后，时间相同用文件名自然升序，再按完整名称和页面标识确定顺序。压缩格式的时间精度不同（例如 ZIP 的 DOS 时间可能只有两秒精度），不会虚构缺失日期。

切换顺序时保留当前图片，为新顺序重新计算页码和双页配对。书签、续读、配对起点同时保存稳定图片标识：文件夹用图片名称，归档用完整内部路径。已有书签按图片名称迁移，只有没有名称的旧记录才按其原顺序页码迁移。返回详情后按新顺序刷新缩略图清单，并保留选中的图片。单纯重排不会改动图片、归档或书签内容。

## 自动阅读

点击顶部播放三角形启动，再次点击暂停。总设置的「阅读器」分类中可调翻页间隔（1–60 秒）和滚动速度（10–400 像素/秒），参数按本书保存。

- 普通单页按间隔翻一页，双页推进一个实际显示的页面组；跨页与窗口放不下的双页仍按原有规则处理。
- 全景连续阅读平滑滚动，横向、纵向均可用；到达长图实际末端后停止。
- 加载中的页面等待加载及显示准备完成，重新计时，不累计时间连续跳页。当前页加载失败则停止。
- 手动翻页、跳页、拖进度、滚轮、点击画面、键盘操作、切换模式或排序都会暂停。打开菜单 / 对话框、窗口失焦、最小化或后台也暂停。
- 回到窗口、重开漫画或重新启动程序都不会自行播放；末尾停止，不自动进入下一本。

阅读方向、全屏、沉浸工具栏隐藏和 ↑/↓ 切换书籍保持原有行为。面板打开时顶部栏保持可见，Esc 先关闭面板。

## 画面调整

顶部「画面调整」在同一下拉面板中提供：亮度（50–150%）、对比度（50–150%）、伽马（0.5–2）、暖色、灰度、反色、锐化和降噪。

默认关闭总开关，显示原图，所有参数为中性值。拖动参数或切换滤镜会启用效果并即时预览。取消「启用画面调整」可对比原图，参数仍保留；「恢复默认」同时重置参数并关闭效果。参数按本书保存，双页与连续阅读共用同一组效果。外部点击与 Esc 可关闭面板，拖动滑块不会误关闭。

所有效果仅改变阅读显示，不写入原文件、不更改封面或导出文件。本轮没有 AI 超分辨率。

### 锐化与降噪边界

图片和 PDF 页面使用一个后台图像处理任务，按可见页面生成显示预览。降噪使用 3×3 双边邻域，抑制小幅噪声并保留高反差边缘；锐化使用带阈值、限制增益的反差增强，限制文字边缘与网点的光晕。两者强度均可调，不能恢复原图没有的细节，也不是去网纹工具。

处理预览不放大原图，最多 400 万像素、长边 8192 像素，并按显示尺寸和屏幕密度缩小。大图在原始尺寸下开启锐化 / 降噪时，处理预览可能比原图更软；可关总开关立即对比。基础调整和颜色滤镜不采用这项处理预览降采样。

仅处理进入阅读视口的页面，离开后释放处理结果，不预处理整本漫画。快速拖动参数会合并过期请求；只有一个处理任务并行，空闲后释放 worker。处理中继续显示原图，失败或超时明确提示并回退原图。原始图片解码、PDF 页面缓存与浏览器合成仍会占用内存，400 万像素是处理预览上限，不是应用总内存上限。

EPUB 章节属于排版文档：支持亮度、对比度、伽马和颜色滤镜；锐化与降噪明确禁用。动画图片开启像素处理时显示采样静帧，关闭后恢复原动画。
