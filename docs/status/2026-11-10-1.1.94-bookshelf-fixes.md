# 1.1.94 书架返回位置与 PC 选择菜单修复

Windows / Android 版本均为 1.1.94，Android versionCode 为 10194。基于完整 1.1.93 发行基线 `bffa90e`，在 `codex/bookshelf-fixes-1.1.94` 上修改。工作树位于 `.cache/android-ui1193/worktree`，主工作区原有累计修改保留。

## 修复

- 书架内部的进入和返回复用原导航会话，保留连续列表的定位记录。侧栏“书架”从内部返回时使用同一返回路径，避免重新初始化栏目。保留资源库、收藏等栏目原有重置规则。
- 删除 PC 选择模式对整页右键事件的拦截及专用三项菜单，恢复卡片和空白区域各自的原菜单。全选、取消全选和退出选择继续由原选择操作栏提供。
- 保留已有批量整理逻辑：右键选中资源时，加入书架、收藏、移动和复制继续根据当前选择处理。

## 验证

- `npm run verify` 整条命令退出码为 0：两端共享 TypeScript 与 Windows 构建通过，核心检查 148 通过、1 项原有跳过，55 个文件的 305 项 DOM 检查通过。
