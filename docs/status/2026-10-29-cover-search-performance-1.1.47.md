# OmiComic 1.1.47 封面与搜索优化记录

日期：2026-10-29。基线为已发布的 Windows 1.1.45 与 Android 1.1.46，本次两端统一为 1.1.47。

## 检查结论与实施

| 范围 | 发现的开销 | 本次处理 |
| --- | --- | --- |
| PC 封面调度 | 仍使用整批 effect；滚动或搜索追加导致整批退出，保留在窗口内的工作也被重建。队列从虚拟窗口起点开始，可能先处理可见卡片之前的预加载内容。 | 复用手机已有的持续需求队列，保留重叠任务；PC 仍六路，Android 仍两路。PC 可见卡片优先，然后处理附近两行。 |
| PC 请求复用 | 前端只共享进行中的压缩包封面，文件夹和 PDF 等请求可能重复。 | 所有 PC 封面按路径、类型和版本共享进行中的请求；刷新切换请求代次。 |
| PC 跨重启缓存 | 文件封面只有进程内缓存，重启需要重新解码。 | 图片、压缩包、EPUB 增加磁盘缓存，按源文件 mtime、ctime、size 校验；保留 240 项内存缓存，磁盘按 128 MiB／2048 项预算清理。缓存损坏或文件变化回退生成。文件夹仍读取当前目录，避免仅凭父目录时间复用失效子封面。 |
| 两端封面显示 | 视口队列已经限制需求，生成后的卡片图片又标记浏览器懒加载，形成第二层显示等待。 | 已生成的卡片封面直接加载；保留虚拟窗口、图片尺寸限制和队列预算。详情页的大量预览未改为全量加载。 |
| 两端搜索 | 增量命中已经追加，但每次快照仍完整遍历旧记录、核对已有命中及缓存。 | 目录发布新增／修改／移除的增量，搜索连续消费增量；条件变化、漏过快照或任务中断时完整核对。快照身份不持有上一份完整数组，避免积累旧快照链。Windows 仅大小写变化的改名也替换旧命中。 |
| PC 搜索调度 | 已经保存的目录摘要也被封面前台忙碌条件挡住。 | 允许有限批次重放已有摘要；实际磁盘目录扫描仍为前台读取让出资源，逐次授权检查保留。 |
| 两端页数统计 | 全部项目都已有页数时，原逻辑反而重新统计整个需求窗口。 | 按资源版本复用未变化页数；源文件变化或手动刷新重新核对。 |

没有替换 Android 的原生阅读器、SQLite／URI 定位、原生封面磁盘缓存、可取消分片扫描或生命周期处理；没有将手机并发预算套到 PC。

主要文件：`src/hooks/useMobileCoverQueue.ts`、`src/reader/thumbnailClient.ts`、`src/library/catalogSnapshot.ts`、`src/library/progressiveSearch.ts`、`src/library/libraryCatalog.ts`、`src/pages/LibraryPage.tsx`、`electron/services/thumbnailDiskCache.ts`、`electron/services/thumbnailService.ts`、`electron/services/libraryCatalog.ts`。

## 前后测量

### Windows 实际程序

同一台开发机、相同 8 本 CBZ、1440×960 窗口，各使用独立配置目录。计时从真正点击主页资源库按钮开始，到前六张卡片图片完成加载；另在真实 IPC 处理器记录封面结果返回时间。重启组使用同一测试配置，完整退出进程后再启动。

| 项目 | Windows 1.1.45 | Windows 1.1.47 |
| --- | ---: | ---: |
| 冷应用缓存，前六张显示 | 1078 ms | 137 ms |
| 进程重启后，前六张显示 | 1090 ms | 110 ms |
| 重启后，前六张原生封面结果返回 | 46 ms | 11 ms |

这是隔离的隐藏窗口测试；旧版浏览器懒加载产生的等待是显示差异的主要部分，不能据此声称图片解码算法本身加速八倍。新版本冷生成结果约 47 ms，与旧版约 43 ms 相近；跨重启的原生结果提速来自持久缓存。实体前台窗口和不同磁盘仍可能有不同耗时。

原始结果：`output/performance-1147/covers-before.json`、`covers-after.json`。复核入口为 `tests/performance-1147.electron.cjs`。

### 搜索增量处理

同一开发机直接运行搜索模块：初始 20,000 条，随后追加 50 批，每批 128 条；查询、比较器和初始数据一致。

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 50 批追加处理 | 140.2 ms | 15.7 ms |
| 追加期间再次访问旧记录 | 1,156,800 次 | 0 次 |

这些时间是 JavaScript 匹配与发布耗时，不包括磁盘发现、桥接传输、界面绘制，也不代表实体手机的全库搜索耗时。删除、元数据编辑、查询变化或不连续快照仍需要相应核对。

### Android 原生模拟器

Android 15 专用模拟器，同一授权测试库、清除封面缓存后，六张封面为 1.1.46 的 2487 ms 和 1.1.47 的 2380 ms。两轮目录缓存命中状态不同，这组数据只支持封面可正常加载及未见明显回退，不作为严格速度提升结论；手机端主要收益为减少搜索旧记录遍历和重复页数请求。
