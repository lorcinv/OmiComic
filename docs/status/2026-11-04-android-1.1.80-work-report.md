# OmiComic Android 1.1.80 工作报告

2026-11-04，Asia/Hong_Kong。Android 版本 1.1.80，versionCode 10180；Windows 安装包保持 1.1.78。

## 本轮结果

本轮九项问题均已修改，并完成浏览器、安卓模拟器和手机尺寸回归。使用了你放在 `D:\下载\手机` 的三本原文件。华为 MatePad 11 与 OPPO 平板尚未实机复测。

| 项目 | 原因与修复 | 验证结果 |
|---|---|---|
| 1. 首页底栏比例、资源库按钮 | 上轮统一导航样式覆盖了首页按钮，平板规则又把三个按钮等分。恢复 **1.8∶1∶1** 的原比例；“进入资源库”保持主题深色实底，横竖屏使用同一规则。 | 手机、平板横竖屏检查比例和按钮底色通过。 |
| 2. 阅读菜单短横条与图标太近 | 增大短横条的预留区域，并增加下方间距；保留下拉关闭与回弹手势。 | 安卓三个尺寸均检查短横条与首排按钮的距离不少于 16px；原菜单手势回归通过。 |
| 3. 浅色导航选中不明显 | 非首页导航的选中项改用主文字色、加粗文字和图标；未选中项使用较浅灰色。保留无浮起阴影的样式。 | 雾白、北境、砂色三套浅色主题检查通过。 |
| 4. 文字 MOBI、EPUB 成长条并闪烁 | 原来把整章当成一张超长页面。安卓改为按行进行固定尺寸分页，正文同步排版；预览显示所在页的文字。每章第一页沿用旧标识，以便恢复旧章节位置。 | 原文字 MOBI 在模拟器中分为 615 页；长篇 EPUB 测试同样分页，连续页预览不同；实际文字样书滑动切换通过。 |
| 5.《きらめく瞳の描き方》图片不显示 | 文件用 SVG 容器引用 JPEG，原清理逻辑删除了整个容器。现在仅提取容器中的本地栅格图片，仍删除脚本、事件属性和外部引用；正文读取原图。 | 原 EPUB 的 152 页能打开，正文与详情预览有图；模拟器检查正文原图宽度超过 1000 像素。 |
| 6.《葬送的芙莉莲》缩小、预览慢和闪烁 | 纯图片页改用共享图片阅读层，采用真实图片比例，提前完成解码；图片与文字文档均在既有正文缓存预算内准备相邻页。章节和预览合并重复读取，增加有界的章节内容缓存；大 MOBI 的几百个记录签名改为安卓一次返回。 | 442,071,646 字节原文件按需读取，正文、详情预览和翻页通过；浏览器滑动前后尺寸一致，采样未出现缺少已准备内容的帧。 |
| 7. 安卓按钮没有点击反馈 | 原来隐藏了系统点击高亮，却没有补统一的按压反馈。现在增加安卓按钮按压变淡效果，快速点击后保留 120ms；滚动或取消触摸时撤销。 | 实际按压样式检查、菜单操作及阅读手势回归通过。 |
| 8. 外置盘缺失影响资源库 | 侧栏的一个子目录失败会拒绝整组结果，并显示全局错误；启动恢复目录失败时也没有尝试其他根目录。现在逐目录隔离错误、显示本目录重试；恢复失败后继续尝试可访问的根目录。 | 浏览器模拟缺失根目录和不可读子目录；安卓三个尺寸均加入缺失的上次目录，仍能进入可用目录，侧栏分别显示离线提示和有效目录。 |
| 9. 首页刷新没有反应 | 原按钮只重读内存中的阅读记录，仍沿用封面缓存，也缺少过程反馈。现在清理封面与目录索引、调用安卓封面刷新、重读最近阅读；按钮显示旋转和“刷新中…”，完成后更新状态。 | 刷新接口调用、状态变化和按压反馈检查通过。 |

另补旧 WebView 不支持独立 `translate/scale` 时的阅读位移动画回退。支持这些属性的内核继续使用原路径。

1.1.79 已有的旧内核接口补齐、PDF 兼容分支、浅色光圈、详情封面与标签描边回退、安卓滚动条隐藏继续保留。

文字页数会随浏览器字体排版出现少量差异：本轮原文字 MOBI 在安卓为 615 页，在桌面浏览器约 618 页。大 MOBI 的总页数包含漫画图页及书内文字，不能直接与旧版章节数比较。
