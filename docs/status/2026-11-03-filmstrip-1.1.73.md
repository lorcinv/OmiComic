# 1.1.73 手机预览条快速滑动修复

2026-11-03，Asia/Hong_Kong。基于 1.1.72 的累计工作区修改，编辑前快照在 `.cache/omi1173/before/`；旧包保留。

## 原因与处理

1.1.71 为了消除松手后的二次回中，将预览条改为 `touch-action:none`，由应用接管全部触摸位移，并在松手时强制定位到整页。1.1.72 修复了触摸捕获提前丢失，但仍保留这条路线，所以能拖动几页，却失去原来的快速甩动和惯性。上版的验证范围不足以证明快速滑动已恢复。

本版把触摸恢复为系统原生横向滚动，手指滑动和松手都不再由应用捕获、阻止或强制定位；鼠标拖动继续保留。页码和缩略图窗口始终跟随真实滚动位置，阅读器自己的延迟回报与双页配对不发起二次居中。主动拖动进度条、点击缩略图、预览尺寸变化仍能明确定位到指定页。

功能改动限于 `MobileReaderPreviews.tsx` 和预览条的一条样式规则。PDF、MOBI、封面缓存、PC 翻页和书架等功能沿用 1.1.72。

## 验证方法

- 在已交付的 1.1.72 Android APK 上复现：90 ms 快速滑动仍被应用接管，未触发原生滚动接管，松手时调用 `scrollTo`，位置从约 4051 回到 4032。记录保存在本版验证目录的 `android-baseline.json`。
- 新增 Android 原生输入专项，分别使用 100 页 CBZ 与 100 页合成 PDF，检查快速甩动后的惯性位移、连续快速滑动、反向滑动、停止后 650 ms 的位置稳定、最终阅读页与预览一致，以及选中缩略图实际解码。原生滑动测试是惯性的验收依据。
- 最终 APK 的两种资源均通过全部手势检查。90 ms 快滑后，CBZ 在松手位置之后继续滑行约 1518 个逻辑像素，PDF 约 1567 个逻辑像素，均约 16 页；整次滑动约 18 页。各自 4 次快速及反向手势期间，应用主动定位次数均为 0。停稳后 650 ms 位置不变，阅读页与最终所选预览一致。这是模拟器上的样本结果，实际惯性距离由设备与手势决定。
- 浏览器专项检查原生触摸接管、取消强制定位、停顿后松手、不回弹、400 ms 延迟回报、双页配对、连续与反向滑动、主动进度跳转、首尾页和鼠标拖动。浏览器基础触摸注入在普通滚动容器中也没有生成惯性，因此不把其结果冒充手机甩动验证。
- 类型检查和构建通过；完整 DOM 回归 212 项通过；浏览器专项 17 项通过，包含预览条、预览加载取消、两端 PDF 翻页及既有相关操作。
- Windows 从本版安装程序提取后运行，12 组检查通过；Windows / Android 包内渲染文件与构建输出逐一核对。
- 最终 Android 实测数据与截图以交付目录 `verification/` 和 `verification.json` 为准。测试使用独立 Android 15 模拟器，未进行实体手机测试。
- 模拟器软件渲染器在安装期间崩溃，切换为宿主渲染后完成最终检查；最终 APK 使用完整流式安装，安装文件哈希与交付文件核对。
