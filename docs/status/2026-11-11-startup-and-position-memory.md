## 实现

启动页采用共享校验规则，并接入 Windows JSON 设置和 Android 原生设置保存。初次加载资源库后进入所选栏目；外部文件打开仍优先，Android 启动遮罩等待目标栏目准备完成。

连续列表使用稳定的栏目、目录、布局和查询身份保存可见资源及行内偏移，去掉会随导航变化的计数。各栏目不再夹带其他栏目的文件夹标识。书架位置在恢复前核对分类和文件夹是否仍存在。普通滚动面板共用位置恢复逻辑，等待异步内容具备足够高度后再恢复，避免加载中的零位置覆盖已保存记录。

浏览位置保存在本机界面存储中，滚动时批量写入；导航层级变动立即写入。Android 同时写入独立的原生原子文件，并在界面挂载前恢复，避免 WebView 在退出时丢失最后一次浏览器存储提交。窗口关闭、页面退出、切入后台和 Android 暂停时刷新。此类界面位置不包含在漫画数据备份中。
