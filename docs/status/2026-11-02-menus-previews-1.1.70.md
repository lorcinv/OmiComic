# 1.1.70 右键规则与缩略预览

2026-11-02，Asia/Hong_Kong。基于 1.1.69 继续修改，累计工作区与旧交付保留。

## 修改

- PC 拖入结果提示顶部 64 px，继续对齐内容区中央。
- 资源库根据实际缩略图的 itemCount 识别合集文件夹，与“xx 项”的外观一致；不显示资源信息、加入收藏和加入书架。取消资源库打开路径，增加选择文件。
- 选择模式在库页面捕获右键，统一提供全选、取消全选、退出选择；书架根层增加独立选择状态、批量删除确认、Ctrl+A 和 Escape，内部沿用资源选择。
- 移除 PC 书架编辑备注入口，临时存放不提供打开路径。
- desktop nativeImage 失败后，在隔离的缩略图进程使用 createImageBitmap 解码，输出最长边 360 px 的 PNG。文件授权、原图显示及正文读取路径保留。
- 手机原生预览仍可短时复用已显示页；同时从现有小图服务取得有界缩略图，完成后由 WebView 保留显示。虚拟列表拖动状态改为可触发呈现更新，计算中心时限制在当前书籍页数内。
- PDF 缩略图订阅对应正文页的完成事件。已就绪的正文缩小成预览后直接交付，取消旧队列中的对应请求；32 张小图限制保留。
- 开书意图到来时提前导入 PDF runtime。原生打开后立即读取最多 256 KiB 文件头，与 runtime 加载重叠，作为 PDF range transport 的 initialData；不改变正文分辨率或阅读缓存预算。
