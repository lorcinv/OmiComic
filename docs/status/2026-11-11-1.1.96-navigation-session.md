# 1.1.96 浏览位置与重复点击导航修正

用户明确修正为：只记本次使用期间的位置；软件重启后各处回到顶部；再次点击当前导航栏，返回该栏目顶层顶部。Windows / Android 统一为 1.1.96，Android 版本码 10196。基于 v1.1.95，在 `codex/navigation-session-1.1.96` 完成。

## 实现

- 浏览位置仅保存在当前运行的内存中，应用启动时建立新会话；不再读取或写入旧浏览器与 Android 原生位置文件。旧记录不会带回上次位置。
- 启动仍遵循用户选择的栏目，资源库从当前库的根目录开始，书架从顶层开始；文件夹、列表、网格、设置、详情与标签列表的滚动位置从零开始。漫画阅读进度和应用设置继续正常保存。
- 重复点击当前导航栏时记录“主动返回顶层”的意图，等待目标目录和连续列表准备完成后重置目标列表的定位。资源库返回根目录，书架返回当前分类顶层，收藏、书签、最近阅读及 PC 临时存放回到顶部。
- 普通返回和跨栏目切换继续恢复本次位置。重选导航只重置目标顶层，书架和文件夹内部本次已记住的位置仍可在再次进入时恢复。
- 更新三语内置说明、导出的使用文档及版本页面。
