# OmiComic 1.1.42 Android 验收

2026-10-28。结论：本轮 Android 15 模拟器原生验收通过，七组运行测试全部成功，未发现需要修改应用的新问题。按用户追加要求移除了 PC 与 Android 的资源清单补全提示，双端重新构建；最终 APK 的七组原生测试再次全部通过。

## 环境与升级

- Android 15 / API 35 / x86_64，1080 × 1920、420 dpi；官方模拟器 37.2.12，专用测试 AVD `OmiRegression1141`，设备号 `emulator-5680`。
- 通过独立、同签名的测试 APK 驱动发布 APK，使用真实 Android 触控、输入法、返回键、SAF 文件提供器和原生阅读显示。
- 从原有 1.1.41 覆盖安装到 1.1.42 / versionCode 10142。安装前后应用数据文件逐字节相同；原有一个目录授权、一个收藏及备注保留。
- SQLite 已实际升级到版本 3。强制停止后重新启动，目录授权、收藏、PDF 与 EPUB 的第二页进度保留。
- APK SHA-256：`cd3f4cfab752037b2346823c02ef96e248dbf1eddd291b9937cdc5bbe40972db`。

此前连接失败的原因已查明：Windows 当时预留了 `5510–5609`，覆盖此前尝试的 5554、5560、5580 等端口。改用可绑定的 5680 后连接成功。没有调整系统网络设置。端口预留范围可能随 Windows 环境变化，后续运行以实际可绑定端口为准。

应用运行日志中没有发现本轮测试的 `FATAL EXCEPTION`。原生计数包含扫描查询、摘要命中、传输字节、持锁累计时间、URI/目录索引命中和 Java/原生堆采样。堆采样不是峰值，也不涵盖 WebView 全部内存；本轮没有完成十万条资源的 Android 内存压力测试。

测试开发中修正了两处测试程序问题：JSON 空值解析和截图文件名大小写。对应测试修正后重跑成功，应用原生文件访问与阅读实现未改动；界面按追加要求仅移除那条补全横幅，并删除对应多语言文案。PC 浏览器回归及最终安卓包均确认已有结果可继续浏览且横幅不显示。

最终扫描复验期间，Windows 安装包也在同机构建。表中耗时为该轮实际采样；首轮较空闲环境的数据保存在 `output/android-1142-acceptance/initial-native-run/`，未将两轮当作严格性能对比。

## 证据与复跑

汇总及七组原始结果：`output/android-1142-acceptance/acceptance-summary.json`。同目录保存升级前后数据、运行日志、ZIP/PDF/EPUB 截图与锁屏录像；这些本机证据不进入源码分发包。

复跑入口为 `scripts/test-android.ps1`，需要已启动的专用测试模拟器和匹配的测试目录。新模式为 `catalog1142`、`acceptance1142`、`provider1142`、`formats1142`、`restore1142`；本轮明确传入 `-Serial emulator-5680 -ExpectedVersion 1.1.42`。格式样本由 `tests/android/mobile1116-fixtures.py` 生成，放在测试授权目录的 `Formats116` 子目录。`restore1142` 接在格式测试和强制停止之后，用于检查真实进程重启。

本轮结果适用于上述 Android 15 模拟器。实体手机、ColorOS、平板原生环境、长时间锁屏和低内存设备尚未实测；不据此关闭这些条件的验收项。
