# 1.1.76 标签、数据管理与临时目录验证

交付：`release/OmiComic-1.1.76-标签与数据管理版/`。Windows 与 Android 为 1.1.76，Android versionCode 为 10176。

## 完成范围

- 新增标签联想限定在输入框左右，横向滚动、渐隐边界、隐藏滚动条；PC 支持滚轮和鼠标拖动，手机支持手指滑动。
- 标签管理使用拖动落点提示和选择模式微动；选中直接点亮，只有删除按钮使用红色。
- 快速标签复用标签管理的标签样式，移除分区大框，用细线分隔；上方按已有标签数量收紧。加入、移出使用单折角方向图标，两端标题和列表左缘对齐，手机成对按钮平分整行。仅分配现有标签。
- 设置 → 数据管理：平台和日期时间命名的 JSON 导出、格式校验、导入预览、合并/替换、冲突选择、导入前备份和恢复。跨平台保留设备专用设置。
- 目录先自动检查原路径，再用本机已授权目录中的少量相对路径寻找唯一候选；不枚举整库或读取漫画内容计算指纹。无候选、多个候选时保留记录并允许补配。目录匹配不校验漫画文件版本。
- PC 临时存放和两端最近阅读可临时浏览目录；Android 文件单独授权不足时选择目录授权，不要求保存为书库。PC 最近阅读的库外记录可右键加入所在目录。临时浏览和临时记录导入均不会自动添加资源库目录。
- 软件内操作说明与三语文档同步。原有阅读画质、默认缓存预算和进入动画没有调整。
