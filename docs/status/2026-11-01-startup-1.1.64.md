# 1.1.64 启动与开书准备优化

2026-11-01，Asia/Hong_Kong。基于本轮编辑前的 1.1.63 工作树，包括 PC 提示优化和 Android 显示优化；不以较早的 Git HEAD 覆盖累计修改。编辑前快照与实验放在被忽略的 `.cache/startup-1164/`。

## 修改范围

- `App.tsx`：首页手机设置原先静态引用设置、使用说明和漫画设置。改为打开设置时同时取得两个组件及最新资料，全部就绪后执行原有转场；失败可以重试。PC 首页不再为这个入口提前加载对应模块。
- `reader/loadReader.ts`：复用阅读器模块加载任务，加载失败后允许下次尝试。`HomePage.tsx` 与 `LibraryPage.tsx` 在开始读取漫画清单时预热该任务；`App.tsx` 保留原有空闲预热，并在真正打开时等待同一任务。尚未读完的清单不会提前进入阅读器。
- `main.tsx`：Android 文件接口模块和原生连接同时准备。仍等原生连接成功后才创建接口、读取资料与挂载应用。
- 版本：Windows / Android 1.1.64；Android versionCode 10164。

本轮生产代码只增加一个模块、修改上述四个文件。没有调整阅读器页面、图片解码、滤波、清晰度、内存或预读预算、目录排序与文件格式读取实现。版本与交接文件另行更新。

## 测量条件与结果

| 项目 | 编辑前 | 1.1.64 | 条件 |
| --- | ---: | ---: | --- |
| PC 首屏入口脚本 | 382,690 字节 | 约 295,760 字节 | Vite 正式构建，未压缩传输，减少约 22.7% |
| PC 首屏入口脚本 gzip | 约 133.16 KB | 约 100.43 KB | 构建工具估算，减少约 24.6% |
| 普通本地漫画开书中位数 | 70.6 ms | 70.2 ms | 各 5 次，24 页合成 CBZ，1200×1800 PNG，实际 Electron / IPC / 图片解码 |
| 慢准备开书中位数 | 573.5 ms | 317.3 ms | 各 3 次，清单和阅读器模块各受控延迟 250 ms |

开书测试采用独立用户目录，交替运行两版，抑制空闲预热，专门覆盖用户在预热完成前打开漫画的路径。普通样本已很快，本轮没有测得有意义的进一步缩短；受控慢准备减少约 256 ms，验证两个独立等待被重叠。新版在点击后 0–1 ms 请求阅读器模块，旧版在 251–255 ms 后才请求。所有样本恢复同一第 5 页。

上述约 45% 的慢准备改善只对应注明的人工延迟条件，不作所有漫画或真机的统一速度承诺。单独进程启动计时受模拟器启动和并行构建负载影响，仅作原始诊断保留，不用于性能结论。Android 启动时间用于确认首屏完成，不与旧轮次直接计算提速倍率。
