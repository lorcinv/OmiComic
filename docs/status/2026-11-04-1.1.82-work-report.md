# OmiComic 1.1.82 工作报告

本次完整处理 PDF、EPUB、MOBI 的读取和阅读流程，修复上一版 PDF 的重复处理与翻页退步。Android 和 Windows 均交付 1.1.82，保留旧安装包及累计工作区。

| 范围 | 本次修改 |
| --- | --- |
| PDF | 系统渲染后直接使用原生位图绘制，移除正文 PNG 编码、网页解码和再次重采样。放大时按视口重新渲染 PDF 区域；预览使用小尺寸画面。 |
| 图片 EPUB / MOBI | 与漫画压缩包共用原生绘制和缓存，前台页优先，相邻页提前准备。长图直接解码对应区域，保持分段比例和原图放大细节。 |
| 文字 EPUB / MOBI | 复用章节解析及图片信息；分页遍历约每 4 ms 让出线程，滑动时暂停。只有实际页数变化才重建页面表，修正缓存驱逐计量。 |
| 阅读衔接 | 检查单／双页、阅读方向、连续模式、缩放、反向翻页和退出续读。补齐两种电子书的拖动预览，修复原生队列限制连续模式可见页的问题。 |
| PC | 同步文字调度与解析复用，详情预览统一复用文档会话；验证原文件、翻页、书签与重启续读。 |

ComicScreen 采用 PDF 直接渲染位图、原生分页和分块读取等机制。已复查用户 APK 对应的本地反编译资料，按 Omi 现有结构重新实现相关机制；无需新增大型 PDF SDK。[具体依据与验证边界](2026-11-04-comicscreen-pdf-motion-analysis.md)。

## 同设备对照

Android 15 x86_64 模拟器，WebView 124，手机尺寸 412×660。使用相同 36 页、约 11.57 MiB 图片 PDF、三本用户原文件及人工长图样本，对比已交付的 1.1.80、1.1.81 与本次 1.1.82。

独立 PDF 流程连续打开三次，入口到首屏内容就绪的中位数为：

| 版本 | 中位时间 |
| --- | ---: |
| 1.1.80 | 353 ms |
| 1.1.81 | 302 ms |

| 文件类型 | 1.1.81 | 1.1.82 |
| --- | ---: | ---: |
| PDF | 33.4 ms | 16.8 ms |
| 图片 EPUB | 33.4 ms | 16.7 ms |
| 漫画 MOBI | 33.4 ms | 16.8 ms |

新版五组连续滑页均未记录到内容空白帧，并验证了反向翻页。文字 MOBI 的这项帧间隔没有改善，因此不将它描述为帧率提升。独立 PDF 的三次结果包含后两次暖打开；混合书库首次打开 PDF 仍记录到约 1.58 秒，启动时间会受初始化和书库后台任务影响。1.1.81 的第一轮混合流程有一次漫画滑页未完成，复跑结果及首次失败日志均保留，未用复跑覆盖失败记录。

## 完整流程验证

- 安卓手机实包：PDF、文字 MOBI、文字 EPUB、图片 EPUB、漫画 MOBI、长图 EPUB 六组，覆盖详情预览、阅读、模式切换、缩放还原、阅读中预览、退出及页位续读；PDF 放大后实际生成了清晰分块。
- 安卓平板横屏、竖屏：各六组文件完成打开、预览、翻页、菜单与效果检查。6000×6000 扫描页和长图末段另外核对了实际原生绘制、颜色和内存预算。
- 核心检查 139 项通过、1 项跳过；组件全量 238 项及相关专项检查通过；当前 Chromium / Chromium 100 各 27 项兼容检查通过，文档及手势回归 34 项通过。
- Windows 成品：三本原文件、PDF、长图的打开、翻页及书签通过，文字书重启后页位保留。

Android APK 约 15.31 MiB，与 1.1.81 相当。交付含 APK、Windows 安装版与便携版、源码、验证记录和 SHA-256 清单；测试书籍与 ComicScreen APK 不包含在安装包或源码包内。

以上性能数据来自模拟器，华为 MatePad 11、OPPO Pad mini 与用户手机尚未完成本轮实机复测。此版为本地交付，未提交、推送或公开发布。
