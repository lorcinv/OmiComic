# 1.1.73 手机内页进入、轻滑翻页与文件夹过渡修复

日期：2026-11-03，Asia/Hong_Kong。仅修改手机对应行为，不更新版本，不重建 Windows 安装包，不提交、推送或发布。

## 最终行为

- 进入阅读器采用 200 ms 动画。点击时并行准备原页面快照与文档/内页；保存的实际阅读页就绪后进入，不展开模糊封面，也不将空白页作为进入画面。取消、失败和后台切换仍清理过渡。
- 点击进度或缩略图后，预览条对齐所选页的中心，并等待正文确认该次目标；正文的旧页码不能把它拉回。手指直接拖动预览条时仍使用系统惯性滚动，允许一定范围内偏移，不在松手后强制回中。
- 手机横滑起步距离从 8 调整为 6 CSS px；轻微斜向起步继续观察，只有明确纵向手势才放弃横滑。快速翻页门槛从 0.4 调整为 0.3 CSS px/ms，最小有效位移从 25 调整为 18 CSS px；非快速手势的距离门槛从视口宽度 28% 调整为 22%。正常页间位移仍按手指 1:1 跟随，书首/书尾保留阻力。松手时补计合并掉的最后一次普通横滑位移；放大后的边缘溢出沿用既有移动量。
- Android PDF 按完整相邻页组预读，双页不再只准备其中一页；复用现有字节预算和取消队列。预先准备的滑页画布在真正拖动时复用，不在每次起步临时复制。额外预备画布限于当前可用缓存的 25%，最高 64 MiB，并计入显示缓存。
- PDF.js 绘制仍在 WebView 线程上进行；拖动/归位时在绘制分段之间让出一帧，优先处理输入和画面移动。冷打开沿用即时绘制安排，关闭文档会取消未继续的分段。
- 容器文件夹直接进入目录；无法提前确认类型的文件夹，先根据清单确认可阅读后才启动阅读器反馈。进入目录、栏目等网页过渡前，等待原生旧快照清除，避免旧缩略图迟到覆盖新页面。

- `com/viewer/widget/ImageViewPager.java:103`、`:129`：手势主要交给父级 AndroidX ViewPager；会考虑图片自身的可滚动范围。

- 同文件 `:801`、`:2364`：以系统滑动阈值、400 dp/s 的快速滑动速度和 25 dp 的位移参与判定；普通距离、最大时长和插值分属不同环节，不能把它们统称为一个“阻尼值”。

以上为静态观察，不能当作 ComicScreen 的运行帧率或真机手感测量。本次以 Omi 自有实现调整识别、预读与画面交接，未复制其反编译实现。
