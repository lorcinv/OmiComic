# 1.1.93 滑动跨本与连续阅读补修

版本保持 1.1.93，Android versionCode 10193。安装包在 `release/OmiComic-1.1.93-swipe-fix/`。未发布 GitHub，未安装到用户日常程序；Android 只装到专用模拟器，Windows 通过独立临时资料测试。

## 修复内容

- Android WebView 在一次边界滑动后，可能发送跨本按钮的 pointerdown／pointerup，却不发送随后的 click。实包事件记录确认旧包第一次点箭头时没有资源请求。本次跨本按钮在完整、未拖移、未取消的触摸松开时直接激活，忽略随后可能到来的兼容 click，避免漏切或连切。鼠标及键盘保持原点击行为。
- 连续阅读在真实首尾边界继续拖动达到 40 CSS px 后显示跨本入口；页面内部移动不累计边界距离，反向移动撤回累计值，取消手势不显示入口。开头和结尾对称处理。
- 横向从左往右阅读：左上一本、右下一本；反向阅读对调。纵向阅读：顶部向上箭头为上一本、底部向下箭头为下一本。
- 纵向箭头避让 Android 安全区域，以及可见的工具栏、底栏和页面预览。
- 上一轮菜单等修复完整保留。

## 验证结果

- 类型检查、两端构建通过；4 项按钮组件用例覆盖缺失 click、重复 click、拖移回原位、取消、鼠标和键盘。
- 29 项浏览器场景通过，包含源目录排序、历史入口、原有页面预览组合，以及单页／双页／横向连续／反向连续／纵向连续的首尾跨本与纵向工具栏避让。
- Android 实包完成上述五种阅读模式 × 上一本／下一本，共 10 种系统触摸组合。每次由真实滑动触发入口，首次点按只请求并打开一本相邻漫画。最终包另复核双页上一本、纵向上下两端，纵向箭头实际截图核对通过。实体手机未测试。
- Windows 实包在独立资料下验证恢复页码、按源目录倒序切换及返回上一本。
- APK 签名保持原签名，系统外部打开守卫通过；419 个 APK 网页文件及 415 个 Windows 网页文件与构建输出逐字节一致。安装器内应用与已测试的 Windows 实包一致。

Android 测试入口为 `tests/android/book-swipe1193.js`，仪器参数示例：`mode=quality1155 fixture=tablet1179-bookSwitch1193-swipe-vertical-previous`。截图及逐场景结果保存在 `.cache/android-ui1193/`。
