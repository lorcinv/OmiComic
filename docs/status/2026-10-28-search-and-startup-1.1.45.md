# 1.1.45 搜索与启动设置

本次依据 ComicScreen 的搜索流程分析，优化 Omi 的搜索结果发布，并调整手机收藏入口、增加双端主界面开关。分析来源及代码定位见 [ComicScreen 搜索逻辑](2026-10-28-comicscreen-search-logic.md)。采用其逐目录交付思路，自行实现；未引入对方代码、资源或二进制。

## 最终行为

- 搜索在发现批次到达时交付结果，不再等待全库文件夹清单结束才显示漫画。同一新增批次先文件夹、后漫画；后续批次追加在现有结果后，避免后发现的文件夹挤动已显示漫画。
- 已计算且未变化的资源复用匹配结果，只对新命中批次排序；资源删除或备注、标签变化仍会重新核对。大批数据按短时间片让出界面，旧搜索和输入法组合输入的取消规则保留。
- 已显示结果保持顺序，追加数据保持当前页码、可见卡片及滚动位置；继续保留 1.1.44 的取消周期自动重扫和随机阅读优先返回规则。
- 手机网格、列表的收藏按钮位于封面右上角，独立处理点击、长按及键盘操作；PC 收藏位置保持原样。四种主题与窄屏布局均已检查。
- 两端设置 → 外观与主题增加“显示主界面”，默认开启，旧数据没有此字段也保持开启。关闭后冷启动直达资源库，重新开启恢复主页。
- 启动先读取一次设置，并把同一份启动资料交给首屏，关闭主页不会启动主页封面请求。Android 启动遮罩等资源库原有就绪回调后结束；外部打开文件仍优先进入阅读器，空资源库返回可退到后台。

- 搜索语法、目录查询与新增增量发布测试：29 项通过。包含 5,000 条数据未处理完即发布、取消后恢复去重、1,000 条旧记录加一条修改和一条新增只执行两次匹配。
- 搜索及连续翻页浏览器验证：7 项通过。包含 PC 与手机分批目录及漫画命中、滚动锚点和页码固定、搜索停留 125 秒不周期重扫、随机返回优先级。
- 手机收藏入口浏览器验证：9 项通过，覆盖四种主题的网格和列表，以及 PC 原有位置。
- 主界面开关：20 项 DOM／Android 适配检查、1 项 Windows 服务持久化、双端浏览器及手机设置同步回归通过。关闭后首屏应用数据读取一次、目录读取一次、主页封面请求零次。详见 `output/implementation-1145/home-toggle-verification.json`。
- Windows 最终实包通过名称／标签／备注搜索与路径排除、随机 Esc 优先返回，以及设置界面保存后完整退出重启的开关验证。已安装至 `D:\software\OmiComic`，安装器退出码 0；产品版本 `1.1.45.0`，已安装应用显示 `1.1.45`，安装目录与已验证包的 `app.asar` 校验一致，用户配置安装前后 SHA-256 一致。
- Android 最终 APK 在专用模拟器 `OmiRegression1141` 验收通过：读取 164 条实际授权目录项目，以三个受控发现批次核对漫画提前显示、后续追加保持卡片／滚动／页码，以及原生返回先退出随机再处理输入法和搜索。
- Android 关闭主界面的冷启动通过：直接进入资源库，原生阅读器出现实际页面，切后台再恢复仍有画面，返回资源库没有重开已关闭的主页。测试结束后，模拟器临时设置按原始字节恢复并核对哈希。
- 实包结果分别为 `test-results/android-search1145.json`、`test-results/android-launch1145.json`；Windows 结果、安装回执及交付校验值见 `output/implementation-1145/`。
