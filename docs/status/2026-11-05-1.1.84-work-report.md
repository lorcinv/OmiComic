# OmiComic 1.1.84 工作报告

本次仅更新 Android，Windows 保持已交付的 1.1.83。沿用原签名，可直接覆盖安装。

| 问题 | 原因与修复 |
| --- | --- |
| 平板竖屏点击漫画时界面上移 | 后台准备阅读页时提前隐藏状态栏，根页面随之改变顶部留白；旧页面截图也会跟着移动。现在准备期间保留资源库布局，截图固定在原窗口位置，阅读页就绪后再切换。 |
| 阅读栏与时间栏呼出时画面移动、动画生硬 | 状态栏显隐会改变整块阅读区的高度，触发重新排版。现在阅读画布固定，状态栏覆盖显示；顶部按钮单独保留安全距离，正文不随栏目的显隐移动或缩放。 |
| 手机偶发 PDF 入场停顿，使用一段时间后又变快 | 原生 PDF 阅读路径仍预热网页 PDF 引擎；资源库已有原生 PDF 封面时也会启动同一套解析器和 Worker。已去掉两处重复工作，并减少原生文档首屏显示前的额外绘制等待；原生提交检查与兼容回退继续保留。 |

手机芯片和内存更强，并不意味着每次冷开都更快。首次解析、后台任务重叠和缓存是否已准备，会改变一次点击的耗时。本次确认的额外开销来自重复启动的网页引擎，和安装包体积、PDF 总大小没有直接关系；这也符合“使用一段时间后恢复秒开”的表现。大 MOBI 仍需读取索引和目标页，本轮同时减少了其原生图片首屏的额外等待。

状态栏使用安卓原生显隐与临时边缘呼出，阅读区使用独立、稳定的安全边距。[Android 沉浸模式](https://developer.android.com/develop/ui/views/layout/immersive)、[WindowInsets 稳定边距](https://developer.android.com/reference/android/view/WindowInsets#getInsetsIgnoringVisibility(int))。

## 验证

旧版 1.1.83 与新版在同一 Android 15 / WebView 124 模拟器对照。下表是呼出栏目之前和之后的阅读视口高度，单位为页面坐标像素（CSS px）；画面坐标另行逐项检查。

| 布局 | 1.1.83 | 1.1.84 |
| --- | ---: | ---: |
| 手机竖屏 | 684 → 660 | 684 → 684 |
| 平板竖屏 | 1224 → 1200 | 1224 → 1224 |
| 平板横屏 | 744 → 744 | 744 → 744 |

- 三种布局分别执行首次打开、换一本、重复打开；连续显隐栏目两轮，确认页面位置和尺寸不变、顶部按钮不被时间栏遮挡、退出后资源库边距恢复。
- 人为延迟文档准备，确认准备期间资源库的状态栏与布局保持原样；逐帧检查旧页面截图，实际绘制位置偏移为 0。
- 旧版会加载网页 PDF 模块与 Worker；新版原生 PDF 流程的对应资源请求为 0。原生第一页提交检查继续有效。
- 139 项核心测试通过、1 项跳过；247 项界面逻辑测试通过；27 项阅读与手势检查通过，包含 PC EPUB、单/双页、放大点按翻页及真实触摸拖动。
- 平板完成 PDF、文字 MOBI/EPUB、图片 EPUB、大 MOBI、长图 EPUB 与大图 EPUB 的完整阅读、缩放、退出及续读检查；手机和平板各执行大 MOBI 的 11 个重叠章节请求和 6 次连续跳转，未出现失败。
- 三类 PDF 样本在手机、平板合计连续拖动 24 次，验证正文、清晰预读和放大后的高清区域继续正常。最终 APK 的 8 组原生流程检查全部通过，模拟器已安装包与交付 APK 的校验值一致。

模拟器用于核对行为、画面坐标和重复加载路径；华为平板与用户手机的实际入场手感仍需用此包复测。未增加依赖或原生 SDK，图片预算、滑页曲线和预读策略沿用 1.1.83。
