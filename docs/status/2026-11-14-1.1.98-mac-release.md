## 构建与验证

[Mac 构建和实包验证](https://github.com/lorcinv/OmiComic/actions/runs/43591209312) 的 arm64、x64 两路均成功，分别在 `macos-15` 和 `macos-15-intel` 上运行打包后的应用。

- 两种架构的普通阅读、横向全景和纵向全景均通过 Command＋滚轮缩小到 25%、松开后保持、重新放大检查，操作前后页码不变。
- 每种架构均通过 4 种真实压缩包图像读取、PDF 文件读取、14 个卡片尺寸测量点、Command 搜索及缩放、关闭窗口后重开检查。
- ZIP 完整性、包内 `CFBundleShortVersionString` / `CFBundleVersion`、可执行文件的 arm64 / x64 架构检查通过。
- 检查了两种架构的阅读截图，界面显示 25% 缩放，页面内容正常显示。
- [上传与附件校验流程](https://github.com/lorcinv/OmiComic/actions/runs/43592789544) 先校验构建产物 SHA-256、运行结果、包内版本和架构，再上传四个 Mac 附件并扩充校验文件；上传后逐项核对 GitHub 返回的文件摘要。

首轮新增测试用正则判断全景模式时，误匹配了动画状态类，导致 arm64 测试失败；改为检查完整类名后，两种架构均通过。原失败日志保留，产品代码未为该测试增加分支。

本轮使用 GitHub 的 macOS 构建环境，没有在用户自己的 Mac 上安装。Mac 包未使用 Apple Developer ID 签名和公证，首次打开方式见 [Mac 安装说明](../APPLE.md)。
