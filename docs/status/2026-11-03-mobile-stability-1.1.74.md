# 1.1.74 手机进入与文件夹稳定性修复

2026-11-03，Asia/Hong_Kong。Android versionName 1.1.74，versionCode 10174；desktopVersion 保持 1.1.73，Windows 包不重建。

## 原因与修改

- 1.1.73 内页进入修复版的 `SceneTransition.readerIntent` 会把整个旧页面快照缩至 0.985。这是用户报告“整个界面像缩放了一下”的直接原因。用旧 APK 和新增断言复现后，原生逐帧记录的最小缩放为 0.9850000143，测试按预期失败。本版快照保持原尺寸，只等待实际内页就绪后执行既有 200 ms 横向进入。
- 文件夹网页过渡会同时把新页面从 0.978 放大至 1，并把旧页面放大至 1.012；原生备用过渡也会缩放新页面。本版两条路径都改为淡入淡出。详情、栏目和首页已有过渡保持各自行为。
- 连续列表会按位置键保存旧锚点，手机再次打开文件夹因此恢复原滚动位置。本版每次明确进入或返回普通目录、书架文件夹时生成新的导航会话，从顶部开始。跨栏目切换与退出漫画回到资源列表仍沿用原浏览会话，漫画阅读页码照常保存。
- 新目录首次渲染使用目标目录的可见行，随后才测量卡片高度。修正先沿用旧目录可见行、再恢复锚点的交接，避免长短列表切换时先挂载错误行。
- 手机底部阅读进度条关闭 WebView 的触摸高亮和焦点外框，保留现有拖动、点击定位及键盘行为。未改正文解码、图片质量、缓存预算、预读和滑页阈值。
