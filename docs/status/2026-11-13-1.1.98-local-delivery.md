## 重现入口

- Windows：`npm run package:prepare`，然后使用现有 `electron-builder.json` 构建 NSIS 安装器；便携版使用 `electron-builder.portable.json` 与同一 `win-unpacked` 成品。便携说明沿用 `resources/portable-readme.txt`。
- Android：`npm run build:android:renderer`，然后运行 `scripts/build-android.ps1`，指定现有 JDK、SDK、原签名与本版交付目录。
- 成品：`tests/packaged.electron.cjs`；Android `scripts/test-android.ps1 -Mode quality1155 -Fixture tablet1179-delivery1198 -ExpectedVersion 1.1.98`。先将 `Panorama.cbz`、`Document.pdf`、`Story.epub` 放到测试 APK 的 `files/tablet1179/`；本轮样例来自 `.cache/experience1186/fixtures/` 和 `.cache/android-format-fixtures/Formats116/`。
- 缩放及兼容浏览器检查：`tests/reader-minimum-zoom.playwright.config.ts` 与 `tests/legacy-startup.playwright.config.ts`。


华为 Android 9 实体平板尚未验证；旧 API 模拟检查不能替代该设备的实际冷启动与阅读检查。
