# 1.1.71 预览与书架交互修复

2026-11-02，Asia/Hong_Kong。基于 1.1.70 的累计工作区修改，编辑前文件快照在 `.cache/omi1171/before/`。

## 修改

- 阅读预览条以实际滚动位置驱动选中页与有界缩略图窗口。手指松开时立即定位到最近一页，不在闲置计时器结束后再滚动；自身导航的延迟回报和双页配对只更新阅读状态，不重新定位预览条。进度条主动跳转仍能接管位置。
- 读取本地 Git 标签 `v1.1.49` 的资源详情控件，恢复 PC 的 `detail-pagination` 和手机 `MobileDetailPager` 原位置、箭头与页码样式。连续预览组件增加定位接口及可见组回报，页码显示与跳转分开处理；手动滚动跨过 48、96 页时不中断列表。虚拟列表与翻页根据实际显示列数、行距计算，兼容 Android 密度覆盖与像素取整。手机复用外层详情滚动容器，保留选择与打开操作；底部留出浮动页码所需空间。
- 加入书架两端共用选择组件。手机使用底部弹层和独立搜索、单列分类、书架区，增大分类区；根据最后一次用户纠正隐藏两个列表的原生与自定义滚动条，直接触摸滚动。PC 保留自定义滚动与轨道翻动。
- 新建分类弹窗显示在选择器上方，保存后选择新分类并保留待加入资源。新建书架并加入后回到原资源列表，不切换书架页面。分类为空时也先展示选择器，两个新建入口继续可用。
- PC 底部动作与选择面板共用玻璃背景、边框和圆角，排除通用按钮样式对边框的覆盖。
- 使用统一提示队列，取可见内容区测量位置和宽度；同时最多展示前景与两层错位背景，只有前景运行计时器。错误保留原有手动关闭行为；等待中的提示不提前过期。资源库、外部打开和拖入结果共用这条队列。
