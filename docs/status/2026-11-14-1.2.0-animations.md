# OmiComic 1.2.0：动图、关于页与默认沉浸模式

交付日期：2026-11-14。Windows、macOS 和 Android 统一为 1.2.0；Android versionCode 为 10200。

## 本次修改

- 按图片内容识别 GIF、动画 WebP 和 APNG（.png / .apng）。动图保留原始图片播放，绕过会丢失后续帧的锐化、降噪、缩放栅格及 Android 静态位图路径；亮度、对比度等实时滤镜继续生效。静态 WebP / PNG 保留原有画质处理与原生渲染。
- 文件夹、压缩包、EPUB 内嵌图及滑页预览使用相同的动图标记。长条 EPUB 动图保留完整动画；静态长图仍按原来的规则分页。Android 更新栅格缓存元数据版本，避免复用旧版 APNG 静态缓存。
- 补齐 .apng 的文件枚举、系统打开和 EPUB 图片识别。
- 关于页三个入口之间统一为 12 CSS 像素。项目主页、操作说明和检查更新改用同一尺寸的 SVG 图标，垂直居中。
- PC“漫画阅读设置”提供“默认进入沉浸模式”，默认关闭。复用原设置字段，打开漫画时按此开关决定是否沉浸；手动切换仍可用。其他阅读位置、缩放、双页等保存行为保持原规则。

## 验证结果

- Windows EXE：GIF、WebP、PNG/APNG、.apng 分别在文件夹、压缩包、EPUB 中完成连续屏幕帧检查，共 12 组；覆盖滤镜、缩放、翻页返回及全景。EPUB 继续使用其原有基础滤镜范围。
- Windows 最终 EXE 读取图片、ZIP、7z、PDF、EPUB 的检查通过；安装器中 EXE、app.asar、EPUB worker 的哈希与所测文件一致。
- Android 最终 APK：上述 12 组均通过，开启画面调整、返回动图的 24 组连续帧采样均包含两个动画帧；静态 WebP 仍走原生渲染。关于页两个间距均为 12 CSS 像素，三个 SVG 图标居中。
- Mac arm64 / x64：原生菜单、压缩包、PDF、窗口尺寸、缩放、重新打开以及上述 12 组动画测试通过。下载包 SHA-256 与 GitHub artifact digest 一致；两种架构的应用 Info.plist 均为 1.2.0。
- 版本、类型检查、动图识别、EPUB 图片处理、Android 外部打开、默认阅读/沉浸设置和关于页的针对性检查通过。
- 验证环境为 Windows 11、Android 15 模拟器，以及 macOS 15 两种架构的 CI。没有进行 Windows 10 真机或 Android 实体机验证。Mac 包未签名、未公证。
