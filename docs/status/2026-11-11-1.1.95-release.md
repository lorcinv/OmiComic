# OmiComic 1.1.95 发行记录

Windows / Android 统一为 1.1.95，Android versionCode 为 10195。源码基于已发行的 v1.1.94（`f239c6e`），在独立工作树 `.cache/release1195/worktree`、分支 `codex/startup-layout-1.1.95` 整理本次变更；主工作区已有修改保留。

## 变更

- 合入本轮“调整栏目布局”、默认启动页和双端浏览位置保存，细节及早先的 1.1.94 本地验证见 [原始记录](2026-11-11-startup-and-position-memory.md)。
- 手机默认阅读将原先固定的“打开漫画时的缩放：适应窗口”替换为可保存的“默认缩放模式”。与 PC 共用适应窗口、适应高度、适应宽度、原始尺寸四项及相同文案。
- 阅读器初始化、资源切换与异步设置恢复均使用默认缩放或该漫画已保存的缩放，移除手机强制适应窗口的覆盖。首次阅读采用全局默认，续读恢复单本状态。
- 移除应用设置中“双击放大画面”下面的说明，保留原开关。
- 旧设置缺少启动页时不写入未定义字段，保持数据备份的序列化往返一致性。
- 更新三语内置说明、导出的使用文档、版本记录及下载链接。

## 验证

- `npm run verify` 正常结束，退出码 0：类型检查、Windows 构建通过；核心检查 149 通过、1 项原有跳过；DOM 检查 57 个文件、313 项通过。首轮发现旧设置备份的未定义启动页字段问题，修正后整条命令重跑通过。
- `npx playwright test --config tests/settings-reader.config.ts tests/default-fit.spec.ts tests/navigation-memory.spec.ts`：25 项通过。覆盖 PC / 手机四种缩放的选择、保存、重载、实际图片尺寸和单本续读，以及启动栏目、目录与书架网格 / 列表的位置保存。
- Windows 最终 1.1.95 实包在独立配置、隐藏窗口下运行：`tests/default-fit.electron.cjs` 验证四种全局默认通过真实界面保存，退出进程再打开新漫画后正确应用；`tests/navigation-memory.electron.cjs` 验证全部启动页，以及资源库 1200px、收藏 900px、书架根层 1100px、内部 950px 的退出重开恢复。运行时 `app.isPackaged` 为 true，版本为 1.1.95。
- `tests/reader-layout.electron.cjs` 使用最终 Windows 实包验证真实宽 / 高 PNG、单双页、缩放、全景与 RTL、沉浸切换和缩放保存，通过。旧用例将隐藏预读页计入当前页数，已改为核对正在显示的页框和图片后完整重跑通过；本次没有因此改动预读或布局实现。
- Windows 安装器与主程序产品版本均为 1.1.95；便携 ZIP 完整性检查通过。分别提取安装器和便携 ZIP 的主程序、`resources/app.asar`，两者均与上述受测程序的 SHA-256 相同。
- Android 渲染与原生 APK 构建通过；最终 APK 版本为 1.1.95 / 10195、最低 Android 8.0，源码与安装包的外部打开声明检查、16 KB 对齐及 v2 / v3 签名验证通过。签名证书 SHA-256 为 `31d30425848de4b32a69e27873756562f400996ef647cba83443b6b20ad9db43`，沿用原密钥。

本轮 1.1.95 的 Android 模拟器未启动成功：硬件加速初始化返回 WHPX `80070005`，软件模式也在初始化阶段退出。因此当前版本的手机行为由浏览器界面回归验证，未完成最终 APK 的模拟器或实体设备运行验证。早先 1.1.94 本地包的位置记忆模拟器结果单独保留在原始记录，不作为本版 APK 的运行结果。未运行全量旧浏览器套件，也未声称 GitHub CI 通过。
