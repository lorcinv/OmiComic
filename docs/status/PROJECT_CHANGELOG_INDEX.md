# PROJECT_CHANGELOG_INDEX

## 使用说明

- Codex 默认不要读取 changelog。
- 只有需要追溯历史原因、旧实现背景、已废弃决策时才读取对应 CHANGELOG 文件。
- 当前开发接续优先读取根目录 `PROJECT_STATUS.md`。
- 归档文件只保存历史，不作为每轮默认上下文。
