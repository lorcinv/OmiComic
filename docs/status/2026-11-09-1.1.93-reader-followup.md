# 1.1.93 阅读与安卓菜单补修（2026-11-09）

本次在本地交付，不发布 GitHub，不替换用户已安装程序。两端版本均为 1.1.93，Android versionCode 为 10193。

## 修复范围

- 安卓显示选项将刷新资源库、标签管理、应用设置放在连续等高行中，移除菜单末尾额外内边距，保留弹层与系统安全区的外间距。
- 安卓画面调整弹窗在手机、平板上均水平居中、底部对齐设置面板，并计入阅读器安全区。保留无框小叉号及此前侧栏按钮居中修复。
- 恢复 Android VIEW/SEND 声明、冷启动及 onNewIntent 接收、临时文件持久化、网页端事件和历史记录接入。修复曾留在主工作区但没有进入 1.1.92 发布基线，导致前两轮基于发布版的包遗漏该功能。
- 首页和历史列表（含详情页）从原始漫画目录建立相邻资源队列，按文件名自然排序，包括未读漫画。图片入口按所在漫画文件夹处理。收藏、书签和书架的显式队列保持原规则。
- 原目录不可读取或 Android 只有单文件授权时不构造相邻队列，不自动弹授权选择器，不回退到历史顺序。

## 防止再次漏包

后续发行以 `codex/android-ui-1.1.93` 分支为本地完整补修基线，而非直接从 GitHub 1.1.92 重新挑选 UI 文件。该分支包含外部文件接入、构建检查和回归测试。主工作区也同步保留本次对应改动。

`build-android.ps1` 构建前检查声明与接收链路，签名后检查安装包内的 intent-filter；缺少 VIEW/SEND、已支持 MIME、文件扩展名时构建失败。`android-external-contract.test.cjs` 进入常规测试；实测此前缺少声明的 APK 会被新检查拒绝。
