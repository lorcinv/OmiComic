# OmiComic 1.1.42 修复与验收记录

日期：2026-10-28。依据 `2026-10-28-performance-audit-1.1.40-to-1.1.41.md` 与 `2026-10-29-modification-plan.md` 实施。工作起点是带有未提交改动的本地 1.1.41；普通浏览、封面与阅读对照基线仍为原版 1.1.40（`ae4ee1139fc92aec72a0183889d9c8bd7fee9dcb`）。

## 已实施的改动

| 审计项 | 实施结果 | 验证与边界 |
| --- | --- | --- |
| R01 | 清单改为分批发现、分批传输。已有目录摘要先进入共享记录；查询已有结果先显示，进度或局部错误不替换可用列表。随机尚无候选时明确显示补全过程。 | 渐进结果浏览器回归、真实 PC 程序首批接口验证；Android 15 原生分批接口通过，首批 39 ms。 |
| R02 | 搜索和随机共用每个根目录的基础记录。关闭一个消费者停止后续派发，保留已完成记录和原生断点。完整与漫画视图不再维护两份发现任务。 | 双根取消与复用测试通过；缓存数量上限的回收与用户取消分开。 |
| R03 | 每个查询只编译一次；按需规范化实际参与匹配的字段，使用有界缓存与常数成本的淘汰队列。大批匹配、合并排序按时间片让出，旧代次退出，组合输入等待确认。删除搜索祖先投影。 | 十万条查询代次测试、Unicode 长路径与统一语法测试通过。 |
| R04 | 恢复空查询直接返回；普通浏览不规范化全列表。 | 一万次空查询的规范化计数为零；纯函数对照见测量文件。 |
| R05 | Android 普通目录与扫描共用 `directoryVersion`，统一真实换行版本键。扫描可复用普通目录快照。 | Android 15 实测磁盘命中、零修改时间重读、进程重启、提供器拒绝及移除授权均通过。 |
| R06 | SQLite 增加独立的持久资源摘要与 URI 记录。完整目录结果批量提交，共用 URI 定位；前台 64 个目录、32000 条热缓存上限保持。 | Android 15 扫描后及进程重启后深层打开均通过持久 URI 定位，父目录内容查询为零。 |
| R07 | Android 每次扫描批次按目录获得读锁并释放，不再持有整库生命周期的锁。前台任务能取消扫描中的 SAF 查询；取消的目录重新排队。 | 独立进程慢提供器实际收到取消；扫描中前台改名 6 ms，之后清单名称一致。记录读锁累计时间，未将其当作单次最长持锁时间。 |
| R08 | PC 用前台活动标记协调目录、封面、归档和后台发现；扫描每次至多处理少量目录。Android 接入 Activity 暂停、恢复、前台调用、媒体解码及 `CancellationSignal`，保留独立扫描队列。 | PC 实际程序、目录/归档回归通过；Android 15 前台取消、暂停、恢复及锁屏运行测试通过。 |
| R09 | 普通目录结果同时供清单持久化；轻量记录与已有 size/modifiedAt 合并。未知版本保留已加载封面，时间排序按分批补齐的真实时间排序。 | 已有元数据复用及 PC 实际封面回归通过。随机不发起全库 stat；时间排序才补未知元数据。 |
| R10 | PC DOM 与封面窗口按视口确定，逻辑页容量继续保留 50/100/150/200/500；手机原视口窗口保留。增量结果使用资源身份维持锚点。补上旋转后列表尾部的空隙容差，末页页码正确。 | 全部容量档、手机旋转、平板和普通目录返回回归通过。 |
| R11 | 两端嵌套包封面只下探必要候选，限制失败重试；不为封面展开全部子包。PC staging 队列支持阅读优先、相同容器去重和预算；归档元数据联合估算预算。Android 保持流式 staging 和 reader/preview 实例隔离。 | PC 嵌套封面、坏子包、优先级、重复请求和实际阅读通过；Android 15 嵌套 ZIP 冷封面及首、中、末页解码通过。 |
| R12 | 原生按目录保存摘要，只保存资源信息；图片页不进入资源清单。PC 每批至多 256 条，Android 每批至多 128 条；前端按批合并并限频通知，基础对象共享，随机排列使用 Uint32Array 编号。完成后释放原生批次；前端保留有限根缓存，原生会话也设上限。 | 源码、分批接口、跨进程磁盘复用及实际 PC 通过。已知搜索摘要仍需要内存；路径、对象、Map、原生服务和位图占用另计，编号大小不是总内存。 |
| R13 | 文件操作按受影响根目录和父目录发出一次更新，保留旧记录直到完整读取成功；排除路径立即退出共享记录。删除、改名后的候选随基础记录更新。完整刷新接口强制核对所有目录，日常刷新仍是局部更新。 | PC 文件操作与持久数据回归通过；72 个子目录的实际磁盘测试证明完整刷新覆盖已退出热缓存的目录。读取失败保存失败状态，不推断整个子树已删除。 |
| R14 | 删除随机的异步候选准备链与收藏/书签全量路径预检。先筛选再随机，重随机仅生成新编号顺序；页容量变化扩展同一顺序前缀。新发现项留到下一次重随机；实际显示的无效路径最多自动补位四次。 | 随机前缀、删除补位、书签身份、阅读返回、无重复、重复抽样及无新增扫描回归通过。 |
| R15 | PC 分别累计目录 readdir/stat、扫描、持久化、桥接载荷、归档读取及 staging 排队；Android 补入 scanner/provider、URI/SQLite 命中、批次字节、持锁与内存计数。运行计数不逐资源写日志。 | PC 测量与测试通过；Android 原生查询、批次、锁、URI/SQLite 及堆采样已保存在七组结果中；堆采样不代表峰值或 WebView 总内存。 |
| R16 | 键盘隐藏只同步焦点；原生第一次 Back 收键盘，后续 Back 退出搜索，再走目录返回。进入搜索文件夹时暂存会话，普通浏览其内容，逐级返回后恢复词、标签、排序、随机批次和位置；恢复不抢焦点。PC 保留 Esc 两阶段及前进。 | 浏览器 PC/手机会话回归通过；Android 15 实际触控、IME/Back、搜索会话恢复均通过。 |

其他清单项已落实：三类 PC 菜单共用毛玻璃参数；窄窗口悬浮按钮采用稳定主题底色，禁用态不降低整组透明度；文案统一为“重随机”，英文、日文及操作说明同步；随机箭头改为 1.6 线宽，并检查 20/24/32/44 px 及 100%/125%/150% 显示比例。

## 验证结果

- TypeScript 与 Windows、Android 构建通过。Android APK 使用原有发布密钥签名，apksigner 验证通过。
- 底层回归：105 通过、1 跳过、0 失败。跳过项是原有 7z 通配符选择器用例。最后的清单与归档专项再测 26 通过、1 跳过。
- React DOM 回归：105/105 通过；清单、查询代次和随机前缀专项 22/22 通过。
- 交付前再次复核分页、手机旋转、渐进清单、四主题及图标显示比例，16/16 通过；完整刷新与磁盘复用专项 4/4 通过。
- 浏览器全量初跑 238/256 通过。18 条旧用例中，多数使用了 1.1.41 已调整的设置名称、整页挂载数量、旧目录按钮或旧文件夹统计；已按现有功能修正后分组复核。另发现旋转后的末页边界问题并修正。当前重点组合 54/54 通过，包含手机/平板、搜索会话、随机、分页、归档返回及图标缩放。各轮原始日志保留在 `output/repair-1142/`，不把分组复核描述成同一次全量通过。
- Windows 实际安装包已验证图片、ZIP、7z、PDF、EPUB 的打开、翻页、返回、重启后数据保留，以及文件改名、移除索引和回收站操作。真实 181 目录库的渐进清单、随机批次、阅读返回和前进另有独立验证。
- 四个主题的菜单与浮动按钮截图，以及三档显示比例的图标截图已目视检查。保留用户要求的现有毛玻璃主题。

性能证据：

- 开发机纯函数对照的 100000 条 `volume` 查询中位数：原版 PC 213.85 ms，原版手机匹配函数在同一 PC 运行 493.185 ms，修复后共用函数 20.501 ms。无磁盘、解包、界面绘制成本，不能换算为实体手机速度。完整结果见 `output/repair-1142/measurements.json`。
- 相同八本测试漫画、独立冷应用缓存下，原版 1.1.40 首张/六张封面为 1188/1188 ms，1.1.42 为 1163/1163 ms。单个受控样本用于检查回退，不据此宣称所有目录都更快。见 `output/repair-1142/cover-comparison.json`。
- 首批与完整清单的实际 PC 数据记录在 `test-results/installed-native-catalog.json`；该程序还读取嵌套包并解码真实图片。完整兼容接口的耗时与 UI 首批返回分别记录。

## Android 原生验收已补齐

后续按用户要求完成 Android 15 专用模拟器原生验收，七组运行测试全部通过。此前 ADB 未连接的原因是 Windows 预留端口覆盖了旧测试端口；改用 5680 后恢复连接。

覆盖安装保留原数据，最终 2088 个目录的增量扫描、持久 URI/SQLite 复用、慢提供器取消与前台改名、暂停恢复、真实 IME/Back、随机、17 个格式入口、嵌套包和原生翻页均通过。锁屏及强制停止后的数据与阅读进度保留。按用户追加要求移除 PC/Android 的资源清单补全横幅，双端重新构建，最终 APK 七组原生复验全部通过；PC 本机程序已更新，安装前后用户数据相同。

R05/R06/R07/R08/R11/R15/R16 对应的上述 Android 运行证据见[Android 验收报告](2026-10-28-android-1.1.42-acceptance.md)。本次覆盖 Android 15 模拟器；实体手机、ColorOS、原生平板及十万条 Android 内存压力测试仍未执行。
