# Android 1.1.91 工作报告

本文件记录首轮构建。原目录 APK 已先后由同版本缩放颤动修复包和翻页优化包替换，当前产物与校验值见 [翻页与双击开关记录](2026-11-08-1.1.91-tap-option.md)，缩放修复经过见 [缩放稳定性修复记录](2026-11-08-1.1.91-zoom-stability.md)。首轮 APK 留存于 `.cache/android1191-jitter/before.apk`。

## 本轮结果

Android 更新为 1.1.91 / 10191，Windows 保持 1.1.90。安装包沿用原签名，位于 `release/OmiComic-1.1.91-Android/OmiComic-1.1.91-android.apk`，尚未公开发布。

双击倍率由 1.5 调整为 2，保持单级放大／还原，放大围绕点击位置。单击确认窗口由 280 毫秒缩短为 200 毫秒。第二次按下后立即保留双击候选，避免等待抬手时先触发翻页。

普通单页、双页放大时，安卓阅读画布使用摄像头和状态栏区域；工具栏、页码与设置面板沿用安全边距。还原后恢复普通阅读的安全区域。画布尺寸变化不再打断放大动画，并按物理触点补偿画布原点变化。

补充修复了拖动惯性期间的双击冲突：第一次点击止动后仍可与第二次点击组成双击；单独的止动点击不会转为翻页。保留之前的详情浮动翻页胶囊修复，进入阅读时移除，返回详情时恢复当前组和操作。
