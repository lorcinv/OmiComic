历史归档，不作为当前默认读取文件。当前状态请看根目录 `PROJECT_STATUS.md`。

## 第 7 轮：本地持久化、阅读进度、最近打开、进度 UI

### 主要完成

- 本地 JSON 持久化系统已实现。
- 数据保存到 Electron `app.getPath("userData") / omicomic-data.json`，不写入项目源码目录，不写入漫画原目录。
- JSON 写入使用临时文件再替换正式文件，降低写入中断导致损坏的风险。
- JSON 文件损坏时会备份为 `.broken.json` 并回退默认数据，应用不会崩溃。
- 根目录恢复已实现：添加目录后会保存，重启后恢复根目录列表。
- 上次激活根目录与上次浏览目录会尽量恢复；路径不存在时显示中文提示。
- 基础界面设置保存已实现：卡片尺寸、每页数量、排序方式、进度光条开关、进度文本开关、进度文本模式、进度条粗细。
- 文件夹图片阅读进度保存与恢复已实现。
- 双击普通图片进入同目录阅读时，进度 key 使用图片所在目录，重新打开会恢复上次页码。
- ZIP/CBZ 阅读进度保存与恢复已实现。
- 阅读器翻页、首页 / 尾页跳转、页码输入跳转后会防抖保存进度。
- 返回资源库或阅读器卸载时会补保存最后阅读状态。
- 最近打开列表已实现，同一资源不会重复出现，最多保留 50 条。
- 最近打开卡片支持缩略图 / 默认图标、进度条、进度文本、双击重新打开并恢复进度。
- 最近打开卡片支持右键“删除此最近记录”，只移除记录，不删除原始文件，也不删除阅读进度。
- PDF / EPUB 不纳入阅读进度和最近打开。

### 资源库分页与网格修复

- 当前目录支持搜索、排序、小 / 中 / 大卡片、60 / 100 / 150 / 200 分页。
- 网格区域独立滚动，分页栏固定在底部。
- 支持滚动到底部 / 顶部自动切换下一页 / 上一页。
- 搜索、排序、缩略图尺寸和每页数量变化后均回到第 1 页。
- 连续滚动仍只渲染当前页切片，不一次性渲染全部目录项目。
- 分页切片改为按当前实际网格列数整除的 `effectivePageSize`。
- 小 / 中 / 大卡片切换后会重新计算列数、`effectivePageSize`、总页数与当前页切片。
- 自动滚动翻页不再因 pageSize 与列数不匹配出现页尾大块空白。

### 进度 UI 与阅读状态补充

- 资源卡片阅读进度光条与进度文本已实现。
- 资源卡片可按设置显示 `当前页 / 总页数` 或百分比。
- 已读完成资源显示完成色，进行中资源显示 `#abfcff`。
- 用户可关闭进度光条或进度文本显示。
- 阅读显示状态区分 `unread / started / completed`。
- 首次打开但停留第一页退出不再显示为 `1 / y`。
- `hasStartedReading` 状态已实现。
- 百分比模式下未阅读资源继续显示纯数字总页数，不显示 `0%`。
- 已开始阅读后回退到第一页会显示 `1 / y`。
- 未阅读资源页数胶囊改为纯数字显示。
- 未阅读资源 pageCount 不再依赖 readingProgress。
- 当前页可见资源的可阅读页数异步统计已实现。
- 未读资源不再出现空白胶囊。
- 卡片底部信息区整理为左类型、右页数的同一行布局。
- 未阅读或停留在第一页的资源仅显示页数文本，不显示进度条。
- 资源卡片底部进度 UI 重新整理，进度条占满卡片底部可用宽度。
- 资源类型信息从进度条区域分离。
- 缩略图右下角曾为未来收藏爱心预留位置。
- 资源管理器网格大块空白问题已修复。
