# CHANGELOG_14

## 本轮主题

自定义虚拟文件夹最小可用闭环。

## 完成内容

1. 新增 `virtualFolders` 用户数据结构，保存软件内自定义文件夹和资源引用。
2. 旧数据缺失 `virtualFolders` 时自动修正为空数组；写入继续走现有 `omicomic-data.json` 安全写入机制。
3. 新增虚拟文件夹创建、重命名、编辑备注、删除、加入资源、移除资源引用的数据服务。
4. 新增对应 preload + IPC 通道，渲染进程仍不直接访问文件系统。
5. 左侧栏新增“自定义文件夹”区域，支持新建入口、列表、数量、选中状态和右键菜单。
6. 资源卡片右键菜单新增“加入自定义文件夹”入口，并保留资源信息入口。
7. 收藏、最近打开资源支持加入自定义文件夹。
8. 选择模式支持批量加入自定义文件夹；书签暂不加入，避免页级对象和资源级虚拟文件夹混淆。
9. 自定义文件夹内容视图复用资源卡片、缩略图、阅读进度、收藏状态、资源信息侧边栏、标签 / 备注读取逻辑。
10. 自定义文件夹内容支持搜索和排序。
11. 双击自定义文件夹内资源时打开原始资源。
12. 从自定义文件夹移除资源时只移除内部引用。
13. 删除自定义文件夹时只删除内部文件夹记录和引用，不删除真实漫画文件。

## 数据结构

`OmiComicAppData` 新增：

```ts
virtualFolders: VirtualFolder[];
```

核心结构：

```ts
interface VirtualFolder {
  id: string;
  name: string;
  note: string;
  tags: string[];
  items: VirtualFolderItem[];
  createdAt: number;
  updatedAt: number;
  sortIndex: number;
}

interface VirtualFolderItem {
  id: string;
  folderId: string;
  resourceKey: string;
  sourcePath: string;
  sourceType: ResourceType;
  title: string;
  addedAt: number;
  sortIndex: number;
}
```

## 安全边界

1. 不创建真实自定义文件夹。
2. 不移动、复制、删除或修改用户漫画原文件。
3. 不写入漫画目录。
4. 删除自定义文件夹、移除文件夹内资源只影响 OmiComic 内部 JSON 数据。
5. 资源标签和备注继续以 `resourceMeta` 为准，不复制到虚拟文件夹 item 中形成双份真相。

## 追加：书架体验优化

本次只处理书架文件夹卡片预览、书架内部 Esc 返回、普通目录隐藏已加入书架资源设置。

### 完成内容

1. 优化书架根层文件夹卡片视觉：封面预览成为主体，前景文件夹外壳改为半透明轻遮罩和底部包边，不再大面积遮挡封面。
2. 文件夹内存在第二个资源时，书架卡片可显示一张轻微错位的背板预览；空文件夹继续显示清爽占位。
3. 进入书架文件夹内部后，按 Esc 返回书架根层。
4. Esc 优先级保持为：菜单 / 标签浮层 / 右侧抽屉 / 弹窗 / 删除确认 / 加入文件夹弹窗 / 选择模式先处理，完全没有浮层与选择状态时才返回书架根层。
5. 新增 `settings.hideBookshelfItemsInLibrary`，默认开启。
6. 普通目录视图在该设置开启时隐藏已加入任意书架文件夹的资源；收藏、书签、最近打开和书架内部视图不受影响。
7. 过滤依据优先使用 `virtualFolders.items.resourceKey`，并兼容 `sourcePath`；从所有书架文件夹移除资源后，普通目录会重新显示该资源。

### 安全边界

1. 隐藏逻辑只影响普通目录视图渲染、搜索、排序和分页计算。
2. 不删除、不移动、不复制、不修改真实漫画文件。
3. 不写入漫画目录。
4. 不新增独立 JSON 文件，仍使用现有 `settings` 持久化。

## 追加：书架命名与备注悬浮窗优化

本次只处理书架命名统一、书架文件夹卡片尺寸优化、备注悬浮显示和备注悬停延迟设置。

### 完成内容

1. 将用户可见的“加入自定义文件夹”统一改为“加入书架”，覆盖普通目录、收藏、最近打开和选择工具条入口。
2. 将加入弹窗标题改为“加入书架”，相关新建、重命名、删除、移除和提示文案统一为“书架文件夹”体系。
3. 书架根层文件夹卡片调整为更高的竖向长方形，预览区固定为更舒展的高度，名称、数量、更新时间和操作按钮保持对齐。
4. 书架文件夹备注不再常驻显示在卡片正文中，避免有无备注导致卡片高度变化。
5. 新增书架文件夹备注自绘悬浮窗，只显示备注内容，不重复显示文件夹名称；视觉为浅色半透明毛玻璃、柔和边框和轻阴影。
6. 备注悬浮窗使用 fixed 定位，并限制在窗口可视区域内，减少靠近边缘时被裁切的风险。
7. 新增 `settings.bookshelfNoteHoverDelayMs`，默认 1000ms，旧数据缺失时自动回退默认值。
8. 设置侧边栏新增“书架备注悬停延迟”，支持立即、0.5 秒、1 秒、1.5 秒、2 秒，修改后即时影响后续悬停行为。

### 安全边界

1. 仅修改用户可见文案、书架根层卡片表现、备注悬浮窗和 settings 字段。
2. 不重命名底层 `virtualFolders` 数据结构，不迁移已有书架文件夹数据。
3. 不写入漫画目录。
4. 不移动、复制、删除或修改用户漫画原文件。
