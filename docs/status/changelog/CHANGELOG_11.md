## 第 11 轮：设置面板、沉浸模式、系统全屏、批量删除

### 基础设置面板 + 阅读器全屏 / 沉浸模式

- 左侧“设置”按钮已实现，打开右侧设置抽屉。
- 设置面板集中管理卡片尺寸、每页数量、默认排序、文件夹优先、进度条、进度文本、进度文本模式、进度条粗细、阅读器默认缩放、鼠标滚轮翻页、沉浸自动隐藏和自动隐藏延迟。
- 设置仍写入现有 `omicomic-data.json`，通过 preload 安全 IPC 调用主进程保存。
- 缺失或非法配置会回退默认值。
- 阅读器新增“沉浸”按钮和 F 快捷键。
- 沉浸模式为应用内全屏覆盖，不调用系统全屏。
- 开启沉浸自动隐藏后，鼠标静止到达设置延迟会隐藏顶部栏、底部栏和书签悬浮按钮。
- 鼠标移动后 UI 重新显示。
- Esc 在沉浸模式下优先退出沉浸模式；非沉浸模式下仍返回资源库。
- 鼠标滚轮翻页可通过设置关闭。
- 适应宽度和原始尺寸模式仍保留滚动浏览。
- PDF/EPUB 禁用状态已复核，仍只识别显示，不触发阅读、页数统计或缩略图解析。
