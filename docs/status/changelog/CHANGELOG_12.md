# CHANGELOG_12

历史归档，不作为当前默认读取文件。当前状态请看根目录 `PROJECT_STATUS.md`。

## 第 12 轮：双页阅读、方向逻辑、智能跨页图、loading 状态机

### 双页阅读模式基础

- 双页阅读模式基础能力已实现。
- 阅读器支持单页 / 双页切换。
- 双页模式支持阅读方向切换。
- 双页页组翻页、页码输入、阅读进度保存与书签跳转完成适配。
- 初期实现包含封面单页、双页方向、页组推进和底部页码适配。

### 双页 UI 压缩与页码逻辑

- 阅读器顶部标题曾重构为紧凑标题区域，后续继续演进为独立文件名细栏。
- 单页 / 双页切换从中文按钮改为数字按钮。
- 双页模式底部页码不再显示 `x-y / 总页数`，统一显示当前页组阅读顺序起始页。
- 双页翻页按页组推进。

### 独立文件名栏与方向组合按钮

- 阅读器深色面板顶部新增独立 `reader-filename-strip`。
- 控制栏不再承载长标题。
- 文件名细栏单行显示资源标题与当前页名，空间不足时省略，悬停可查看完整文本。
- 顶部控制栏改为左侧“返回资源库”、右侧阅读设置与缩放按钮。
- 1/2 单双页按钮保持独立小按钮，只显示当前页模式数字，点击后即时切换并持久化。
- 阅读方向切换改为单个组合按钮，内部同时显示左右箭头；当前方向高亮，点击按钮整体切换方向并持久化。

### 方向按钮与方向翻页一致性

- 右上角阅读方向按钮改为单个紧凑堆叠式胶囊按钮。
- 阅读方向高亮改为推进方向：从左到右时右箭头高亮，从右到左时左箭头高亮。
- 键盘左右键跟随阅读方向切换。
- 鼠标滚轮保持下滚前进、上滚后退，不受视觉方向影响。
- 底部翻页按钮位置和文案跟随阅读方向切换。
- 从左到右阅读时底部为“首页 / 上一页 / 页码 / 下一页 / 尾页”。
- 从右到左阅读时底部镜像为“尾页 / 下一页 / 页码 / 上一页 / 首页”。
- 首页按钮始终跳到第 1 页，尾页按钮始终跳到最后一页。
- 阅读方向按钮内部改为固定 viewBox 的内联 SVG，不再使用 Unicode 文本箭头。

### 双页锚点与页间距

- 双页页组主索引改为当前阅读页本身，不再按“首页单独显示”或固定奇偶组重新归组。
- 双页模式下第 1 页显示为 `1 + 2`。
- 单页切双页时显示为 `N + N+1`。
- 双页翻页继续保持步长为 2，例如 `5 + 6` 的下一组为 `7 + 8`，上一组为 `3 + 4`。
- 双页底部页码继续只显示当前页组起始页。
- 双页图片容器页间距归零，两页之间不再保留中缝 gap。
- 方向切换 SVG 保持堆叠式按钮结构，并拉长内部左右箭头主干。

### 智能跨页图

- 新增 `smartDetectSpreadPage` 设置，默认开启；缺失或非法配置会回退为开启。
- 设置面板新增“智能识别跨页图：开 / 关”，修改后通过现有 `updateSettings` 持久化。
- 阅读器在图片加载完成后记录当前资源当前页组的 naturalWidth / naturalHeight 到内存尺寸表。
- 尺寸记录不写磁盘缓存，不修改漫画文件或压缩包。
- 双页模式下当当前页宽高比达到阈值时，当前页作为跨页横图单独显示，并使用双页画布宽度。
- 双页翻页改为按页组计算：普通双页按 2 页推进，跨页单页按 1 页推进。
- 上一页通过前向页组扫描计算，避免跳页和重复页。
- 智能跨页识别扩展到文件内部任意横屏页。
- 内部横图不会被前一页拼进去，下一组再以横图单独显示。
- 跨页横图适配阅读器可用宽高，适应高度 / 适应宽度 / 原始尺寸均保留各自逻辑。

### 翻页防闪与加载状态机

- 页组图片加载改为保留已有 data URL，不在翻页时先清空页面图片状态表。
- 新页组未准备好时继续显示上一组画面，并以轻量 loading 提示后台加载。
- 目标页组准备完成后再切换显示层。
- 资源切换时递增加载序号并清空显示缓冲，旧资源异步返回不会覆盖当前画面。
- ReaderPage 当前页组加载改为明确 `idle / loading / ready / error` 状态。
- 每次正式页组加载都会生成新的 requestId，只有最新请求可以更新当前页组状态。
- 正式页组加载增加 10 秒超时兜底，超时后结束 loading，并将未完成页面标记为失败占位。
- 文件夹图片和 ZIP/CBZ 当前页组读取统一走 `Promise.all` 收口，一张成功一张失败也会结束 loading 并显示部分结果。
- data URL 获取成功即可进入可显示状态，`img onLoad` 不再作为 loading 结束的唯一条件。
- 保留已有可显示页组缓冲，避免重新引入翻页闪烁。

### 快速打开多资源竞态

- 快速点击多个文件打开阅读器时的旧请求覆盖问题已修复。
- ReaderPage 在资源切换时会重新挂载，避免旧资源加载状态残留。
- 资源库打开阅读请求加入序号防护，最后一次点击优先。
- 阅读器图片读取加入主进程会话防护，旧资源的图片 IPC 不再占用当前阅读会话。
- ReaderPage 打开序号纳入 React key，即使资源 key / 起始页重复也会强制清理旧加载状态。
- `LibraryPage` 为目录、最近打开、收藏、书签的打开阅读流程统一加入打开请求序号。
- `getResourcePages`、`getReadingProgress` 等异步步骤返回后会校验当前序号。
- `getPageImage` 请求携带 `readerSessionId`，主进程只接受最新会话。

### 资源库分页加固

- 资源库目录视图继续只渲染当前页切片。
- 网格显式从起点排列，禁止自动拉伸行高。
- 搜索、排序、文件夹优先、卡片尺寸、每页数量、实际每页数量和目录变化时，会复位目录滚动状态并清理连续滚动翻页锁。
- 分页栏新增“顶部”按钮，只滚动当前页列表到顶部，不改变页码、搜索、排序或筛选状态。

### PDF/EPUB 状态

- PDF/EPUB 始终保持只识别显示，不触发阅读器或 PDF.js / EPUB.js。
