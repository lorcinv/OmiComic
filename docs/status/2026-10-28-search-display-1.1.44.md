# 1.1.44 搜索显示与随机返回修复

两端搜索先显示匹配文件夹，文件夹发现完成后再接上漫画资源。每批新结果追加到已有结果之后；已有卡片更新元数据时保持原位。改变关键词、筛选条件或排序，以及手动刷新，会重新计算结果。退出随机阅读时保留原搜索词和已固定的顺序。

连续列表不再为每次追加重设滚动位置。原先停在末页时，新增结果不会把当前页码直接改成新末页；返回已浏览位置时按资源身份恢复。搜索停留期间取消两分钟定时重查，过期清单在下一次进入搜索或手动刷新时更新。

PC Esc、手机返回优先退出随机阅读，第一次操作保留搜索、弹层和目录位置。Android 键盘展开时也先退出随机，再按后续返回处理键盘和搜索；阅读器自身的返回流程保持独立。

25 项逻辑检查和 8 项界面检查通过，覆盖搜索语法、旧查询取消、分批追加、随机退出恢复、跨页衔接、窗口与卡片密度变化、路径排除，以及模拟超过两分钟的停留。浏览器用 800 项受控分批数据检查两种布局；Android 15 模拟器成品用 164 个真实 SAF 条目和 3 批受控发现结果，确认当前卡片、偏移和页码不跳动，并通过实际触摸和系统返回检查优先级。本次未重新做全库扫描性能验收或实体手机验收。

Windows 与 Android 版本统一为 1.1.44，Android versionCode 为 10144，沿用原签名。PC 安装位置为 `D:\software\OmiComic`；安装前后用户数据的 SHA-256 一致。此次为本地交付，未发布到 GitHub。
