# OmiComic 1.2.1 侧栏样式修正

本轮保持版本号 1.2.1，仅修正 Windows / macOS 阅读设置侧栏的半透明毛玻璃，并替换现有发布页的桌面附件。Android APK 保持原文件，按钮布局、阅读逻辑和数据格式不变。

## 原因与改动

桌面主题的 `.reader-tool-panel` 使用不透明背景，覆盖了共用菜单的半透明底色。先前检查到 `backdrop-filter` 存在，但没有验证背景透明度，导致发布包视觉上仍是实色。

在 `src/styles/desktopTheme.css` 为桌面阅读侧栏添加专属规则，采用现有菜单的 78% 主题底色、18 px 背景模糊及 1.16 饱和度。应用改动只有这一处样式规则；构建源码为 `cc2d7112f5c78062927f600f6e7ef707fda5dcf2`。

## 验证

- 类型检查、Windows 安装版和便携版构建通过。
- 浏览器及 Windows 实际成品检查了 mist、nord、sand、night 四种主题：侧栏背景透明度约 0.78，模糊生效，顶部覆盖和 360 px 宽度保留。
- 用彩色条带和细线铺满侧栏背后，对照实色背景、仅透明和毛玻璃三种状态；实际截图确认底色能够透出，细线被模糊，控件文字保持清晰。
- 两项既有侧栏检查通过，覆盖展开全部控件、阅读区域尺寸、顶部按钮遮挡、主题选中态、点击外部关闭与防误翻页。
- Windows 成品验证全程隐藏窗口，使用独立测试数据，不改动日常阅读记录。
- Apple Silicon 和 Intel Mac 的构建及实际应用检查均通过：[本次构建记录](https://github.com/lorcinv/OmiComic/actions/runs/43704036731)。

本轮未重复上一轮的启动和翻页性能测量，不据此新增性能结论。模糊范围限于打开的阅读设置侧栏。
