# 1.1.75 Omi 图标细线与最近阅读闪动修复

2026-11-03，Asia/Hong_Kong。Windows、Android 版本均为 1.1.75，Android versionCode 10175。

## 原因与修改

- 图标为 `OmiBrandIcon.tsx` 中的 SVG。圆环内部存在半径 22 的高光弧线，以及两层内缘描边；它们在深色背景上表现为细线。本版移除这三处装饰线，保留外部轮廓、灰色环体、白色嵌片和双眼。手机专属的旧内缘隐藏规则一并移除，两端共用相同形状。
- 首页准备最近阅读时，原 `readDisabled` 把品牌按钮临时禁用，图标专属样式及全局按钮样式都会降低其透明度；读入很快时就形成一次明暗闪动。本版区分忙碌和不可用状态：忙碌时仍禁用点击以阻止重复打开，但透明度固定为 1；真正无阅读记录或初始化时沿用原不可用提示。
- 首页最近卡片打开、失败恢复都使用新状态。资源库“最近阅读”栏目切换保留原品牌节点；直接点击图标仍保留原眨眼续读、转动与视线跟随。
- 没有修改阅读解码、图片质量、缓存预算、翻页手势、进入动画或书架计数。

## 验证

- 类型检查通过；阅读预热和进入所有权 DOM 检查 8 项通过。
- 浏览器 21 项通过：两端深色/浅色环面像素检查、最近阅读打开和失败期间逐帧透明度、重复打开保护、最近阅读栏目、首页转场、手机触摸目标与卡片位置等。环体内部采样为同一灰色，最近卡片打开期间透明度始终为 1，没有触发眨眼状态。
- Windows 使用实际安装器解包后的程序和独立数据目录核对版本、深色图标、真实最近阅读打开及直接点击图标的既有行为。
- Android 使用最终 APK 和专用 Android 15 模拟器核对夜色图标、原生最近卡片点击、加载失败恢复与正常进入；未做实体手机测试。最终结果、截图、包内资源与源码校验随交付保存。
