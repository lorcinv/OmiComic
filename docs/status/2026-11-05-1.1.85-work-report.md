# OmiComic 1.1.85 工作报告

本轮更新 Android 与 Windows，处理平板入场顶部闪动、漫画卡片蒙版和系统主题跟随。

| 项目 | 本轮结果 |
| --- | --- |
| 平板进入阅读时顶部闪动 | 入场截图覆盖到状态栏背后的顶部背景，避免阅读页提前从顶部露出；状态栏显隐与转场开始同步，重复的显隐和同色更新不再发送。保留上一版固定阅读画布的处理。 |
| 安卓漫画卡片点击蒙版 | 浅色主题从 10% 调至 17%，夜色调至 15%；保留主题色、按下渐显与释放淡出，卡片本身保持不透明。 |
| 双端跟随系统主题 | 默认关闭。开启后，系统浅色模式使用所选的雾灰／北境／暖沙，系统深色模式使用夜色；自动切换保留日间选择。系统浅色时，“夜色”置灰且无法通过鼠标、触摸或键盘选中。 |
| 开关位置 | 安卓位于“界面主题”上方；Windows 位于四张主题配色卡片下方。中、英、日文标签均已补齐。 |

跟随依据是系统当前的浅色／深色模式。系统若设置了定时深色，OmiComic 会随其切换。深色期间也可调整日间配色，界面继续使用夜色，“日间配色”提示会显示新的选择。关闭跟随后恢复手动主题选择。

安卓直接读取系统 uiMode，并处理系统切换与返回前台；启动时也先确定系统模式，再显示应用界面。这样可以避开固定浅色应用主题对 WebView 媒体查询的影响。[Android WebView 主题规则](https://developer.android.com/develop/ui/views/layout/webapps/dark-theme)。Windows 监听系统外观变化并实时更新，无需重启。[Electron 系统主题规则](https://www.electronjs.org/docs/latest/api/native-theme)。
