OmiComic 1.1.53：缩放还原与手机普通分页

本轮改动限于缩放还原、手机单页／双页的拖动和松手动画，以及缩放期间的画面保留。版本号维持 1.1.53，保留前序缩放按钮配色、纯文字和标签间距修复。没有发布到远程仓库或替换用户正在运行的安装版。

参考来源与边界：

- 指定的 EhViewer 上游 revision `9e1021640472ee45f35c0bb1950723db08549b9e`，另存于 `.cache/ehviewer-neko-9e10216/`；未将本地旧 `lorcinv/EhViewer-test` fork 当作指定上游。
- `PagerLayoutManager.java` 的 `SmoothScaler` 使用 300 ms 和 `LinearOutSlowInInterpolator`；`SmoothScroller` 使用五次减速曲线，按帧更新已有图片，并在新触摸时取消动画。Omi 迁移其时序，保留自己的页组、缓存和画面几何。来源、版权和 Apache 2.0 许可随两个安装包一并提供。
- 用户 ComicScreen APK 与既有解包 APK 的 SHA256 均为 `a565e7469804864e342a52188327994237c04952e548fb55d80038ed6cfa5baa`，包名 `com.viewer.comicscreen`，版本 2260。定点检查既有 JADX 输出的 `ImageViewPager`、`ImagePhotoView`、`H0/m.java` 和 AndroidX `ViewPager`。其交互特点包括直接按位移滚动、最近松手速度、距离／速度决定完成时长、图片缩放优先于分页。没有复制商业 APK 的业务实现。
- REA 的 Android 提供程序缺少所需的 `REA_JADX_MCP_JAR`；本轮未修改 REA 或客户端配置，APK 结论来自已核对摘要的独立 JADX 解包资料，不宣称为本轮 REA 会话证据。

修改内容：

| 文件 | 本轮内容 |
| --- | --- |
| `src/reader/transitionAnimation.ts` | 可取消的逐帧动画，缩放和翻页曲线，遵循系统减少动画设置；运动期间暂缓旧画面的重新取样。 |
| `src/hooks/useReaderZoom.ts` | 用户还原时在 300 ms 内同时归还比例与位移；新的触摸、滚轮或比例输入打断当前动画；切换资源／模式和卸载仍立即清理。 |
| `src/hooks/useReaderDisplaySampling.ts` | 还原过程中保留已显示的取样图或原图，停止后再取样；新取样任务开始时不隐藏已显示的原图，关闭空白窗口。新页仍按既有准备流程显示。 |
| `src/hooks/useMobilePageSwipe.ts` | 消除“等邻页准备好才突然移动”的门槛；按手指位移连续跟随，采用已有最近 120 ms 速度估算；按剩余距离和速度减速完成／回弹，支持反向与新手指接管，首尾页有限阻尼。 |
| `src/pages/ReaderPage.tsx` | 主画面与邻组接收同一逐帧位置，移除独立的 160 ms CSS 动画；手机普通分页手势由新流程统一处理，避免短拖回弹又落入旧快速翻页。 |

本轮未改动 `NativeReaderSurface.java`、`useNativeReaderSurface.ts`、`displaySampling.ts`、全景惯性算法、解码滤波、缓存预算与预加载机制。Android 原生层继续通过几何消息接收每帧位置；这次改为逐帧改变实际位置，因此不再依赖 CSS 动画头尾的样式通知。

验收输入说明：专用安卓模拟器的同步输入注入曾将短按延长约 5 秒，导致“点按”被识别为长按。交互验收改为有固定真实时序的输入队列，并等待两帧确认位置；这是测试工具改动，不改变安装包输入处理。
