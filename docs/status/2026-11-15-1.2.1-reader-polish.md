# OmiComic 1.2.1 工作报告

本次包含桌面阅读侧栏、Android 操作反馈与预览方向、跨页拆分，以及 EPUB 空白页和 GIF/JPG 混合排序修复。交付 Windows 安装版与便携版、Android APK、Apple Silicon 和 Intel Mac 的 DMG / ZIP。

同日补充：首批桌面包的侧栏背景被桌面主题规则覆盖，未实际呈现半透明毛玻璃。原检查只确认了模糊属性，遗漏了实色背景覆盖；已在同一版本中修正并重新核对截图，见[侧栏样式修正记录](2026-11-15-1.2.1-sidebar-glass.md)。下文性能数据和原始构建记录仍对应首次发布时的测量。

## 功能与修复

### 桌面阅读设置

- 横向三点位于沉浸按钮右侧；适应方式、跨页拆分、全部画面调整直接展开。
- 侧栏从窗口顶部开始覆盖，移除右上角关闭叉，沿用阅读浮层的毛玻璃背景。
- 点击外部关闭时消费完整的按下、松开和点击事件，不会顺带翻页；下一次主动点击仍可正常操作。Esc 关闭保留键盘焦点。
- 适应方式和拆分按钮默认灰色，选中时使用当前主题的深色强调色；核对了四种主题。

### Android 阅读操作

- 沉浸位于画面调整右侧，启用后恢复主题强调色。
- 阅读按钮松手即清除按压效果，触屏不再继承鼠标悬停色；资源库卡片保持原来的反馈。
- 预览条的显示顺序、拖动选页、点击选页和定位跟随左右阅读方向。继续使用原有虚拟列表与浏览器惯性滚动，没有创建整本缩略图。

### 拆页与数据

拆页默认关闭、按本书保存。普通单页模式下，图片和 PDF 中宽高比至少 1.2 的横页从中间分开；横向插画也按同样规则处理。双页和全景模式显示完整原页。

页数沿用原始总页数，显示 `12L/100`、`12R/100`，L/R 表示原页的物理左半/右半，翻页顺序跟随阅读方向。书签和续读保留具体半页，读到最后一页的第一半不会提前标记读完。拆分仅改变显示，共用原图或 PDF 页面数据，不生成切开的图片，不写入原文件。

本次没有加入目录识别或镜像功能。

### EPUB 空白页

复现了带 XML 命名空间前缀的 EPUB：例如 `h:img`、`s:svg` / `s:image` 在 Android 的 HTML 解析中保留前缀，原过滤逻辑未能识别，可能把图片删除后仍返回空章节。现在统一识别标签的本地名称，保留允许的正文与本地图片，同时过滤脚本、外部嵌入和头部元数据。

带前缀的 XHTML 图片和 SVG 包裹图片均通过当前浏览器及 Chromium 100 检查。小新 GT11 的反馈没有原始 EPUB、系统/WebView 版本或实机复现；此次修复覆盖已证实的问题，不能认定已解决该设备上的所有白屏原因。

### GIF / JPG 混合排序

用户提供的 `00013.jpg` 到 `00026.jpg` 序列可复现：`00016-GIF.gif`、`00021- GIF.gif` 等名称被共用规则判定为非编号页，放到了编号 JPG 后面。Android 原生目录排序本身正确，后续共用的页码整理重新改变了顺序，桌面阅读路径也受同一规则影响。

现在识别页码时忽略末尾的格式标记，仍保留原文件名、内部路径、稳定页标识和书签对应关系。原有封面优先、混合扫描前缀、字母子页、目录分组及多组数字不猜页码的规则保留。升序、降序、同时间排序、旧书签定位、Android 文件夹/压缩包接口及桌面实包均有验证。

## 性能对照

同一台 Windows 电脑，对照已发布的 1.2.0 便携版和最终 1.2.1 成品。两版交错启动，各测 5 次首页；阅读使用 16 张 2400×1600 PNG，每种条件测 3 轮、每轮往返翻页 60 次，共 540 次。使用独立配置和相同缓存档位，窗口始终隐藏；在窗口创建后统一关闭后台限速，测试时没有并行构建或其他测试。

| 指标 | 1.2.0 | 1.2.1 普通单页 | 1.2.1 开启拆页 |
| --- | ---: | ---: | ---: |
| 首页就绪中位数 | 389 ms | 404 ms | — |
| 直接打开图片就绪中位数 | 498 ms | 484 ms | — |
| 翻页就绪中位数 | 5.4 ms | 5.3 ms | 4.4 ms |
| 翻页就绪 P95 | 9.1 ms | 7.8 ms | 11.4 ms |
| 首页进程工作集合计中位数 | 316.6 MiB | 314.1 MiB | — |
| 连续翻页后进程工作集合计中位数 | 802.5 MiB | 806.9 MiB | 788.3 MiB |

首页中位数增加约 15 ms（3.8%），两版样本范围分别为 379–410 ms、359–429 ms，区间重叠。这组样本未显示明显的启动或常规阅读性能衰退。拆页的翻页就绪 P95 比本版不拆页高 3.6 ms，内存没有随半页数翻倍。

“翻页就绪”测量点击到页码更新且显示图片已解码，以 5 ms 间隔检查；不等于屏幕呈现时间或帧率。内存是 Electron 各进程工作集合计，并非独占内存。系统文件缓存未清空，属于同机重复启动对照，不是重启电脑后的冷启动，也不代表小新 GT11 的速度。初次测量受隐藏窗口动画限速影响，已废弃该轮翻页耗时，没有把它计入表中。

10 次首页测量在可用时都没有加载阅读模块；19 次有效启动未记录到页面脚本错误。源代码复查及原生检查确认：拆页复用原始页面缓存，Android 预览维持按需渲染，未改为全书预处理。[测量数据](2026-11-15-1.2.1-performance.json)。

| 首次失败，独立复测通过 | 4 | EPUB 字体等待、桌面预取、横向/反向全景切页；含同组相邻场景共 6 项复测通过 |

36 项旧版同样失败的用例涉及已移除的关闭按钮、预加载元素计数、旧默认缩放/颜色断言、目录与搜索流程、虚拟列表定位、移动端手势，以及模拟缺失 API 的 PDF 测试重载时序。它们并不等于 36 个已确认的产品缺陷，但仍需整理或进一步排查；本次没有通过删除、跳过这些用例来把全量套件标成通过。

默认适应方式、焦点与三语说明的复测共 17 项通过；大图处理及手机布局切换另有 1 项通过。完整结果按首次运行与后续复测分别记录，没有将部分重测包装成第二次完整 620 项通过。
