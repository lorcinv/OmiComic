# OmiComic Windows 1.1.24 工作报告

日期：2026-10-16。本轮只调整 PC 配色、资源卡片和目录计数显示。Android 沿用已交付的 1.1.23。

## 交付

- [Windows x64 免安装 ZIP](../release/OmiComic-Portable-1.1.24-x64.zip)，140,661,768 字节，约 134.1 MiB。完整解压后运行 `OmiComic.exe`，沿用本机已有阅读记录。
- SHA-256：`5e0a7bbf24e54b28ed149e7f11009a76e8d29a7b2fcabc70cd4f4be0cd121d1c`。[校验文件](../release/OmiComic-Portable-1.1.24-x64.sha256)
- 本轮未上传 GitHub，也未生成新的 Android APK。

## 改动

1. **配色**：PC 与手机共用雾蓝、北境、暖沙、夜色四套主题。修正阅读进度浮层、文档保存错误边框与外部打开错误阴影中的固定颜色；卡片保留失效资源的提示色。
2. **卡片**：资源库、书架内资源、收藏、书签、临时存放和最近阅读统一移除封面标签与标题下路径。收藏改为透明底白色爱心，收藏后使用主题收藏色；详情改为底部信息行右端的横向三点。详情和右键菜单仍可查看、复制路径。
3. **信息与空间**：标题单行截断，普通卡片显示页数／百分比与已知文件大小，书签显示页码和日期；不再显示文件类型、书架类别和页数胶囊。内边距、标题区与行间距缩小，进度条贴底。保留七档卡片尺寸、双击、右键、中键排序和键盘操作。
4. **目录计数**：增加实际子文件夹数量作为显示依据。没有子文件夹就不显示“X 项”，未知文件不计入；图片漫画仍显示页数和阅读进度。合集分类、打开方式和借用子资源封面的规则保持原实现。

## 验证

- `npm run dist:portable`：类型检查、前端、Electron 与 Windows ZIP 构建通过。
- 文件夹分类与缩略图测试 5 项通过，覆盖图片、未知文件、独立文档和嵌套目录。
- 浏览器相关回归分批完成，共 36 项通过：卡片布局／操作、连续滚动、PC 阅读进度与双页、书签重命名、提示浮层、主题切换和手机既有布局。旧卡片文案、旧固定颜色和卡片变矮后的可见行数断言已更新。
- 最后一处样式修正后，紧凑卡片与四套 PC 主题再次检查，5 项通过。检查包括详情、标签编辑、标签管理、书架／分类弹窗、全部设置分类和阅读工具；未发现旧色、背景渐变或页面横向溢出。
- 实际 Windows EXE 的 PDF／EPUB／合集封面检查通过：7 个真实封面、2 个格式图标回退，覆盖无子目录不显示项目数、有子目录显示项目数及双页进度。
- 最终 ZIP 解压运行结果见 [交付包验证](../test-results/portable-smoke.json)，覆盖图片、ZIP、7z、PDF、EPUB、阅读适配、阅读工具、130 个目录连续滚动和大封面。

额外运行的旧 `tests/document-reader.electron.cjs` 综合测试未通过：它在恢复“适应宽度”的 PDF 后固定要求同时显示两页，实际只显示一页；现有阅读布局规则仅在两页能完整放入窗口时配对。诊断过程中旧全景动画断言也未通过。未把这项列为通过，未为本次卡片调整修改阅读器；书签卡片本身由浏览器回归验证。阅读器及手机相关源文件与本轮基线的哈希核对见 [改动范围记录](../test-results/pc-ui-1.1.24-scope.json)。
