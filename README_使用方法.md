# OmiComic 使用方法

Windows 1.1.37：解压整个免安装包，双击 OmiComic.exe。

- 设置 → 关于 OmiComic：查看 Omi 介绍、当前版本及 GitHub 项目主页。手机和 PC 均可打开项目链接。
- 设置 → 外观与主题 → 主界面图案：选择 PNG、JPG、WebP、BMP 后打开裁剪窗口；可输入宽高、选择比例、缩放、拖动位置，并查看四周羽化后的效果。“保存图案”应用到首页，“调整裁剪”可从原图副本重新裁剪，“恢复默认”恢复默认插画。图片不超过 20 MB，移动原图不影响显示。
- 设置 → 外观与主题：切换简体中文、English、日本語，通过“− 数值 +”调整全局字号和页码信息字号，也可输入 10–24 的自定义数值。页码信息标准为 12，全局以 14 为原界面标准。
- 设置 → 阅读器：选择自动、均衡、高性能或自定义性能；可启用普通阅读工具栏自动隐藏，鼠标移至顶部或底部重新显示。
- 自动性能按电脑配置分配；32 GB / 16 线程电脑约为 4096 MB 图片缓存、48 页预读、12 路加载。预读提前完成原尺寸图片解码。旧版 500 MB / 5 页 / 5 路配置升级一次后使用自动模式，之后仍可自定义。
- 阅读中的“画面调整”修改参数直接生效，无需勾选开关；“恢复默认”显示原图。PC 仅详情标题、阅读标题和输入框支持拖选文字。
- 资源库、收藏、书签、最近阅读和书架均连续滚动，底部数字可直接跳转。标题显示两行，悬停标题查看全名；右侧三点打开详情。
- PC 详情页简介双击正文编辑，点击外部自动保存。缩略图双击打开对应页，单击不选中；键盘 Enter 或空格也可打开。
- 首页最近阅读双击卡片进入，或点击悬停显示的“继续阅读”。
- 中键拖动卡片，目标卡片外缘显示一圈高亮描边；松开后移动到该卡片的位置，移出卡片或回到原卡片则取消。书架分类上下浅白横杠固定在轨道首位，向中间有轻微光效，分类文字从中滑过。


适用版本：Windows 1.1.37（x64）/ Android 1.1.38（Android 8.0 及以上）。

## 手机 1.1.19 操作

首页底部「设置」直接进入设置，返回仍回到首页。在「设置 → 外观与主题 → 语言」选择简体中文、English 或日本語；界面立即切换，重启保留选择，漫画文件名、标签及简介保持原文。叠加菜单和弹窗共用一层遮罩，首次进入线性变暗，换层不重复变灰。漫画阅读设置移除当前漫画选择，速度项显示为「全景滚动速度」；性能与缓存保留容量、用量和清理功能。关于页提供手机版操作简介。

资源库、书架、收藏、书签和最近阅读各自保存卡片模式、网格列数和列表封面尺寸。显示选项只改变当前栏目；设置→外观与主题可选择要调整的栏目。最近阅读和书架内漫画长按「打开路径」会进入所在目录，并采用资源库自己的显示方式。详情文件名可长按复制，其他展示文字不弹出系统复制框；搜索、标签和简介的编辑输入仍可正常选择文字。

首页轻触直接阅读，长按才显示继续阅读。底栏按栏目位置左右衔接，目录居中渐变，详情以同一封面衔接；最近阅读长按可打开所在目录。拖动预览优先加载选中页并复用原生已解码画面；换书取消过期工作并收缩旧缓存。 设置→性能与缓存中的内存容量和预加载页数同时控制相邻页准备；预加载设为 0 可停用。

卡片显示「当前页/总页数 · 百分比 大小」，例如 `10/12 · 83% 0.4MB`，不加胶囊底色；书签页码与创建日期同排，首页最近阅读不显示「页」字。侧栏支持平滑滑入和跟手滑出，退出不回闪，已缓存目录立即呈现。点击漫画直接打开，目录切换等待期间保留原列表，不闪现文件名或加载提示。拖拽预览为 50% 无模糊半透明，选中框在卡片内绘制，全景跳转不会遮挡上下操作栏。雾蓝底色为柔白，北境保留冰雪蓝灰。

全景阅读可切换左右顺序。标签长按编辑，简介可长按或点击编辑；点非编辑区退出并保存简介。左滑打开标签管理，资源库侧栏的三点可移除资源库索引，原始文件不受影响。书架以三层封面显示，后两层取内部第二、第三个资源。

- 首页显示最近四本漫画，底栏为进入资源库、刷新、设置。未加入目录的文件只记录在最近阅读中。
- 资源库左上角三横杠打开目录树，右滑呼出、左滑关闭；箭头展开层级，名称直接切换目录；长按根目录调整顺序。树索引跨重启保存，刷新或文件操作后更新，无子目录不显示展开箭头。书架左侧打开分类，可新建分类、新建书架。
- 顶部搜索将名称、标签与备注合并。中英文逗号分隔条件；设置→资源库→搜索匹配方式中，模糊匹配任一条件，精准要求所有条件。空格为同时匹配，引号组合词语，`-词语` 排除，`tag:标签` 限定标签，`name:名称` 限定名称、`note:备注` 限定备注，`|` 表示任选一项。
- 右上角三点打开显示选项，设置网格列数、列表封面大小与资源库默认排序。此排序不改变书架手动顺序；标签管理打开右侧抽屉，可长按排序、选择删除，不设置搜索框。
- 网格点击卡片直接阅读；列表点击封面进详情、点击文字阅读。长按显示底部操作栏，选择可多选；书架、收藏、书签可进入排序后拖动卡片。
- 阅读点中央显示工具栏，三点打开设置，进度条最右侧启动自动阅读。左侧显示当前页（双页为 `x~z`），右侧显示总页数；从右到左阅读时交换两端数字。拖动实时翻页并唤出缩略预览，滑动预览精调、点击选页，点击外部直接关闭预览。全景拖动连续滚动，只有点击进度条播放跳转动画。双指缩放，双击恢复默认；画面调整应用于所有漫画。
- 自动阅读启动后显示双竖线图标，点击漫画、手动翻页或跳页后继续运行；操作手势和打开设置时临时停留，结束操作后继续。再次点击按钮停止，恢复三角形。离开阅读页、进入后台、遇到错误或读到结尾时停止。
- 返回键／手势先关闭最上层菜单、弹窗或选择模式，再返回详情、目录或首页。设置中的音量键翻页可选择正向或反向，并设置全景翻页间隔。
- 手机每次打开漫画使用适应窗口，旧的按本缩放设置不覆盖此默认。阅读三点中可关闭拖动预览；应用设置的外观中可调预览宽度。
- 书签长按选择重命名书签，只改软件内显示名称。书架长按可重命名、重置封面、删除、置顶或排序。
- 连续资源列表底部浮钮显示页数，尖括号移动到上一组或下一组，点击中间数字输入页码；资源库设置可选每组 50／100／150／200／500 项。详情页滚过缩略预览标题后显示同款浮动分页栏。再次点击当前底栏：资源库回所选根目录，书架回分类最外层，收藏／书签／最近阅读回顶部。
- 详情页的「添加标签」只修改标签，「简介→编辑」只修改简介。长按现有标签，或添加标签后，可点击标签旁的叉号移除；点击非标签区域退出编辑。
- 设置保留外观、资源库、默认阅读、每本漫画阅读设置、性能与缓存、安全与确认和关于七个入口。

## Windows 旧版安装程序（1.0.2）

1. 从 [GitHub 发布页](https://github.com/lorcinv/OmiComic/releases/tag/v1.0.2) 下载 `OmiComic-Setup-1.0.2-x64.exe`。
2. 运行安装包，选择安装目录并完成安装。
3. 从桌面或开始菜单的 OmiComic 快捷方式启动。

安装器会注册系统应用信息和“打开方式”，不改变当前默认文件关联。本版本未做数字签名，首次运行可能显示系统发布者提示。

源码用户应先 `npm run build` 再 `npm start`；只更新源码不会改变已经生成的程序。安装版使用安装目录中的程序，开发用的 `OmiComic.cmd` 使用当前项目的构建文件。

手机「设置 → 性能与缓存」中，可分别调整阅读页面磁盘缓存（默认 512 MB）、封面与预览磁盘缓存（默认 128 MB）以及阅读图片内存缓存。阅读磁盘缓存总预算内，最多 128 MB 用于保留大 PNG 的清晰底图，其余用于阅读期间的临时原页；退出漫画后清理临时原页与整包复制副本，保留清晰底图方便重开。清理不会删除漫画或阅读记录。

## Windows 1.1.37 免安装版

使用本次交付的 `release/OmiComic-Portable-1.1.37-x64.zip`，完整解压后双击 `OmiComic.exe`。GitHub 发布页：https://github.com/lorcinv/OmiComic/releases/tag/v1.1.38。不能在 ZIP 中直接运行，也不要单独移动 EXE；同目录的 DLL、`resources`、`locales` 都需要保留。

PC 卡片采用手机的信息排布：封面不显示标签，右下角为透明爱心；下方仅保留两行标题、页数／进度与已知文件大小，右端三点打开详情。资源库、书架内资源、收藏、书签、临时存放和最近阅读都不在卡片标题下显示路径；路径仍可从详情中的「路径」按钮或右键菜单查看、复制。进度条紧贴卡片底边。1.1.26 将 PC 雾蓝改为雾灰，普通按钮为浅灰蓝，关键操作保留蓝色，详情、阅读器与设置同步主题。

阅读器设置不再提供“当前漫画”下拉选择。在详情页打开设置时，页面排序、翻页间隔和滚动速度作用于该漫画；从资源库打开时，作用于最近阅读的漫画。原有按本保存的设置继续保留。“上/下一篇按钮透明度”调整阅读边界出现的换书按钮。

1.1.5 保留大压缩包封面与删除窗口修复，增加实时进度拖动、单／双页数字浮层（按实际页数、半透明、靠近滑块显示）、Ctrl＋滚轮缩放与左键平移。阅读默认适应窗口；左下角「重置大小」恢复设定尺寸。详情返回在左侧，重命名和删除在右侧；标签管理只滚动全部标签区域。

免安装版无需 Node.js，不运行安装向导、不创建快捷方式、不注册文件关联。更新时关闭程序，将新版解压到新文件夹即可；移除时删除解压目录。

阅读数据保存在本机 `%APPDATA%\OmiComic\omicomic-data.json`，与安装版、开发版共用，因此重新安装或换成免安装版后会继续显示旧记录。发行 ZIP 不含任何用户的漫画、收藏或阅读记录，应用不提供云同步；复制程序目录到别的电脑不会自动带走记录。删除程序目录不会删除漫画原文件或本地记录。

## 首页与资源库

- PC 首页显示最近三本及页数/章节进度，双击卡片或点击悬停出现的“继续阅读”；手机显示四本，轻触卡片继续阅读。
- “我的资源库”进入资源整理界面。
- 资源库左上角 OmiComic 文字返回首页；旁边图标用于继续阅读。
- 左下角“添加目录”导入本地漫画根目录；选择目录后即可浏览子文件夹、图片和文档。
- 双击可读资源打开阅读；无图片的父文件夹进入下一级。
- 手机端单击打开，底部切换资源库、书架、收藏、书签和最近阅读；长按打开底部操作栏。
- 三个点打开资源信息；爱心切换收藏；右键提供当前视图可用的整理操作。

## 本地重命名与删除

- 在资源卡片菜单或详情点击“重命名”，输入新的本地名称，保留文件扩展名。阅读记录、收藏、书签、标签和书架引用一起更新。
- 点击“删除…”时默认选择“仅移除索引”：保留原文件，清理该资源的关联记录，并从目录列表隐藏。资源库的“恢复文件索引”可重新显示这些文件，不恢复已清理的进度与整理记录。
- Windows 中选择“同时删除本地文件”会移入回收站；回收站操作失败时不会改为永久删除。
- Android 中选择“删除本地文件”会永久删除。删除文件夹包含其全部内容，弹窗会显示目标路径并要求单独确认。
- 根目录使用原有的“移除根目录”操作。禁止通过本地文件操作删除整个已授权根目录。

## Android 安装与使用

1. 将 `release/OmiComic-1.1.18-android.apk` 复制到手机并安装。已安装此前版本时直接覆盖安装，保留记录，不要先卸载。
2. 进入资源库，点左上角三横杠打开目录侧栏，点击「添加目录」并授权；这里也能切换目录或直接打开文件。右上角网格／列表按钮切换卡片，放大镜将顶栏变为统一搜索框，三点打开显示选项。
3. 网格点击封面或文字阅读；列表点击封面进入详情、点击文字阅读。左右滑动或点击页面两侧翻页，点击中央显示或收起工具栏。全景模式继续支持拖动与惯性。
4. 系统返回键先关闭当前菜单、弹窗、选择模式和设置子页，再退出阅读、详情或子目录，最后返回首页。阅读进度在翻页、返回和进入后台时保存。

手机端支持图片目录、图片、ZIP/CBZ、RAR/CBR、7z/CB7、PDF 和 EPUB。压缩包可以直接点击阅读，无需手动解压；支持 RAR4、RAR5 及固实归档，暂不支持密码或分卷压缩包。本地可定位文件直接读取；仅流式文件提供程序的单本缓存上限为 1 GB。封面后台任务不复制整个文档。单文件授权不能访问同目录中的其他文件；需要浏览整本图片漫画时请使用“添加目录”。

阅读时点中央，再点右上角竖向三点，即可调整阅读模式、缩放、画面效果和音量键。播放按钮在进度条最右侧。启用「音量键翻页」后，音量＋上一页、音量－下一页，也可勾选反转方向；默认关闭，退出阅读、进入后台或打开面板时恢复系统音量操作。音量键设置也可从应用「设置 → 阅读器」修改。

每本页面排序、自动翻页间隔与全景滚动速度可从阅读设置中选择。图片目录与归档支持修改时间排序；文件提供程序或归档没有记录时间时会说明限制。画面调整在手机上全局保存，中性参数不改变原图。深层目录封面分段查找，找到后缓存并跨重启复用；外部改动后可在资源库右上角三点中刷新。

桌面图标沿用 Omi 灰蓝配色，支持系统圆形、圆角方形裁切，以及 Android 13+ 主题单色图标。APK 已使用持续保存的发布密钥签名。

Android 的阅读数据保存在应用私有目录，卸载会删除这些记录；漫画原文件仍在所选目录中。撤销目录权限后，需要重新选择并授权。

## PC 临时存放

安装后可在资源管理器中右键文件，选择“打开方式 → OmiComic”。也可以使用“临时存放”底部的“打开文件”。

尚未属于资源库的文件会出现在左侧“临时存放”，位置在“最近阅读”上方。这里与其他资源视图共用卡片、搜索、标签、收藏和书架逻辑。

- **删除临时引用**：只移除这里的条目，原文件、标签、收藏、书签和进度保留。
- **将所在目录加入资源库**：导入该文件的所在目录，目录内的临时条目自动归入资源库。

单张图片打开后，所在目录中的其他支持图片组成阅读列表，并定位到所选图片。

## PC 缩略图与详情

“视图”、设置和详情工具栏均提供七档缩放滑条。由左向右分别是每行 7、6、5、4、3、2、1 张，默认四张。拖动滑块或按 Ctrl＋滚轮切换，上滚放大，下滚缩小；聚焦滑条后也可用方向键。

每档根据当前内容区宽度均分卡片，窗口最大化或还原会重新适配。最后不足一行的卡片保持当前档位宽度。资源列表与详情缩略图分别记忆自己的档位。

点击“视图”外部空白或按 Esc 可关闭菜单。刷新与失效资源检测在顶部“选择”右侧。合集文件夹取首个可读子资源的封面；存在子文件夹时显示“X 项”，计入子文件夹和支持的独立文档，未知文件不计入。没有子文件夹时不显示项目数，图片漫画仍显示阅读页数与进度；没有封面时显示对应格式图标。

详情页中：

- 下滚先收起上方封面和简介，随后滚动缩略图。
- 上滚到首排后，继续略加滚动才展开详情。
- “展开详情”可直接恢复封面和简介。
- 单击缩略图选页，双击从该页阅读；每组最多 48 页，可翻组或按原页码定位。
- 标签和简介可在详情中编辑；编辑框保留自身的滚动行为。

## 阅读

图片、ZIP/CBZ、RAR/CBR、7z/CB7、PDF、EPUB 使用同一阅读窗口。

- 顶部切换单页/双页、阅读方向、横向/纵向、全景和适应尺寸。
- 双页从进入页配对：开头为 1+2、3+4；从单页第 6 页切换则为 6+7、8+9。智能检测到横跨页时独立显示。
- 最后一组包含尾页即显示最终页码，进度为 100%，返回资源库后同步显示读完。
- 相邻书籍的三角按钮默认隐藏；在首页继续向前或尾页继续向后翻页时出现，点击后切换书籍。从右到左阅读时按钮位置镜像。
- 全景中可拖动或滚轮连续浏览，快速拖动会加速并保留松手惯性。
- 两端都可点击／拖动进度条实时切页，默认适应窗口。PC 额外保留页码输入和首页／上一页／下一页／尾页按钮；手机以进度条上方的浮层显示页码。
- 书签按钮保存当前图片/PDF 页或 EPUB 章节。
- “沉浸”进入全屏并自动隐藏控件；鼠标移到窗口顶部或底部可再次显示。
- 返回资源库后保留进入阅读前的列表位置。

| 快捷键 | 功能 |
| --- | --- |
| Esc | 先退出沉浸；非沉浸时返回资源库 |
| F | 切换沉浸/全屏 |
| 左/右方向键 | 按当前阅读方向翻页 |
| 上/下方向键 | 上一本 / 下一本，横向和纵向阅读均生效 |
| Space / Backspace | 下一页 / 上一页 |
| Home / End | 首页 / 尾页 |

EPUB 按完整章节计数，不按窗口宽度重新分页；PDF 按文档页码计数。Windows PDF 封面取第一页，EPUB 优先使用声明的封面图，再尝试首章图片；无法提取时显示格式图标。详情逐页预览仍使用格式图标。

### 资源库目录与连续分页

- 在子目录按 Esc 返回上一级；有菜单、弹窗、输入焦点或选择模式时，先处理当前操作。
- 纯图片文件夹只显示“文件夹”。有子文件夹，或有两个及以上可独立阅读的压缩包、PDF、EPUB 时显示“含 X 项目”；X 仅统计子文件夹与这些漫画文件。
- 资源库、收藏、书签、最近阅读、临时存放及书架连续滚动；底部数字可直接跳转。
- 当前页按顶部所在行计算，滚到底时显示末页。输入页码、上一页 / 下一页、PageUp / PageDown 均定位对应段首行；超范围输入自动修正。最后一段不足一屏时受列表底部限制，仍正确显示末页。
- 调整列数、窗口大小或每页数量时保留当前可见项目所在行；搜索、排序或切换目录后从顶部浏览。返回阅读器之前的目录时恢复位置。此规则针对资源库目录列表。

### Windows 1.1.2 缩放与全景

- 普通阅读的缩放下拉菜单包含适应窗口、适应宽度、适应高度、原始尺寸。适应窗口完整显示页面；适应窗口去掉左右预留边距，宽图可以铺满可用宽度；适应宽度只按宽度缩放，适应高度只按高度缩放，超出部分可滚动查看；原始尺寸保持原图大小。
- 双页只有在当前窗口能完整容纳时合并；放不下会逐页显示，调整窗口大小后自动重算。
- 横向全景自动适应高度，纵向全景自动适应宽度，沿阅读方向拖动查看长图。全景期间缩放下拉菜单禁用；退出后恢复普通阅读的选择。
- Esc 关闭菜单或退出沉浸后不再留下按钮描边；使用 Tab 导航仍会显示键盘焦点。
- 上下本按钮采用圆角磨砂底与居中小三角；也可使用 ↑/↓ 切书，恢复各自阅读进度，按住不连续切换。顶部工具提示显示在按钮行下方。

## 整理与设置

- 书架保存软件内引用，可以移动、复制、重命名和排序，不移动真实漫画文件。
- 收藏、书签、最近阅读和临时存放的删除只影响对应记录。
- 标签和简介用于搜索与筛选；失效路径会标记，可检查后清理引用。
- PC 设置中可选择雾灰、北境、暖沙或夜色，调整阅读行为、分页、进度显示、预加载和缓存。
- 缓存预算不是应用总内存上限；正在显示的大图仍需占用解码内存。

## 备份、更新与卸载

设置、资源库引用和阅读记录位于 Electron 用户数据目录中的 `omicomic-data.json`。Windows 位于 `%APPDATA%\OmiComic`；备份时保留整个目录。

免安装版更新时关闭程序，把新 ZIP 完整解压到新目录后运行；本机记录会继续保留。安装版可使用新版本安装包更新。卸载入口位于 Windows“设置 → 应用 → 已安装的应用 → OmiComic”，卸载保留漫画文件和用户数据。
